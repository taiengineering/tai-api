## STEP 2 관찰: 법령엔진 처리 결과

### 2-1. 적용 법령

**관찰된 주요 법령** (실제 `law_name` 값에서):
- 승강기 안전관리법 시행령
- (기타 법령은 실제 데이터에서 확인 미완료)

**관찰 사항**:
- 1개 사업장(승강기 보유)이 1,000개 룰을 받는 것이 **의도된 것인지 과다 생성인지 기준 없음**. 비교군 없음 (1개 사업장 데이터만 존재).
- 업종별 법령 셋 차별화 여부를 확인할 다른 사업장 진단 데이터가 없음.

### 2-2. 누락 법령 (관찰)

시뮬레이션 입력 기반 예상 vs 실제:

| 업종 | 예상 적용 법령 | 현재 시스템 확인 가능 여부 |
|------|------------|----------------------|
| #01 아파트 신축 | 산업안전보건법, 건설기술진흥법, 건설업 기초안전보건교육 | 확인 불가 (비교 진단 없음) |
| #12 터널 공사 | 발파작업 안전기준, 밀폐공간 작업 | 확인 불가 |
| #24 화학공장 | 화학물질관리법, 위험물안전관리법, PSM | 확인 불가 |
| #33 반도체 제조 | 화학물질관리법 + 반도체 특수 법령 | 확인 불가 |
| #06 철거 공사 | 석면안전관리법 | 확인 불가 |

**관찰**: 현재 시스템에서 업종별 법령 차별화가 되는지 확인 불가. 단일 사업장 데이터만 존재.

### 2-3. 과다 법령 가능성

**관찰**: 1,000개 룰이 1개 사업장에 생성됨.
- 실제 한 사업장에 적용되는 의무는 업종·규모에 따라 30~500개 수준(법령 전문가 기준 추정).
- 1,000개가 적절한 수인지, 과다 생성인지 **현재 기준 없음**.
- rule_type 필드가 있으나 해석 기준 없음 (`"002"` 등 코드값 — 의미 미확인).
- law_system = `"NOT_MAPPED"` 값이 확인됨 → 법령 매핑이 완료되지 않은 룰이 포함되어 있음.

### 2-4. 건설업 vs 운영업 구분

**관찰**:
- 현재 데이터(실제 진단 1건)는 운영 중인 제조/설비 사업장으로 추정.
- 건설현장(#01~#12) 형식의 진단 결과는 실제 데이터 없음.
- 건설업과 운영업이 동일한 법령 체계로 처리되는지 확인 불가.

### 2-5. 입력값과 법령엔진 연결 관찰

**관찰**:
- 사용자가 입력한 설비 정보(압력용기 종류, 크레인 정격하중 등)가 법령 선택에 실제로 반영되는지 확인 불가.
- 입력 정보가 `input_data` 필드에 저장됨은 확인 (`factory_diagnosis_results.input_data` 존재) — 내용 확인 미완료.
- 법령엔진이 어떤 입력 필드를 사용하는지 매핑 정보 없음.
