## 입력 난이도 분석 (관찰)

### 입력하기 어려운 정보 (상위 5개)
1. **변압기 용량(kVA)** — 50개 중 38개 사업장이 모름. 전기담당자나 한전 계약서 확인 필요
2. **압력용기 종류·설계압력·재질** — 전문 지식 필요. 장비 명판 확인 필요
3. **크레인 정격하중·형식** — 임대크레인은 임대업체에 문의 필요
4. **위험물 정확한 저장량** — 일일·계절 변동. 고정값 입력 불가
5. **화학물질 정확한 종류·농도** — MSDS 없이 입력 불가. 전담자 필요

### 입력 불가능한 정보
- 이동형 사업장(운송업, 소방공사업, 전기공사업)의 현장 정보
- 임차인 각 업종의 위험물·설비 (건축물 운영자 관점)
- 공사 중 변동 정보 (협력업체 수, 외국인 비율, 위험물 일일 반입량)
- 석면 함유 여부 (조사 결과 대기 중)

### 입력 누락 가능성이 높은 정보
- 에스컬레이터 (승강기로 대체 입력 경향)
- 목분·분진 (위험물로 미인식)
- 냉동기 냉매 종류 (특히 암모니아 — 알면서도 어느 항목인지 모름)
- 발전기 용량 (비상발전기를 설비로 미인식)
