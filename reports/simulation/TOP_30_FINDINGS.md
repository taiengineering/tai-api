# Phase 11 — Top 30 Findings
## 중요도 순 발견 사항

> 관찰 기준: 실제 사용자 입력 시뮬레이션 + 실제 시스템 데이터(Phase 10~10B 기반).
> 이 목록은 **무엇이 문제인지 관찰**한 것이며, **어떻게 고쳐야 하는지 결정하지 않음**.

---

### 🔴 심각 (운영 블로킹)

**#1. READY 의무가 0건 — 어떤 사업장도 스케줄 생성 불가**
- 전체 50개 사업장 시뮬레이션, 1,000개 의무 적재 후 READY = 0건
- 원인: evidence.chain이 LEG 의무에 연결되지 않음
- 영향: Schedule Gate를 활성화해도 스케줄 생성 0건

**#2. LEG 결과의 result_data 스키마가 schedule_pipeline이 기대하는 키와 다름**
- 실제 진단: `result_data.rules[]` 사용
- schedule_pipeline이 기대: `result_data.inspection_required[]`
- 영향: 현재 `/legal-engine/generate-schedules` 엔드포인트가 실데이터에서 0건 생성

**#3. evidence.chain이 LEG 의무 스키마에 없음**
- `result_data.rules[]` 각 항목에 evidence.chain 필드 없음
- Check는 claim은 처리하나 evidence/chain 판단 불가
- CHAIN_NOT_DECLARED가 모든 의무에 발생

**#4. 압력용기·크레인 사양을 일반 사용자가 입력 불가**
- 50개 사업장 중 38개 이상이 변압기 용량 모름
- 압력용기 설계압력·재질은 전문가만 알 수 있는 정보
- 법령은 이 사양을 기반으로 의무를 결정하는데, 입력 자체가 불가

**#5. 이동형 사업장(운송업·소방공사·전기공사)의 입력 체계 없음**
- 현장이 매주 바뀌는 사업장은 "현재 어느 현장" 단위로 입력 불가
- 본사 단위로만 입력 시 실제 현장 위험이 반영되지 않음

---

### 🟠 높음 (품질 저하)

**#6. law_system = "NOT_MAPPED" 룰이 존재함**
- 실제 진단 데이터에서 확인
- 법령 매핑이 완료되지 않은 의무가 생성·적재됨
- 사용자에게 의미 없는 의무가 포함될 가능성

**#7. 1개 사업장에 1,000개 의무 생성 — 과다 여부 판단 기준 없음**
- 비교군 없어 1,000개가 적정인지 확인 불가
- 업종별 의무 수 벤치마크 없음

**#8. 위험물 입력값과 법령 선택의 연결 추적 불가**
- 사용자가 "암모니아 냉매 4,000kg" 입력 시 어떤 법령이 트리거되는지 사용자가 알 수 없음
- 입력→법령 선택 로직이 블랙박스

**#9. 석면·화약류·방사선 등 특수 위험물 입력란 없음**
- #06 철거 공사: 석면 함유 의심 → 어느 항목에 입력해야 하는지 모름
- #12 터널: 화약(발파) → 위험물인지 화약류인지 구분 불명
- #13 병원: 방사선 → 입력란 없음

**#10. 임차인 위험물·설비를 건물 관리자가 입력 불가**
- #19 지식산업센터: 입주 제조업체의 위험물 현황 파악 불가
- #16 백화점: 매장별 인화성 물질 파악 불가

**#11. 공사 중 사업장에서 운영법령과 건설법령 중복 적용 여부 불명**
- #10 공장 증설: 기존 공장 운영 중 증설 공사 병행
- 어느 법령 체계가 적용되는지 사용자가 판단 불가

**#12. 에스컬레이터가 승강기와 다른 항목임을 사용자가 모름**
- #16 백화점: 에스컬레이터 80기를 승강기로 입력할 가능성
- 실제 안전검사 대상이 다름

**#13. 냉동기 냉매 종류(암모니아 vs 프레온)에 따른 법령 차이를 사용자가 모름**
- #20 대형마트, #31 냉동창고: 암모니아 냉매 → 화학물질관리법 대상
- 사용자는 냉동기 정보를 냉동기 항목이 아닌 설비 일반에 기입

**#14. 다수의 소규모 사업장이 안전관리 담당자 없이 대표자 직접 입력**
- #09 상가 신축, #22 모텔, #45 가구 제조: 처음 입력하는 사용자
- 항목 의미 자체를 모름

**#15. 보관 품목이 매일 바뀌는 물류창고·위험물저장소의 입력 현실성 문제**
- #17 물류창고: 리튬배터리 보관량 일일 변동
- #29 위험물 저장소: 고객사에 따라 품목·저장량 변동

### 🟡 보통 (사용자 경험·데이터 품질)

**#16. 건축물 사용승인일이 오래된 경우 서류 찾기 어려움**
- #41 방직공장 (1995년), #22 모텔 (2001년): 30년 이상 된 서류

**#17. 다동(多棟) 건물을 단일 사업장으로 입력하는 방법 불명**
- #01 아파트 신축: 5개동 → 동별 입력인지 단지 단위인지 불명
- #21 아파트 운영: 8개동

**#18. 위험물 농도 정보를 MSDS 없이 입력 불가**
- #46 신발 제조: 접착제 톨루엔 농도 모름
- #25 도금공장: 크롬산 농도 모름

**#19. 임시 설비(건설용 크레인, 가설전기)가 사업장 설비 입력에 포함되는지 불명**
- 타워크레인은 임시 설비 — 상시 설비 입력란에 넣어야 하는지

**#20. 장기 공사의 단계별 입력 방법 없음**
- #11 재건축(48개월): 공정별로 위험이 달라지나 단일 입력만 가능

**#21. 협력업체 수·외국인 근로자 비율 입력란 없음**
- 건설현장에서 실제 안전관리에 중요한 정보
- 시스템에 항목 없음

**#22. 발전기 용량을 사용자가 모르는 경우 다수**
- 비상발전기 용량: 시설팀 또는 전기담당자 확인 필요
- 50개 중 약 20개 사업장이 이에 해당

**#23. 지게차가 크레인 항목에 들어가는지 불명**
- #17 물류창고: 지게차 15대 — 위험기계 항목에 포함 여부 불명

**#24. 세대 내 보일러를 공동주택 관리자가 집계 불가**
- #21 아파트: 1,200세대 각각의 보일러 → 집계 불가, 공용부분만 입력

**#25. 도장부스 방폭 등급 입력란 없음**
- #40 자동차 도장업: 방폭 여부가 법령 적용의 핵심이나 항목 없음
