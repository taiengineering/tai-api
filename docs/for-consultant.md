## 이 페이지를 보는 사람

- 1인 안전 컨설턴트 (경력 15년+, 독립)

- 공통점: 전문성은 최고인데 반복 매출이 없고, 입소문에만 의존

## 섹션 (12개 + 교차링크)

### §1 히어로 [A 다크]
"보고서 한 건 쓰면\n끝입니다."
컨설팅은 한 건이 끝나면 다음이 없습니다.\n다시 처음부터 영업입니다.
"한 건이 끝나도 다음 건이 이어지는 구조를 준비하고 있습니다."

### §2 속마음 — 반복 매출이 없다 [B 좌텍-우목]
"안전관리체계 구축해주면 끝이에요.\n위험성평가 써주면 끝이에요.\n반복 매출이 없어요.\nSaaS처럼 매달 들어오는 돈이 아니라\n한 건 하고, 정산하고, 또 찾아야 해요.\n12월에 내년 매출이 얼마일지 모르겠어요."
→ 해결: TAI에서는 법적 의무가 발생할 때마다 컨설팅 수요가 생깁니다. 한 건이 끝나도 다음 의뢰가 자동으로 이어집니다.
→ 목업: 의뢰 대기열 (대기 2건, 진행 1건, 완료 8건)

### §3 속마음 — 입소문 의존 [C 좌목-우텍]
"입소문이 전부예요.\n한 곳 잘해주면 거기서 다른 곳 소개해주고.\n근데 그게 불규칙해요.\n3개월 연속 일 있다가 갑자기 2개월 없고.\n후배한테는 '잘 되고 있다' 하는데\n사실 불안해요."
→ 목업: 컨설팅 의뢰 알림 (건설업 48억, 안전관리체계+위험성평가, 중대재해법)

### §4 속마음 — 가치를 인정받지 못한다 [B 좌텍-우목]
"위험성평가 한 건에 보통 200~500만원인데\n'그거 그냥 서류 아니냐'고 해요.\n며칠 걸려서 현장 다니고 분석하고 쓰는 건데\n서류 한 장 값으로 보는 거예요.\n전문성을 이해하는 곳이 없어요."
→ 해결: TAI를 통해 연결되는 사업장은 법적 의무를 이미 인지한 곳입니다. "왜 필요한지" 설명할 필요 없이 업무에 집중할 수 있습니다.
→ 목업: 의뢰 상세 (관련 법령 자동 첨부, 의무 항목 정리됨, 사업장 규모·업종 명시)

### §5 속마음 — 중대재해법 이후 [C 좌목-우텍]
"중대재해처벌법 나오고 문의가 좀 늘긴 했어요.\n근데 '싸게 해달라'는 곳만 와요.\n법 때문에 어쩔 수 없이 하는 거지\n진짜 안전을 위해서 하는 곳은 드물어요.\n그래도 어쩌겠어요, 일이니까."
→ 해결: TAI에서는 사업장의 규모·업종·법적 상황이 정리되어 있어서 적정 범위를 사전에 파악할 수 있습니다.

### §6 전환점 [A 다크]
"전문가의 시간이\n제값을 받을 수 있어야\n합니다."
"지금은 '서류 한 장'으로 취급받습니다.\n전문성이 숫자로 증명되는 구조를 만들고 있습니다."

### §7 속마음 — 신규 개척 [B 좌텍-우목]
"새 고객을 찾으려면 세미나 가서 명함 돌리거나\n지인한테 부탁하거나.\n홈페이지 만들어봤는데 검색에 안 잡혀요.\n안전 컨설팅을 검색하는 사업주가\n얼마나 되겠어요."
→ 해결: 사업주가 "안전 컨설팅"을 검색하는 게 아니라 법령진단 결과에서 컨설팅 필요가 자동으로 감지됩니다.
→ 목업: 매칭 알림 ("위험성평가 미작성 사업장 감지, 컨설팅 의뢰 자동 생성")

### §8 속마음 — 경력 증명 [C 좌목-우텍]
"20년 했어요. 대기업 출신이에요.\n근데 독립하니까 그게 다 의미 없어요.\n이름값이 없으니까.\n법인 이름 걸면 좀 낫긴 한데\n결국 실적을 보여줄 방법이 없어요."
→ 해결: 완료한 컨설팅마다 실적·규모·평가가 자동 누적됩니다. 20년 경력이 데이터로 증명됩니다.
→ 목업: 컨설턴트 프로필 (⭐4.9, 완료 31건, 전문: 제조·건설, 평균 프로젝트 규모: 200인)

### §9 매칭 구조 [F 다크 SVG]
"법이 만들어낸 수요가, 전문가에게 연결됩니다."
SVG: [사업장 법령진단] → [컨설팅 필요 감지] → [전문분야·규모 매칭] → [컨설턴트 알림] → [의뢰 확인·수락] → [진행·정산]
