# Q-Net API 활용 가능 항목 분석

> 작성일: 2026-04-11  
> 출처: https://openapi.hrdkorea.or.kr/main

---

## 결론: 개인 자격 진위 확인 불가

국가자격취득자 현황 조회는 **집계 통계 API**.
특정 개인이 자격을 보유했는지 조회 불가.

Q-Net 웹에 진위확인 화면 존재하나 공개 API 없음.
→ NetFunnel 대기열 시스템으로 자동화 크롤링도 어려움.

**초기 방식: 자격증 사본 업로드 + TAI 수동 승인**

---

## TAI 활용 가능 항목

### 🔴 즉시 활용 (공급자 검증)

| API | 활용 | 신청처 |
|---|---|---|
| 국가자격취득자 현황 조회 | 지역별 자격자 수 파악 (통계) | data.go.kr |
| 국가자격 종목 목록 | 공급자 등록 폼 드롭다운 표준화 | data.go.kr |

### 🟠 중기 활용 (안전정보 콘텐츠)

| API | 활용 |
|---|---|
| 국가자격 시험일정 | "이번 달 산업안전기사 시험 일정" 콘텐츠 |
| 숙련기술인 정보 | 프리미엄 공급자 풀 (대한민국명장 등) |
| 지역별 자격취득 정보 | 선임연결 지역별 매칭 고도화 |

### 🟡 장기 활용

| API | 활용 |
|---|---|
| NCS 관련 정보 | 점검 항목 자동 분류 정확도 향상 |
| 자격취득자 교육훈련 과정 | 법정 의무교육 연계 |

## 신청 방법

모두 data.go.kr에서 신청 가능 (자동승인).
Q-Net 개인 자격 검증 API는 hrdkorea.or.kr 기업 신청 필요 (중기 목표).
