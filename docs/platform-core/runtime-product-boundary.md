# Runtime Product Boundary

## 핵심 전환

과거: 법령 결과 제공 서비스
현재: Human Governance 기반 Runtime Operating System

---

## 무료/유료 경계

### FREE = "법령을 알려주는 단계"

- 법령진단 실행 (1회)
- Candidate Preview (의무 목록)
- 기본 리스크 등급
- 홈페이지 자료 검색

### PAID = "법령을 운영하는 단계"

| 등급 | 핵심 |
|---|---|
| STARTER | Schedule + Assignment + Evidence + Cockpit |
| BUSINESS | + Reviewer + Escalation + Risk Score + Document |
| ENTERPRISE | + Audit + Multi-site + API + Analytics |

## 전환점

**Activation (Candidate 승인)** = 무료→유료 전환 순간

진단은 "법령을 보는 것".
Activation은 "법령을 운영하는 것".

## 고객 가치

고객이 돈을 내는 이유:
"법령을 검색하려고"가 아니라, "법령을 운영하려고"

## 기존 vs 현재

| 항목 | 기존 | 현재 |
|---|---|---|
| 무료 | 법령 매칭 일부 | Candidate Preview |
| 유료 진입 | PDF 리포트 구매 | **Activation** |
| SaaS 핵심 | 점검일정+알림 | **Runtime Schedule+Evidence+Cockpit** |
| 전환 동기 | 더 자세한 리포트 | **법령을 실제로 운영** |

## 가장 중요한 전략 변화

진단 리포트는 더 이상 최종 상품이 아니다.
진단은 **Runtime Operating System의 진입점**이다.

```
기존: 진단 → PDF → 끝
현재: 진단 → Candidate → Activation → Runtime → 지속 운영
```
