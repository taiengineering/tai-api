## 아이디어 요약

실시간 기상 데이터(풍속·기온·강수량·낙뢰)와
현장 위치 정보, 법적 작업중지 기준 DB를 연계하여
작업중지 여부를 자동 판단하고 법적 증빙을 생성하는 시스템.

## 특허 요건 검토

- **신규성**: 기상+법적기준 자동 연계 서비스 미확인 → 가능성 있음
- **진보성**: 설비별 차등 기준 + 격자 변환 + 증빙 생성 구조 → 가능성 있음
- **이용가능성**: 건설·제조·시설 현장 전체 적용 가능 → ✅

---

## 핵심 청구항 후보

```
① 현장 위치좌표 → 기상청 격자(nx, ny) 자동 변환 (Lambert 투영)
② 실시간 기상값 ↔ 산안법 조문별 작업중지 기준 자동 매핑
③ 작업 유형(설비)별 차등 기준 적용
   (타워크레인 풍속 기준 ≠ 일반 고소작업 기준)
④ 기상특보 → 법적 의무 작업중지 자동 연계
⑤ 작업중지 기록 → 법적 증빙 문서 자동 생성
```
