# Archive Directory

This directory contains historical documents moved from docs/ root.

These documents are retained for reference but are not part of active operational documentation.

## Categories

| Subdirectory | Contents |
|-------------|----------|
| sessions/ | Session logs, session handoffs, session summaries |
| memory/ | TAI_Backend_MEMORY_* session memory files |
| temp/ | Temporary files, deploy triggers, restart triggers |

## Policy

- Documents here are read-only historical reference
- No active operational dependency
- Runtime boundary docs remain in docs/ root (not moved here)
