## 고객 유형별 필요 정보

```
"이번 달에 뭐가 바뀌었나?"
```

## 유효 콘텐츠 5가지

고객이 실제로 검색하고 클릭하는 콘텐츠:

| 순위 | 콘텐츠 유형 | 핵심 질문 | 긴급도 |
|---|---|---|---|
| 1 | **법령 개정 알림** | "이번 달 바뀐 것" | 🔴 높음 |
| 2 | **중대재해 사례** | "같은 업종 사망사고" | 🔴 높음 |
| 3 | **감독 동향** | "요즘 어디 집중 감독하나" | 🟠 중간 |
| 4 | **과태료·처벌 판례** | "얼마까지 나왔나" | 🟠 중간 |
| 5 | **점검 기준 해설** | "이 항목 어떻게 판단하나" | 🟡 낮음 |

## 데이터 소스 및 수집 방법

### 1. 법령 개정 알림

**소스:**

| 기관 | API | 엔드포인트 |
|---|---|---|
| 법제처 국가법령정보센터 | OpenAPI (공개) | `open.law.go.kr` |
| KOSHA 안전보건법령 스마트검색 | 공공데이터포털 | 산업안전보건법·중대재해처벌법 전용 |

**수집 방법:** 자동 (API)

**TAI 활용:**
```
법제처 API → 산업안전보건법·중대재해처벌법 개정 감지
→ posts 테이블 자동 저장
→ TAI Safe 앱 내 알림 + 이메일 발송
```

**핵심 파라미터:**
- 법령명: 산업안전보건법, 중대재해처벌법, 건설기술진흥법, 소방시설법 등
- 시행일, 개정 이유, 변경 조문 번호

---

### 2. 중대재해 사례

**소스:**

| 기관 | API | 공공데이터포털 ID |
|---|---|---|
| 안전보건공단 국내재해사례 | OpenAPI (공개) | `15121001` |
| 고용노동부 산업재해현황 | 파일+API | `15002274` |

**수집 방법:** 자동 (API)

**KOSHA 재해사례 API 명세:**
```
URL: data.go.kr/15121001
파라미터:
  - business: 게시판 종류 (제조업/건설업/조선업 등)
  - keyword: 제목 키워드
  - pageNo, numOfRows
응답: 재해 발생 일시, 업종, 재해 유형, 사망 여부, 원인
```

**TAI 활용:**
```
KOSHA 재해사례 API → 업종·재해유형별 파싱
→ TAI Safe 대시보드에 "우리 업종 최근 사고" 위젯
→ posts 테이블 저장 (섹터 태그 포함)
```

---

### 3. 감독 동향

**소스:**

| 기관 | 방법 | 비고 |
|---|---|---|
| 고용노동부 보도자료 | RSS 구독 / 크롤링 | ⚠️ API 없음 |
| 고용노동부 근로감독 계획 | 홈페이지 게시판 | 분기별 공표 |

**수집 방법:** 반자동 (크롤링 + 편집 검토)

**TAI 활용:**
```
고용노동부 보도자료 RSS → "집중감독", "감독계획" 키워드 감지
→ AI 초안 생성 → 편집팀 1회 검토
→ posts 테이블 게시 (태그: 감독동향)
```

---

### 4. 과태료·처벌 판례

**소스:**

| 기관 | API | 비고 |
|---|---|---|
| 법제처 행정심판 재결례 | `open.law.go.kr` | 2024년 12월 60만건 개방 |
| 대법원 판례 | 공공데이터포털 | 공개 API |

**수집 방법:** 반자동 (API 수집 + AI 요약)

**TAI 활용:**
```
"중대재해", "산업안전", "과태료", "벌금" 키워드 판례 수집
→ AI로 요약 (업종, 위반 내용, 처벌 금액)
→ posts 테이블 게시 (태그: 판례·과태료)
```

---

### 5. 점검 기준 해설

**소스:**

| 기관 | 방법 | 비고 |
|---|---|---|
| KOSHA GUIDE | KOSHA API / PDF | 기술지침 600종 이상 |
| KOSHA 안전보건법령 스마트검색 | 공공데이터포털 | AI 검색 포함 |

**수집 방법:** 수동 (PDF → AI 요약)

**TAI 활용:**
```
KOSHA GUIDE PDF 다운로드 → AI 요약
→ 설비·업종별 해설 시리즈 posts 게시
→ TAI Safe 내 관련 점검 항목과 연결
```

```
  - 'penalty_case'    과태료·판례

sector_tag:
  - 'construction'    건설

  - 'law_go_kr'       법제처
```

## TAI만의 차별점

일반 안전 뉴스 사이트와 다른 점:

```
일반 사이트:
  모든 사람에게 동일한 뉴스

TAI:
  수집된 데이터를 고객의 업종·설비·지역에 맞게 필터링
  → "우리 업종 이번 달 사고 3건"
  → "우리 지역 이번 달 감독 계획"
  → "우리 설비 관련 법령 개정"
```

이것이 TAI 안전정보의 핵심 경쟁력.
