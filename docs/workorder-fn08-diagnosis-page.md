## 진입 경로 2가지

### 경로 1: 무료 진입

```
URL: free-diagnosis.html
플로우: 본인인증 → 섹터선택 → FREE입력 → 면책동의 → 결과 → 추천 → 유료전환
```

### 경로 2: 유료 진입 (pricing에서 결제 완료 후)

```
URL: free-diagnosis.html?paid=INDUSTRY_STANDARD&order_id=TAI2604180001
플로우: 섹터자동 → PAID필드전체 → 면책동의 → 진단실행 → 결과즉시표시
```

### URL 파라미터

| 파라미터 | 값 | 용도 |
|---|---|---|
| `paid` | `BUILDING_V2`, `INDUSTRY_STANDARD` 등 | 결제 완료된 가격 코드 |
| `order_id` | `TAI2604180001` | 결제 검증용 |
| (없음) | — | 무료 진입 |

### 진입 로직

```javascript
const params = new URLSearchParams(location.search);
const paidCode = params.get('paid');
const orderId = params.get('order_id');

if (paidCode && orderId) {
  // 경로 2: 결제 검증 → 섹터 자동 → PAID 폼
  await verifyPayment(orderId, paidCode);
  autoSetSector(paidCode);   // INDUSTRY_STANDARD → sector='INDUSTRY'
  loadPaidForm(paidCode);
} else {
  // 경로 1: 본인인증부터
  showIdentityVerification();
}
```

## 스텝 구조

### Step 0: 본인인증 (무료 경로만)

**좌측:**
```
클립보드 이미지
"사업장 정보 보호"
"타인의 사업장 정보가 무단 조회되지 않도록
 간편 본인확인을 진행합니다"
```

**우측:**
```
사업장 정보 보호를 위해
간편 본인확인이 필요합니다

[네이버] [PASS] [토스] [금융인증서]

10초면 완료됩니다
```

- "사업장 정보 보호" 프레이밍
- "회원가입", "로그인" 표현 금지
- 유료 경로는 이 단계 건너뜀 (pricing에서 이미 인증)

### Step 1: 섹터 선택

**좌측:**
```
"법령진단"
"법령위반 중이십니까?"
체크리스트 4개
```

**우측:**
카드 **3개** (소형/대형 분리 금지):
```
[🏢 건물]   [🏭 제조·산업]   [🏗️ 건설현장]
```

### Step 2: FREE 입력

**좌측:** 섹터별 매칭 변경
```
BUILDING: "주소만 입력하면 바로 확인됩니다"
INDUSTRY: "업종과 규모만으로 진단합니다"
CONSTRUCTION: "공사 기본 정보로 진단합니다"
```

**우측:**
- `GET /diagnosis/fields?sector={}&tier=FREE` 로 필드 동적 로드
- 주소 검색 → 면적·층수 자동 채움 (**건축물대장 언급 금지** — 값이 채워지는 것 자체가 피드백)
- BUILDING/CONSTRUCTION: 면적/공사금액 입력 시 가격 자동 판정 (**사용자에게 노출 안 함** — 결제 시점에만 표시)
- 면책 동의 체크박스 (진단 실행 버튼 직전)

**면책 동의 UI:**
```
☐ 본 진단 결과는 현행 법령과 사업장 정보를 정밀 분석하여
  적용 가능한 법적 의무를 도출한 것입니다.
  법률 상담·자문·의견 제공이 아니며, 개별 사안에 대한
  법적 판단이나 해석을 포함하지 않습니다. [전문 보기]

[무료 진단 실행 →]    ← 체크 시 활성화
```

### Step 4: 유료 PAID 입력

**좌측:**
```
BUILDING/CONSTRUCTION:
  "위험물·설비가 있으시면
   해당 법령이 추가로 적용됩니다"

INDUSTRY:
  "입력하신 정보에 해당하는
   법령이 자동으로 적용됩니다"
```
- "더 많이 입력하면 더 정확" 표현 **금지**
- "안 보이는 법령이 있다" → "해당 법령이 추가 적용된다"

**우측:**

**BUILDING/CONSTRUCTION:** FREE 데이터 유지 + PAID 필드 추가 표시
**INDUSTRY:** 등급 선택 (79K/149K/249K) → 해당 tier 필드 로드

**업그레이드 감지 (BUILDING/CONSTRUCTION):**
```
┌──────────────────────────────────────────┐
│  이 건물은 대형건물(5,000㎡ 이상)입니다      │
│  대형건물 진단이 필요합니다                   │
│                                          │
│  추가 결제: 150,000원 (249K - 99K)         │
│  [추가 결제하기]  [현재 등급 유지]             │
└──────────────────────────────────────────┘
```

### Step 5: 유료 결과 (즉시 표시)

**결제 완료 → 엔진 실행 → 결과 즉시 표시 (같은 페이지 내)**
- PDF 이메일 발송 (백그라운드)
- 마이페이지에도 저장 (나중에 재확인용)
- "마이페이지로 가세요" 리다이렉트 금지

## 필드 로딩 규칙

### 주소 검색
- 행정안전부 도로명주소 API (juso.go.kr) 사용
- 카카오 API 사용 **절대 금지**
- 주소 입력 → 면적·층수 자동 채움
- **"건축물대장"이라는 단어 UI에 노출 금지** — 값이 채워지는 것 자체가 피드백

### 가격 자동 판정
- BUILDING: 면적 입력/자동조회 시 내부적으로 판정 (사용자 미노출)
- CONSTRUCTION: 공사금액 입력 시 내부적으로 판정 (사용자 미노출)
- 결제 시점에만 가격 표시
- INDUSTRY: 사용자가 등급 직접 선택

### 필드 API
- `GET /diagnosis/fields?sector={}&tier=FREE` → FREE 필드
- `GET /diagnosis/fields?sector={}&tier=PAID` → PAID 필드 (BUILDING/CONSTRUCTION)
- `GET /diagnosis/fields?sector=INDUSTRY&tier=PAID1` → INDUSTRY 등급별

## 금지 사항 (전체)

| 금지 | 대체 |
|---|---|
| "건축물대장" 노출 | 자동 채움 — 언급 없음 |
| "기계적으로 대조" | "정밀 분석하여 도출" |
| "더 많이 입력하면 더 정확" | "해당 법령이 추가 적용" |
| 유료 추천 시 가격 먼저 노출 | 필요성 먼저 → 버튼 클릭 시 가격 |
| "회원가입", "로그인" | "사업장 정보 보호를 위한 본인확인" |
| 전문가 상담 버튼 | 없음 |
| 소형/대형 섹터 분리 | 자동 판정 |
| 결과 인위적 제한 | 입력한 만큼의 완전한 결과 |
| "마이페이지에서 확인" 리다이렉트 | 결과 즉시 표시 |
| 카카오 API | juso.go.kr 또는 네이버 |
