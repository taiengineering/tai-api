## 1. 핵심 원칙

### 1.1 이중 페르소나 설계

리포트는 **두 사람**이 본다. 각자 관점이 완전히 다르다.

| | 안전관리자 (사용자) | 결재권자 (대표/임원) |
|---|---|---|
| **동기** | "혼자 못 하겠다, 도구 필요" | "안 하면 얼마나 위험한가" |
| **판단 기준** | 업무 경감 여부 | 비용 vs 리스크 |
| **시간** | 5~10분 꼼꼼히 | 30초 안에 판단 |
| **행동** | 기안PDF 다운 → 품의서 작성 | 품의서 결재 승인 |

**하나의 관점만 설계하면 전환율이 낮아진다.**
- 안전관리자 관점만 → 결재권자가 못 읽음 → 품의 반려
- 결재권자 관점만 → 안전관리자가 가치 못 느낌 → 품의 안 씀

### 1.2 전환 포인트

**기존 사고**: "콘텐츠 잠금 → 결제하면 해제" (블러/잠금)
**확정 구조**: "무료에서 전부 보여주고 → 유료에서 공식 문서 형태를 준다" (형식 차별)

전환이 일어나는 순간:
```
안전관리자가 웹에서 전체 확인
→ "이걸 대표님한테 보여드려야 하는데"
→ 기안용 PDF 다운 (무료)
→ 품의서 작성 + 결재 요청
→ 결재 승인
→ 유료 결제
→ 상세 보고서 PDF 다운
```

### 1.3 기안용 PDF = TAI 영업 도구

무료로 제공되는 기안용 PDF가 핵심:
- 안전관리자가 품의서에 첨부할 수 있는 공식 자료
- TAI 서비스 소개 + 견적이 자연스럽게 포함
- **고객이 TAI 영업을 대행하는 구조**
- 품의 작성 장벽 제거 → 전환율 극대화

## 2. 4개 산출물

### 2.1 무료

#### ① 무료 웹 결과 화면
- **콘텐츠 100% 공개** (잠금/블러 없음)
- 위험도 HIGH + 적용 의무 220건
- 5개 카테고리 전체 목록 (선임/점검/조치/보고/교육)
- 법조항/주기/벌칙 전부 열람
- 법률별 68개 카드 그룹핑 (아코디언)
- 용도: 안전관리자가 혼자 확인
- 제한: 링크 공유 7일 만료, 인쇄/저장 불가

#### ② 기안용 PDF (무료)
- **품의서 첨부용 요약 문서** (3~4페이지)
- p.1: 경영진 요약 (위험도 + 의무 건수)
- p.2: 미이행 시 리스크 (벌금 추정)
- p.3: 서비스 비용 + 견적
- p.4: TAI 서비스 소개
- 용도: 결재권자에게 전달하는 문서
- 핵심: **안전관리자가 TAI 영업을 대행**

### 2.2 유료

#### ③ 유료 간단 리포트 웹
- 결제 직후 바로 확인하는 화면
- 핵심 요약 + 카테고리 건수
- "상세는 PDF 다운로드"
- 용도: 결제 후 즉시 가치 확인

#### ④ 유료 상세 진단 보고서 PDF
- **유료의 핵심 산출물**
- 전체 법령 상세 포함 (본문 + 부록)
- 보관/인쇄/감사 대비용
- 안전관리자의 실행 도구

## 3. 유료 PDF 구조 (본문-결론-부록)

### 3.1 구조

| 페이지 | 내용 | 대상 | 중복 처리 |
|---|---|---|---|
| 표지 | 회사명, 진단일, 위험도 | 모두 | — |
| p.1~2 | 경영진 요약 + 비용 비교 | 결재권자 | 숫자만 |
| p.3~8 | 카테고리별 법률 요약 (묶음) | 안전관리자 | 법률 단위 그룹 |
| p.9 | **결론 + 권고 = SaaS 안내** | **모두** | — |
| 부록 | **220건 전체 표** | 안전관리자 | 원본 표 형태 |

### 3.2 설계 의도

**결재권자는 부록까지 안 읽는다.**
- 표지 → 요약 → 결론 순서로 넘김
- **"결론 = SaaS 안내"가 이 사람한테는 마지막 페이지**
- SaaS 유도가 자연스러운 "끝"으로 작동

**안전관리자는 부록까지 전부 읽는다.**
- 본문에서 법률별 묶음 확인
- **부록에서 220건 원본을 표 형태로 확인**
- SaaS 유도는 이미 결론에서 봤고, 부록은 순수한 참고 자료

### 3.3 본문의 중복 처리

**본문 (p.3~8)**: 카테고리별 법률 요약
```
■ 선임 의무 (10건)
  산업안전보건법 → 안전관리자 외 3명
  소방시설법 → 소방안전관리자 외 1명
  ...

■ 점검 의무 (42건) → 18개 법률 요약
  ...
```

**부록**: 전체 상세 표
```
No | 법령 | 조항 | 의무유형 | 주기 | 벌칙 | 양식코드
1  | 산업안전보건법 | 제17조 | 선임 | — | — | APPOINT-SAFE-001
2  | 산업안전보건법 | 제18조 | 선임 | — | — | APPOINT-HLTH-001
... 220행
```

## 4. 중복 데이터 정리 전략

### 4.1 현황 분석 (BUILDING_FREE 기준)

```
total_items:        220
unique_laws:         68  (법률당 평균 3.2건)
unique_law_articles: 187
unique_summaries:    195
unique_rule_ids:     220
```

### 4.2 중복 유형

**Type A: 의미 있는 중복 (같은 조항, 다른 조건값)**
- 소방법 제22조 INSPECT × 3: 면적 200㎡/1,000㎡/1,500㎡
- 면적 단계별로 다른 점검 수준 → 하나의 카드로 묶되 조건 표시

**Type B: 진짜 중복 (같은 조항, 같은 조건값)**
- 하수도법 제37조 INSPECT × 2: 둘 다 400㎡
- 데이터 오류 → DB에서 병합 필요

### 4.3 3단계 정리

| 단계 | 어디서 | 작업 | 효과 |
|---|---|---|---|
| 1. 데이터 정제 | DB/BE (Claude Code) | 같은 조항+유형+조건값 병합 | 220→~190건 |
| 2. 조건 통합 | FE 렌더링 | 같은 조항+유형, 다른 조건값 → 1카드 | ~190→~170카드 |
| 3. 법률 그룹핑 | 리포트 UI | 68개 법률 단위 아코디언 | 사용자 체감 68개 |

### 4.4 중복이 영향받는 산출물

| 산출물 | 중복 영향 | 처리 방법 |
|---|---|---|
| ① 무료 웹 | 220건 → 체감 큼 | 법률별 68카드 그룹핑 |
| ② 기안용 PDF | 요약 3~4p → 없음 | 숫자만 표시 |
| ③ 유료 웹 | 간단 리포트 → 없음 | 핵심 요약만 |
| ④ 유료 PDF | 부록 220건 → 체감 큼 | 본문=묶음, 부록=표 |
