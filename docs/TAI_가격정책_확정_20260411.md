# PART 1. 법령진단 가격 — 확정

## 전략 원칙

```
법령진단 = 퍼널 (유입 도구)
SaaS = 핵심 수익
진단 → SaaS 전환 유도가 목적

FREE → 유료 진단 → SaaS 구독
```

## 섹터별 가격 구조

### 건설 (Construction)

| 단계 | 가격 | 내용 |
|------|------|------|
| FREE | 0원 | 기초 진단 (입력값 제한 방식) |
| 유료 | **199,000원** | 단일 상품 / 즉시 결제·즉시 대응 / 점검항목 생성 포함 |

```
포지션: "지금 바로 현장 대응"
단일 상품 구조 → 고민 없이 결제
감독 대응 및 제출용 리포트 생성
```

### 시설 (Facility)

| 단계 | 가격 | 내용 |
|------|------|------|
| FREE | 0원 | 기초 진단 (입력값 제한 방식) |
| 베이직 | **49,000원** | 법령 확인 / 선임·점검·신고 리스트 / PDF 리포트 |
| 스탠다드 | **99,000원** | 전체 결과 공개 / 실행 필요 항목 확인 |
| 프리미엄 | **149,000원** | 실무자 활용 단계 / 연결 서비스 진입 |

### 산업 (Industrial)

| 단계 | 가격 | 내용 |
|------|------|------|
| FREE | 0원 | 기초 진단 (입력값 제한 방식) |
| 베이직 | **79,000원** | 법령 이해 |
| 스탠다드 | **149,000원** | 전체 확인 및 실무 판단 |
| 프리미엄 | **249,000원** | SaaS 진입 전 단계 / 전환 유도 역할 |

## FREE 단계 설계 원칙

```
결과를 제한하지 않는다
입력값을 제한한다
→ 고객이 직접 입력할수록 더 정확한 결과
→ 유료 전환 = 더 정밀한 진단 욕구

FREE만으로도 기본적인 법령 인식 가능
→ "이것만 봐도 유용하다" → 유료 전환 동기
```

## 가격 설계 원칙

```
시설:  49 → 99 → 149  (약 2배 단위)
산업:  79 → 149 → 249 (약 2배 단위)
건설:  199 단일

→ 2배 단위 구조 = 고민 없이 업셀 가능
→ 가격으로 설득하지 않는다
→ 구조로 결제하게 만든다
→ SaaS만이 실행 기능을 가진다
```

## SaaS 전환 혜택

```
진단 후 SaaS 구독 전환 시:
  첫 달 기본료 50% 할인 쿠폰 자동 발송
  → 진단 = 퍼널의 시작
  → SaaS = 실제 수익의 시작
```

# PART 2. SaaS 구독 가격 — 확정

## 과금 단위

```
시설(사업장) 단위 과금
→ 사용자 수 과금 아님
→ 작업자: 무제한 무료
→ 추가 관리자: 10,000원/월
```

## 섹터별 가격 차등 근거

```
건물 < 산업인 이유:

건물 (Facility):
  적용 법령: 소방·전기·건축 중심
  점검 항목: 상대적으로 단순
  설비 종류: 제한적

산업 (Industrial):
  적용 법령: 산업안전보건법 + 화학물질관리법
            + 고압가스안전관리법 + 위험물안전관리법 등
            건물 대비 적용 법령 수 훨씬 많음
  점검 항목: 설비별·공정별·작업별 세분화
            건물 대비 2~3배 많음
  설비 종류: 크레인·프레스·압력용기·컨베이어 등
            고위험 설비 다수
  작업 유형: 밀폐공간·고소·화학물질 등 특별관리
  → 관리 복잡도가 건물 대비 압도적으로 높음

→ 산업 SaaS 가격이 건물보다 높은 것이 타당
→ 고객도 납득 가능
  "관리할 게 많으니 가격이 높은 게 당연하다"
```

## 섹터별 플랜 요금

| PRO | **149,000원/월** | 시설 단위 | BASIC + 작업자 배정 + 그룹 관리 + 기록 무제한 |
| PREMIUM | **249,000원/월** | 설비·모델 | PRO + 설비관리 + 위험예측 + 교육관리 |
| 커스터마이징 | **협의** | 맞춤 | 전체 커스텀 구성 |

### 산업 (Industrial)

| 플랜 | 가격 | 관리 단위 | 주요 기능 |
|------|------|---------|----------|
| BASIC | **99,000원/월** | 공정 단위 | 법령진단 자동 + 할 일 목록 + 스케줄 + 알림 |
| PRO | **199,000원/월** | 시설 단위 | BASIC + 작업자 배정 + 설비 기초 + 기록 무제한 |
| PREMIUM | **349,000원/월** | 설비·모델 | PRO + 설비관리 + 위험예측 + 교육관리 |
| 커스터마이징 | **협의** | 맞춤 | 전체 커스텀 구성 |

```
산업 섹터 가격 근거:
  건물 대비 적용 법령 수 압도적으로 많음
  점검 항목 2~3배
  고위험 설비 관리 포함
  → 관리 복잡도 완전히 다름
  → 가격 차등 완전히 합리적
```

### 건설 (Construction)

| 플랜 | 가격 | 특징 |
|------|------|------|
| 단일 플랜 | **149,000원/월** | 공정 + 작업 통합 / 분리 불가 |
| 커스터마이징 | **협의** | 대형 현장 맞춤 |

```
건설 SaaS 특징:
  공정·작업 통합 구조로 분리 불가
  건설 단건 진단(199,000)과 연계
  현장 단위 과금
```

## 커스터마이징 플랜

```
모든 섹터에 적용

대상:
  대형 사업장 (단일 플랜으로 해결 안 되는 규모)
  다시설 그룹사 (여러 사업장 통합 관리)
  특수 업종 (일반 플랜 미적용)

가격: 협의
구성: 필요 기능만 선택·조합
담당: TAI 담당자 직접 상담
```

## 핵심 원칙

```
1. SaaS 무료 없음
2. 법령진단 SaaS에 자동 포함 (별도 리포트 없음)
   → SaaS 자체가 진단 결과를 실행으로 보여줌
3. 섹터별 가격 차등 (확정)
   건물 BASIC 79,000 / 산업 BASIC 99,000
   → 적용 법령 수·점검 항목·관리 복잡도 반영
   → 건설 단일 플랜 (현장 특성)
4. 기능이 아닌 "관리 깊이" 기준 과금
5. 상시 할인 없음 (조건부 할인만)
6. 처음부터 제대로 된 가격
   → 지금 고객 0명 = 가격 정정의 최적 시점
```

## 겸직 안전관리자 타깃 가격 근거

```
대체 비용 비교:
  안전관리 대행기관: 월 150,000~300,000원
  중대재해 과태료 최소: 300만원
  → TAI 건물 BASIC 79,000원 = 대행비용의 1/2
  → TAI 산업 BASIC 99,000원 = 대행비용의 1/3

겸직자 시간 가치:
  월 3~5시간 절감 × 시급 15,000~20,000원
  = 월 45,000~100,000원 가치
  → 건물 79,000 / 산업 99,000 = 이 범위 안

핵심 메시지:
  "안전이 본업이 아닌 분들을 위해"
  "매달 뭘 해야 할지 시스템이 알려줍니다"
  "과태료 걱정 없이 본업에 집중하세요"
```

# PART 3. 연결 서비스 — 방향 확정, 세부 미정

## 서비스 본질

```
TAI 연결 서비스 = 거래 성사 플랫폼

수요자: 안전관리자 필요 / 설비 고장 수리 필요
공급자: 일감 필요
→ 서로 아쉬운 상태에서 시장에 나옴
→ TAI = 거래를 성사시키는 역할
→ 성사된 만큼 TAI가 수익을 가져간다

크몽·숨고와 다른 점:
  거래 후 → 기록이 TAI에 남아야 한다
  선임 → 선임계 제출 기록
  수선 → 수리 완료 기록
  → 기록 의무 자체가 플랫폼 Lock-in
```

## 과금 원칙

```
1. 거래 성사 시에만 수수료 발생
   → 견적 요청, 매칭 자체는 무료
   → 숨고의 실패 반면교사

2. 아쉬운 쪽(공급자)이 수수료 부담
   → 일감이 필요한 공급자가 더 아쉽다
   → 수요자(사업장)는 무료

3. 높은 수수료 + 전자계약 + 정밀 기록
   → 전자계약: 모두의싸인 연동
   → 기록: TAI에 자동 저장
   → 수수료의 정당성 확보

4. SaaS 비구독자도 연결 서비스 이용 가능
   → 초기 활성화 + 마케팅 채널
   → SaaS Lock-in은 기록에서 발생

5. 그레이드 구조 적용
   → 거래 규모에 따라 수수료 % 차등
   → 큰 거래 = 낮은 % + 높은 서비스
   → 작은 거래 = 높은 % + 자율
```

## 선임 연결

```
과금 방식: 부동산 모델 적용
  계약 성사 시 1회 수수료
  월 단가 × 배수 = 수수료

예시:
  월 100만원 비상주 선임 계약
  → TAI 수수료 100만원

  월 350만원 상주 안전관리자
  → TAI 수수료 350만원

그레이드: 계약 금액 기준
  소규모 (월 100만원 미만): 1.5개월치
  중규모 (월 100~200만원): 1개월치
  대형 (월 200만원 이상): 0.7개월치

전자계약: 모두의싸인 연동 (전 그레이드)
기록: 선임계 제출 + TAI 자동 저장
```

## 수선 연결

```
핵심 전략:
  소규모 단건 = 신뢰 축적 (씨앗)
  중·대형 계약 = 핵심 수익 (열매)
  → 소규모 없이 큰 거래가 올 이유 없음
  → 작은 거래로 신뢰 쌓기 → 큰 거래로 연결

그레이드 기준: 시장 거래 현실 반영 (초기 운영 후 확정)

  소규모:
    범위: 단건 수리
    수수료: 고정액 or 낮은 % (진입장벽 최소화)
    구조: 자율, 기본 기록
    목적: 플랫폼 유입 + 신뢰 축적

  중규모:
    범위: 설비 보수·교체
    수수료: 중간 %
    구조: 전자계약 + 기록
    목적: 실질 수익 시작

  대형:
    범위: 연간 유지보수 계약 / 대형 설비 교체
    수수료: 낮은 % (절대 금액은 큼)
    구조: 전자계약 + 정밀기록 + 에스크로
    목적: 핵심 수익 + 플랫폼 신뢰 증명

⚠️ 수수료 세부 %:
  시장 거래 데이터 수집 후 확정
  초기 시행 후 조정 가능
  (수수료 구조가 서비스 방식 자체를 결정하므로
   신중하게 시장 반응 보고 확정)

부품 가격 문제:
  표준 인건비 (협회 기준) + 이동비 (GPS 계산) 제공
  부품 가격은 계약서에 별도 명시 구조
  → 투명한 안내로 분쟁 예방
```

# PART 4. 안전교육 — 방향 확정

```
수익 우선순위 1위 (장기)
이유: 법정 의무 + 반복 발생 + 인원수 비례 + 기록 보존 의무

단계:
  1단계 (초기): 교육기관 연결 수수료
    → TAI가 인증 기관과 연결
    → 이수 기록 TAI에 자동 저장

  2단계 (자체 콘텐츠):
    → TAI 직접 온라인 교육 제공
    → 가장 마진 높은 구조
    → 이수 기록 TAI 자동 연동

교육 단가: 기관 협의 후 확정
```

# PART 5. 인앱 결제 — 방향 확정

```
수익 우선순위 3위

원칙:
  반복 기능 → SaaS에 포함
  건별 1회성 업무 → 인앱 과금

대상:
  관공서 자동 제출 (건당)
  문서 템플릿 (건당)
  전자계약 추가 건 (건당)
  팩스 자동발송 (건당)

크레딧 단어는 고객에게 노출 안 함
→ 내부 정산 단위로만 사용
→ 고객에게는 "건수"로 표시
```

# 전체 수익 우선순위

```
1. 안전교육     → 반복·법정·인원수 비례 (장기 최대 수익)
2. 연결 서비스  → 선임 + 수선 (성사 수수료)
3. 인앱 결제   → 건별 1회성
4. SaaS 구독   → 고정 반복 기반 수익
5. 법령진단    → 퍼널 (SaaS 전환 도구)
```
