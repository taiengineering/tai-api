# TAI Safe 확정 가격표 (Single Source of Truth)

> **최종 확정일:** 2026-05-13 (V4)
> **이 파일이 유일한 가격 기준입니다.** 다른 가격 문서는 히스토리 참고용.
> **V4 변경 사유:** 법령진단을 독립 상품("안전관리 설계서")으로 격상, SaaS와 동일 가격 체계 적용, SaaS 전환 크레딧 정책 신설

---

## 0. 핵심 원칙

### 과금 단위
- **SaaS: 시설 1개 기준 과금** (사업장이 아님)
- **법령진단: 1회 단건 과금** (독립 구매 가능)
- **관리자/작업자 등록: 무제한** (인원수 기반 과금 아님)

### TAI의 방식: "많이 넣으면 많이 나온다"
- **기능은 모든 플랜에서 동일합니다.**
- 플랜 간 차이는 **사업장 규모**입니다.
- 규모가 클수록 → 적용되는 법이 많아지고 → 해야 할 일이 다르게 산출됩니다.
- 결과를 인위적으로 제한하지 않습니다.

### 포지셔닝 (V4 변경)
- TAI = **법령 기반 산업안전 운영 플랫폼** (안전관리 SaaS가 아님)
- 법령진단 = **사업장 맞춤형 안전관리 설계서** (독립 구매 가능한 상품)
- SaaS = 설계서를 **자동 운영**하기 위한 **선택형** 운영 플랫폼

### 정책 방향 (V4)
```
SaaS를 쓰지 않아도 운영 가능
SaaS를 쓰면 훨씬 편함
```

### 판매 흐름 (V4 변경)
```
기존: 무료진단 → 유료진단 → SaaS (강제)
변경: 무료진단 → 유료 법령진단 (독립 상품) → SaaS (선택)
```

### 가격 구분 기준 (섹터별)
- **산업:** 상시근로자 수 (법적 의무 단계가 다름)
- **건물:** 연면적 (적용 법조항이 다름)
- **건설:** 공사금액 (적용 법조항이 다름)

### 법령 엔진
- "법개정 자동반영"이 아닌 **"개정된 최신법으로 진단"**이 정확한 표현입니다.

## 2-1. SaaS 전환 크레딧 정책 (V4 신설)

> 유료 법령진단 구매 후 **30일 이내** SaaS 가입 시

```
진단비 100% 크레딧 제공 → 첫 달 이용료 차감
```

예시: 법령진단 299,000원 구매 → 30일 내 SaaS 가입 → 299,000원 크레딧 지급 (첫 달 무료)

## 3. 연결 서비스 수수료 ⚠️ 가안 (미확정)

> **이 섹션은 가안입니다. 시장 반응을 보고 확정 예정.**
> 금지 용어: 소개비/소개수수료/인력소개/소개료 → 매칭 서비스료/플랫폼 이용료/성과 정산금

### 선임연결 (가안)

부담자: 공급자(대행기관/전문가)만 부담.

| 월 대행비 | 매칭 서비스료 | 산정 방식 |
|---|---|---|
| 50만원 미만 | **10만원** | 정액 |
| 50~100만원 | **15만원** | 정액 |
| 100만원 이상 | **첫 월 대행비의 15%** | 정률 |

### 수선연결 — TAI Fix (가안)

부담자: 공급자(정비업체)만 부담.

| 시공비 | 플랫폼 이용료 | 산정 방식 |
|---|---|---|
| 100만원 미만 | **5만원** | 정액 |
| 100~500만원 | **시공비의 8%** | 정률 |
| 500만원 초과 | **시공비의 5%** (최대 50만원) | 정률+캡 |
