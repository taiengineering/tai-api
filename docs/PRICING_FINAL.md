# TAI Safe 확정 가격표 (Single Source of Truth)

> **최종 확정일:** 2026-04-26
> **이 파일이 유일한 가격 기준입니다.** 다른 가격 문서는 히스토리 참고용.

---

## 0. 핵심 원칙

### 과금 단위
- **SaaS: 시설 1개 기준 과금** (사업장이 아님)
- **관리자/작업자 등록: 무제한** (인원수 기반 과금 아님)

### TAI의 방식: "많이 넣으면 많이 나온다"
- **기능은 모든 플랜에서 동일합니다.**
- 플랜 간 차이는 **등록할 수 있는 정보의 범위**입니다.
- 등록 범위가 넓을수록 → 적용되는 법이 많아지고 → 해야 할 일이 다르게 산출됩니다.
- 결과를 인위적으로 제한하지 않습니다.

### 법령 엔진
- "법개정 자동반영"이 아닌 **"개정된 최신법으로 진단"**이 정확한 표현입니다.

## 1. SaaS 구독 (월 정기과금)

### 건물(BUILDING) — 건물 1개 기준

> 기능은 동일. 면적 5,000㎡를 기준으로 적용되는 법조항이 달라집니다.

| 플랜 | DB 코드 | 월 요금 | 기준 |
|---|---|---|---|
| ~~간편관리~~ | ~~BUILDING_LITE~~ | ~~59,000원~~ | **삭제 (is_active=false)** |
| 정밀관리 | BUILDING_BASIC | **145,000원** | 5,000㎡ 이하 |
| 대형건물 | BUILDING_STANDARD | **249,000원** | 5,000㎡ 초과 (추가 법조항 적용) |
| Enterprise | BUILDING_CUSTOM | **협의** | 별도 커스터마이징이 필요한 경우 |

**삭제 사유:** 건물 진단 입력 구조가 FREE(8필드) / PAID(36필드) 2단계만 존재.
산업처럼 3단계(건물→공정→설비) 구분이 불가하므로 59K 플랜 유지 근거 없음.

> 건물+특수설비 → 공정까지 → 설비까지 — 단계별로 입력 범위가 확장됩니다.

| 플랜 | DB 코드 | 월 요금 | 등록 범위 |
|---|---|---|---|
| STARTER | INDUSTRY_STARTER_V2 | **79,000원** | 건물 + 특수설비 등록 |
| BUSINESS | INDUSTRY_BUSINESS_V2 | **149,000원** | + 공정까지 등록 (용접·도장·주조 등) |
| PRO | INDUSTRY_PRO | **249,000원** | + 설비까지 등록 (크레인·프레스·지게차 등) |

> 하도급 관리는 모든 플랜에서 제공됩니다. (소규모도 하도급 사용)

| 플랜 | DB 코드 | 월 요금 | 기준 |

## 3. 연결 서비스 수수료 ⚠️ 가안 (미확정)

> **이 섹션은 가안입니다. 시장 반응을 보고 확정 예정.**
> TAI는 대행기관이 아님. 대행기관·정비업체는 공급자(파트너).
> 금지 용어: 소개비/소개수수료/인력소개/소개료 → 매칭 서비스료/플랫폼 이용료/성과 정산금

### 선임연결 (가안)

부담자: 공급자(대행기관/전문가)만 부담. 수요자(사업장)는 무료 매칭.

| 월 대행비 | 매칭 서비스료 | 산정 방식 |
|---|---|---|
| 50만원 미만 | **10만원** | 정액 |
| 50~100만원 | **15만원** | 정액 |
| 100만원 이상 | **첫 월 대행비의 15%** | 정률 |

### 수선연결 — TAI Fix (가안)

부담자: 공급자(정비업체)만 부담. 수요자(사업장)는 무료 매칭.

| 시공비 | 플랫폼 이용료 | 산정 방식 |
|---|---|---|
| 100만원 미만 | **5만원** | 정액 |
| 100~500만원 | **시공비의 8%** | 정률 |
| 500만원 초과 | **시공비의 5%** (최대 50만원) | 정률+캡 |

## 4. 설치비 — 세팅 대행 (확정)

> **견적 기반.** 산업 BUSINESS·PRO 플랜에는 세팅 대행(유료) 옵션 포함.

```
설치비 = 기본 세팅비(20만원) + (설비 수 × 2~3만원/대)
```
