# TAI Safe 확정 가격표 (Single Source of Truth)

> **최종 확정일:** 2026-04-26
> **이 파일이 유일한 가격 기준입니다.** 다른 가격 문서는 히스토리 참고용.

---

## 0. 핵심 원칙

### 과금 단위
- **SaaS: 시설 1개 기준 과금** (사업장이 아님)
- **관리자/작업자 등록: 무제한** (인원수 기반 과금 아님)

### TAI의 방식: "많이 넣으면 많이 나온다"
- **기능은 모든 플랜에서 동일합니다.**
- 플랜 간 차이는 **등록할 수 있는 정보의 범위**입니다.
- 등록 범위가 넓을수록 → 적용되는 법이 많아지고 → 해야 할 일이 다르게 산출됩니다.
- 결과를 인위적으로 제한하지 않습니다.

### 법령 엔진
- "법개정 자동반영"이 아닌 **"개정된 최신법으로 진단"**이 정확한 표현입니다.

## 3. 연결 서비스 수수료 ⚠️ 가안 (미확정)

> **이 섹션은 가안입니다. 시장 반응을 보고 확정 예정.**
> TAI는 대행기관이 아님. 대행기관·정비업체는 공급자(파트너).
> 금지 용어: 소개비/소개수수료/인력소개/소개료 → 매칭 서비스료/플랫폼 이용료/성과 정산금

### 선임연결 (가안)

부담자: 공급자(대행기관/전문가)만 부담. 수요자(사업장)는 무료 매칭.

| 월 대행비 | 매칭 서비스료 | 산정 방식 |
|---|---|---|
| 50만원 미만 | **10만원** | 정액 |
| 50~100만원 | **15만원** | 정액 |
| 100만원 이상 | **첫 월 대행비의 15%** | 정률 |

- 지급 시점: 계약 성사 + 첫 월 서비스 완료 후
- 1회성 (매월 반복 아님)

### 수선연결 — TAI Fix (가안)

부담자: 공급자(정비업체)만 부담. 수요자(사업장)는 무료 매칭.

| 시공비 | 플랫폼 이용료 | 산정 방식 |
|---|---|---|
| 100만원 미만 | **5만원** | 정액 |
| 100~500만원 | **시공비의 8%** | 정률 |
| 500만원 초과 | **시공비의 5%** (최대 50만원) | 정률+캡 |

- 지급 시점: 작업 완료 확인 후

### 정산 방식 (가안)

- 초기: 공급자↔수요자 직접 거래 + TAI가 공급자에게 수수료 별도 청구
- 성장기: TAI 중간 정산 전환 (PG 경유)

### 미결 사항
- 공급자 단독 부담 vs 양쪽 분담 → 시장 테스트 후 결정
- 구간별 금액 적정성 → 공급자 파트너 피드백 반영
- 정산 시점 세부 규칙 → 서비스 운영 시작 후 확정

## 4. 설치비 — 세팅 대행 (확정)

> 안전관리자가 SaaS 초기 세팅을 직접 하기 어려운 경우, TAI가 세팅을 대행.
> **견적 기반** — 고정 가격표가 아님. 상대 크기(설비 수)에 따라 유동.
> **산업 BUSINESS·PRO 플랜에는 세팅 대행(유료) 옵션 포함.**

### 산정 공식

```
설치비 = 기본 세팅비 + (설비 수 × 설비당 단가)
```

| 항목 | 금액 | 포함 범위 |
|---|---|---|
| 기본 세팅비 | **20만원** | 법령진단 결과 반영, 시설 등록, 사용자 계정 |
| 설비당 추가 | **2~3만원/대** | 설비등록 + 점검항목 세팅 + 앵커 설정 |

### 예시

| 사업장 규모 | 설비 수 | 설치비 |
|---|---|---|
| 소형 건물 | 5대 | 20만 + 5×2만 = **30만원** |
| 중형 공장 | 15대 | 20만 + 15×3만 = **65만원** |
| 대형 공장 | 40대 | 20만 + 40×3만 = **140만원** |
| 건설 현장 | 10대 | 20만 + 10×3만 = **50만원** |

### 설치비 원칙
- SaaS 구독과 별도 — 설치비는 1회성, 구독은 월 반복
- 견적서에 설비 목록과 수량 명시 → 투명
- 무료 체험 기간(1개월)에 세팅 대행 포함 시 온보딩 성공률 극대화

## 8. 가격 변경 원칙

1. 가격은 런칭 후 올리기 매우 어려움 → 0고객 시점에 정확하게 설정
2. 이 문서 수정 → DB 동기화 → API 응답 확인 → 프론트 반영 순서
3. 가격 변경 이력은 `price_change_log` 테이블에 자동 기록
4. 금지 용어: 소개비/소개수수료/인력소개/소개료 → 플랫폼 이용료/연결 서비스료/매칭 서비스료/성과 정산금 사용

## 9. 건설 현장 가격 설정 근거

> "결과물을 즉시 사용이 가능하면 사게 됩니다.
> 즉시 사용이 아니면 가격이 낮아도 안 삽니다." — 심태왕 대표

건설 현장 특성:
- "안 걸리면 그만"이라는 인식이 강함
- 안전관리비가 별도 책정되어 예산이 있음
- 가격보다 "할 것인지 말 것인지" 의사결정 자체가 관건
- 하도급은 소규모도 사용 — 하도급 관리는 전 플랜 제공
- 공사금액으로 구분하지만 기능 차이는 없음 — 적용 법조항 차이
