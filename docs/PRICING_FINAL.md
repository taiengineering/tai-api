## 3. 기타 수익 모델 (가격 확정 전)

| 서비스 | 과금 방식 | 현재 상태 |
|---|---|---|
| 교육사업 | 별도 계약 | 최대 매출원 — 별도 기획 중 |
| 인앱 서비스 (자동신고/문서서식/라벨) | SaaS 포함 or 초과 과금 | SaaS에 기본 포함 |
| 수선연결 (TAI Fix) | 플랫폼 이용료 | 연결 서비스료로 표현 |
| 컨설팅 | 건당 견적 | 별도 기획 |
| 선임 연결 | 매칭 서비스료 | 별도 기획 |

> **금지 용어**: 소개비, 소개수수료, 인력소개, 소개료  
> **사용 용어**: 플랫폼 이용료 / 연결 서비스료 / 매칭 서비스료 / 성과 정산금 / 플랫폼 수수료

## 5. 가격 변경 원칙

1. 가격은 런칭 후 올리기 매우 어려움 → 0고객 시점에 정확하게 설정
2. 이 문서 수정 → DB 동기화 → API 응답 확인 → 프론트 반영 순서
3. 가격 변경 이력은 `price_change_log` 테이블에 자동 기록
