# Cursor 작업지시서: 단건결제 로그인 유도 구현

## 배경
유료 결제(단건/구독) 버튼 클릭 시 비로그인 상태인 사용자에게 로그인을 유도하되, 비회원 결제도 허용하는 흐름.

## 요구사항

### 1. 결제 버튼 클릭 시 알럿

유료 결제 버튼(단건결제/구독결제 모두) 클릭 시:
- 로그인 상태 확인
- 비로그인 시 알럿 표시:

```
┌─────────────────────────────────┐
│  회원 가입 후 결제하시겠습니까?    │
│                                 │
│  회원으로 결제하면 결제 내역 관리,  │
│  진단 결과 저장, 구독 관리 등      │
│  모든 서비스를 이용하실 수 있습니다. │
│                                 │
│  [가입 후 결제]  [비회원 결제]       │
└─────────────────────────────────┘
```

### 2. 버튼 동작

**[가입 후 결제]** 클릭 시:
- `taieng.co.kr` 로그인/회원가입 페이지로 이동
- 로그인 완료 후 결제 페이지로 자동 리다이렉트
- URL 파라미터로 결제 정보 유지: `?redirect_after_login=/payments/billing/pay&amount=...`

**[비회원 결제]** 클릭 시:
- 바로 결제 페이지로 이동 (현재와 동일)
- 결제 결과 페이지에서 "결과를 저장하려면 가입하세요" 재안내

### 3. 적용 대상 페이지

- `taieng.co.kr` 마케팅 사이트 가격 페이지 (pricing 섹션)
- `safe.taieng.co.kr` SaaS 내부 구독 페이지

### 4. 기술 요구사항

- 로그인 상태 확인: `localStorage` 또는 Supabase Auth 세션 체크
- 알럿 UI: Bootstrap5 Vuexy 모달 또는 SweetAlert2
- 리다이렉트 URL에 결제 파라미터(amount, product_type, plan_code, goodname) 보존
- TAI UI 원칙 준수: "지금 보지 않아도 되는 것은 보여주지 않는다"

### 5. 절대 금지
- 결제를 로그인 필수로 강제하지 않음 (비회원 결제 허용)
- 알럿이 방해가 되지 않도록 간결하게
