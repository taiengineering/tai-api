---

## 핵심 원칙 (불변)

```
자격 검증 완료 → 매칭 활성화
자격 검증 미완료 → 매칭 불가 (예외 없음)
```

검증되지 않은 공급자는 수요자에게 노출되지 않는다.
이것이 TAI 플랫폼의 신뢰 기반이다.

| 서비스 | 공급자 유형 | 검증 필수 |

| TAI Agent (수선연결) | 수선 업체 | ✅ |
| TAI Agent (대행연결) | 대행 업체·개인 | ✅ |

## 공급자 상태 정의

```
PENDING    → 가입만 한 상태 (자격 미제출)
SUBMITTED  → 자격 제출 완료, TAI 검토 대기
REVIEWING  → TAI 검토 진행 중
VERIFIED   → 검증 완료 ✅ → 매칭 가능
REJECTED   → 반려 (재제출 가능, 사유 통보)
SUSPENDED  → TAI 직권 정지 (분쟁·위반 등)
EXPIRED    → 자격 만료 (재검증 후 복구 가능)
```

**매칭 가능 조건:**
```sql
WHERE verify_status = 'VERIFIED'
AND is_active = true
```

## 상태별 권한

| 상태 | 프로필 작성 | 자격 제출 | 매칭 노출 | 거래 수락 |
|---|---|---|---|---|
| PENDING | ✅ | ✅ | ❌ | ❌ |
| SUBMITTED | ✅ | ✅ (추가) | ❌ | ❌ |
| REVIEWING | ✅ | ❌ | ❌ | ❌ |
| VERIFIED | ✅ | ✅ (갱신) | ✅ | ✅ |
| REJECTED | ✅ | ✅ (재제출) | ❌ | ❌ |
| SUSPENDED | ❌ | ❌ | ❌ | ❌ |
| EXPIRED | ✅ | ✅ (재제출) | ❌ | ❌ |

## 등록 플로우

```
[가입]
  → 기본정보 입력 (사업자번호·연락처·계좌)
  → PENDING 상태

[자격 제출]
  → 유형별 자격·면허·자격증 업로드
  → 수수료 정책 확인 및 동의 (이 단계에서 필수)
  → SUBMITTED 상태
  → TAI에 접수 알림 자동 발송 (SMS + 이메일)

[TAI 검토] (목표: 영업일 1~3일)
  → REVIEWING 상태
  → 승인: VERIFIED → "매칭 시작됩니다" 알림 발송
  → 반려: REJECTED → "재제출 요청 + 사유" 알림 발송

[매칭 활성]
  → 수요자 요청에 노출
  → 거래 수락 가능
```

## 검증 항목

### 공통 (전체 유형)
| 항목 | 방법 |
|---|---|
| 사업자번호 | 국세청 API 자동 조회 |
| 대표자명 | 사업자등록증 대조 |
| 연락처 | SMS 본인인증 |
| 계좌번호 | 1원 인증 (정산용) |
| 수수료 동의 | 동의 일시 DB 기록 (법적 근거) |

### 개인 (선임연결)
| 항목 | 방법 |
|---|---|
| 국가기술자격 | Q-Net API 자동 조회 |
| 협회 자격 (초·중·고·특급) | 자격증 사본 업로드 + 수동 승인 |
| 경력 | 재직/경력증명서 첨부 |
| 결격사유 | 자기신고서 |

### 업체 (수선연결)
| 항목 | 방법 |
|---|---|
| 업종 면허 (전기·소방·건설 등) | 서류 업로드 + 수동 확인 |
| 배상책임보험 | 보험증서 업로드 (필수) |
| 실적 | 계약서·준공확인서 첨부 (신규는 0건 허용, BASIC 등급 시작) |

### 업체·개인 (대행연결)
| 항목 | 방법 |
|---|---|
| 전문기관 지정서 | 고용노동부·소방청 등 서류 |
| 담당 서비스 범위 | 서비스 코드 선택 + 관련 자격 매핑 |
| 실적 | 완료 서류 (준공·검사결과서 등) |

---

## 협회 자격 검증 방침

현재 협회 API 미공개 → **수동 승인 방식**

| 단계 | 방식 |
|---|---|
| 초기 | 자격증 사본 업로드 → TAI 어드민 수동 승인 |
| 중기 | 협회 MOU 체결 → 일괄 조회 자동화 |

**입력 항목:** 자격 종류 / 등급 / 발급번호 / 유효기간 / 사본 파일

---

## 검증 만료 정책

| 자격 유형 | 재검증 주기 |
|---|---|
| 국가기술자격 (Q-Net) | 자격 취소 이벤트 발생 시 |
| 협회 자격 | 1년 주기 자동 확인 요청 |
| 면허 (전기·소방·건설) | 유효기간 30일 전 알림 |
| 배상책임보험 | 만료 30일 전 갱신 요청 |

만료 미갱신 시 자동으로 EXPIRED 상태 전환 → 매칭 중단.

---

## 수수료 고지 정책

- **자격 제출 단계**에서 수수료 구조 고지 및 동의 필수
- 동의 일시 DB 기록 (법적 분쟁 대비)
- 동의 없으면 SUBMITTED 전환 불가

## DB 설계 (핵심 테이블)

```
provider              → 공급자 기본정보 + verify_status
provider_credential   → 자격·면허 (개인·업체)
  ├── credential_type   -- 'national' | 'association' | 'license'
  ├── issuing_body      -- 발급기관
  ├── credential_name   -- 자격명
  ├── grade             -- 등급 (초급/중급/고급/특급/1급/2급)
  ├── credential_number -- 자격번호
  ├── issued_date       -- 발급일
  ├── expire_date       -- 만료일
  ├── file_url          -- 사본 파일
  └── verify_status     -- PENDING | APPROVED | REJECTED | EXPIRED
provider_performance  → 실적 (업체)
  ├── performance_type  -- 'external' | 'platform'
  ├── service_type      -- repair | agency | appointment
  ├── contract_amount   -- 계약금액
  ├── completed_at      -- 완료일
  └── file_url          -- 증빙서류
provider_insurance    → 보험 정보
  ├── insurance_type    -- 배상책임보험 등
  ├── expire_date       -- 만료일
  └── file_url          -- 보험증서
provider_grade        → 등급 (BASIC → PREMIUM)
```
