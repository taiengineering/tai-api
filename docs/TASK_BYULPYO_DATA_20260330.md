## 수집 4: 안전관리자·보건관리자 선임 기준 (별표 3·5)

### 출처
- 산업안전보건법 시행령 별표 3 "안전관리자를 두어야 하는 사업의 종류·규모와 안전관리자의 수"
- 산업안전보건법 시행령 별표 5 "보건관리자를 두어야 하는 사업의 종류·규모와 보건관리자의 수"

### CSV 형식
```
criteria_code,manager_type,industry_category,ksic_codes,min_workers,max_workers,required_count,qualification,legal_basis
SM-S-001,SAFETY,토사석광업,,50,499,1,"산업안전기사 또는 산업안전산업기사",산업안전보건법 시행령 별표 3
SM-S-002,SAFETY,토사석광업,,500,,2,"산업안전기사 또는 산업안전산업기사",산업안전보건법 시행령 별표 3
```

### 주요 항목
- manager_type: SAFETY(안전관리자) / HEALTH(보건관리자)
- max_workers: NULL이면 해당 min_workers 이상 전부
- 건설업은 공사금액 기준으로 별도 행 작성
