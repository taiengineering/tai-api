# Napkin AI 다이어그램 25종 생성 — Sonnet 작업 프롬프트

## 이 문서의 사용법

이 문서 전체를 Claude Sonnet 대화에 붙여넣고, "작업 시작해줘"라고 입력하면 됩니다.
Sonnet이 Chrome 브라우저의 napkin.ai에 접속하여 25종 다이어그램을 순차 생성합니다.

---

## [시스템 프롬프트]

당신은 TAI Engineering의 Napkin AI 다이어그램 제작 전문 에이전트입니다.

### 역할
- napkin.ai에 접속하여 산업안전 관련 다이어그램 25종을 순차 생성합니다.
- 각 다이어그램마다 텍스트를 입력하고, 생성된 옵션 중 최적의 것을 선택합니다.
- SVG와 PNG 두 가지 형식으로 다운로드합니다.

### 작업 순서

1. Chrome 브라우저에서 napkin.ai 접속 (이미 로그인 상태 가정)
2. "+ New Napkin" 클릭
3. 텍스트 입력 영역에 아래 프롬프트 텍스트를 붙여넣기
4. Napkin이 자동 생성하는 시각화 옵션 중 선택 기준에 따라 최적 선택
5. 다운로드 (SVG + PNG)
6. 파일명 변경 후 다음 번호로 이동
7. 25종 완료까지 반복

### 선택 기준 (Napkin이 4~6개 옵션을 제안할 때)

#### 유형 우선순위
- 프롬프트에 "플로우차트"로 지정된 항목 → 순서가 보이는 화살표/단계 옵션 선택
- "계층 트리"로 지정된 항목 → 상하 구조가 보이는 옵션 선택
- "비교표"로 지정된 항목 → 좌우 또는 표 형태 옵션 선택
- "타임라인"으로 지정된 항목 → 시간 순서가 보이는 옵션 선택
- "의사결정 트리"로 지정된 항목 → 예/아니오 분기가 보이는 옵션 선택
- "비포/애프터"로 지정된 항목 → 좌우 분할 비교 옵션 선택
- "매트릭스"로 지정된 항목 → 격자/표 형태 옵션 선택

#### 크기/방향 우선순위
- Tier 1 (기본): 가로형 16:9 선택
- 한글 텍스트가 가장 잘 보이는 옵션 우선
- 여백이 충분한 옵션 우선 (가장자리에 텍스트가 붙지 않는 것)
- 색상이 다양하고 구분이 명확한 옵션 우선

#### 피해야 할 옵션
- 텍스트가 겹치거나 잘리는 옵션
- 너무 단순해서 정보가 누락된 옵션
- 아이콘만 크고 텍스트가 안 보이는 옵션

### #25 안전관리 분산 구조도
**유형**: 비포/애프터
**파일명**: `napkin-25-distributed-safety`

```
TAI Safe 핵심 철학: 안전관리의 분산화

BEFORE (기존 방식)
안전관리자 1명에게 모든 업무 집중:
- 법령 확인 → 안전관리자
- 위험성평가 → 안전관리자
- 점검 실시 → 안전관리자
- 교육 진행 → 안전관리자
- 서류 작성 → 안전관리자
- 신고·보고 → 안전관리자
문제: 겸직자는 본업도 있음 → 안전업무 형식적 처리 → 요식행위 → 사고 위험

AFTER (TAI Safe 도입)
안전관리자는 관리·감독에 집중, 실행은 전 구성원 분산:
- 법령 확인 → TAI 법령엔진이 자동 판정
- 위험성평가 → 작업반장이 현장에서 직접 입력
- 점검 실시 → 작업자가 모바일 앱으로 5초 체크
- 교육 진행 → 시스템이 대상자 자동 선정 + 이수 추적
- 서류 작성 → 자동 생성 (PDF 원클릭)
- 신고·보고 → 자동 신고 (API 연동)

안전관리자 역할 변화:
변경 전: 모든 것을 혼자 하는 사람
변경 후: 할당하고 모니터링하고 이상에 대응하는 사람

결과: 실질적 안전관리 → 법적 증빙 완비 → 사고 예방 → 과태료 0원

TAI Safe는 안전관리를 1인의 부담에서 전원의 참여로 바꾸는 도구입니다.
```

### #16 위험성평가 5단계 프로세스
**유형**: 단계형
**파일명**: `napkin-16-risk-assessment-5step`

```
위험성평가 5단계 프로세스 (산업안전보건법 제36조)

1단계: 사전 준비
- 위험성평가 계획 수립
- 평가 대상 공정·작업 선정
- 평가팀 구성 (안전관리자 + 관리감독자 + 근로자 참여)

- 작업별 유해·위험요인 목록 작성
- 과거 사고 이력 분석

- 사고 발생 가능성 평가 (1~5점)

- 허용 가능 수준 기준 설정
- 허용 불가 → 감소 대책 수립
- 허용 가능 → 현 수준 유지 관리

5단계: 위험성 감소 대책 수립·실행
- 제거 → 대체 → 공학적 대책 → 관리적 대책 → 개인보호구
- 대책 이행 후 잔여 위험성 재평가
- 기록·문서화 (3년 보존)

핵심: TAI Safe에서 작업반장과 작업자가 현장에서 직접 입력 → 안전관리자가 검토·승인
```

### #17 작업중지 판단 기준 플로우
**유형**: 의사결정 트리
**파일명**: `napkin-17-work-stoppage-decision`

```
작업중지 판단 기준 의사결정 트리

판단 1: 기상 조건
- 풍속 10m/s 이상 → 타워크레인 작업중지
- 풍속 15m/s 이상 → 고소작업 전면 중지
- 강우량 시간당 1mm 이상 → 고소작업·굴착작업 중지
- 강설량 1cm 이상 → 옥외 작업 검토
- 폭염 (열사병 위험) → 14시~17시 옥외 작업 자제
- TAI Safe: 기상청 API 연동으로 자동 판정 + 알림

판단 2: 산업재해 발생
- 사망 사고 → 즉시 작업중지 + 고용노동부 보고
- 3일 이상 휴업 부상 → 작업중지 검토
- 중대재해 → 작업중지 + 현장 보존 + 보고

판단 3: 위험 발견
- 근로자 위험 신고 접수 → 즉시 해당 공정 중지
- 장비 이상 발견 → 해당 장비 사용 중지 + 정비 요청
- 구조물 균열·붕괴 조짐 → 즉시 대피 + 전면 중지

판단 4: 법적 명령
- 고용노동부 작업중지 명령 → 즉시 이행
- 해제 신청 후 승인 시까지 작업 불가

핵심: TAI Safe는 기상·신고·법령을 통합하여 작업중지 의사결정을 자동 보조
```

### #12 전문기관 위탁 vs 자체 선임 비교
**유형**: 비교표
**파일명**: `napkin-12-outsource-vs-inhouse`

```
안전관리전문기관 위탁 vs 자체 안전관리자 선임 비교

자체 선임
- 비용: 안전관리자 인건비 (연 3,000~5,000만원)
- 장점: 상시 현장 상주, 즉시 대응 가능, 현장 이해도 높음
- 단점: 인건비 부담, 겸직 시 전문성 부족 가능
- 적합: 300인 이상 대규모 사업장

전문기관 위탁
- 비용: 월 50~150만원 (규모에 따라)
- 장점: 전문 인력, 법령 변경 대응, 다양한 현장 경험
- 단점: 상시 상주 아님 (월 1~2회 방문), 현장 이해도 낮음
- 적합: 300인 미만 중소규모 사업장

TAI Safe 역할
- 선임 연결 서비스: 적합한 안전관리자 매칭
- SaaS 도구: 위탁이든 자체든 일상 업무를 시스템으로 관리
- 핵심: 사람이 바뀌어도 시스템은 유지됨

TAI는 대행기관이 아닌 도구 제공자. 대행기관은 TAI의 경쟁자가 아니라 파트너.
```
