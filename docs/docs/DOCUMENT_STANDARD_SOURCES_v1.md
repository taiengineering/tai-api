# 문서 표준 소스 지도 v1

> 작성일: 2026-08-22
> 목적: 대량 템플릿 제작 시 각 문서의 구성요소를 어디서 확정하는지 규정
> 근거: 외부 조사(국가법령정보센터·KOSHA) + 내부 자산(kosha_guide_body)

---

## 0. 결론 — 표준은 3계층으로 존재

| 계층 | 성격 | 소스 | 해당 |
|---|---|---|---|
| 1. 법정 별지 서식 | 양식이 법으로 고정 | 국가법령정보센터(law.go.kr 별표·별지) | 관공서 제출(D등급): 산재조사표·선임신고 등 |
| 2. KOSHA 표준 서식 | 공단 권고 표준 | KOSHA 서식자료실 + 위험성평가시스템(KRAS) | 위험성평가·관리규정 등(C등급) |
| 3. 필수 기재사항만 법정 | 양식은 자유 | KOSHA 권고 참고 + 법조문 | 점검일지·TBM 등(A등급) |

핵심: A등급 대부분은 "법이 요구하는 건 기록 유지이지 특정 양식이 아님" → 필수 기재항목만 지키면 TAI가 자유 구성 가능.

---

## 1. 외부 소스 (확인됨)

- 법정 별지 서식: 국가법령정보센터 — 법령별 별표·별지서식 다운로드.
- KOSHA 서식자료: oshri.kosha.or.kr 산업안전 서식자료.
- 위험성평가 표준문서: kras.kosha.or.kr — 실시규정(방법별 예시), 안전보건정보 조사표 한글서식 8종, 방법별 실시규정 예시 모음.

## 2. 내부 자산 (이미 확보)

- KOSHA GUIDE 1,039건 본문이 taieng DB `kosha_guide_body`에 추출·적재(1,031건 성공, 99.2%).
- KOSHA GUIDE는 서식 자체는 아니나 안전활동의 필수 구성요소·점검항목 근거 → 템플릿 구성요소 확정 시 내부 조회 가능(외부 재수집 불필요).

## 3. 즉시가용 A등급 → 표준 소스 매핑

| 문서군 | 표준 계층 | 소스 |
|---|---|---|
| 안전점검일지·체크리스트·설비점검(대부분) | 3. 기재사항만 | KOSHA 서식자료 참고 + 자유 구성 |
| TBM·보호구 | 3. 기재사항만 | KOSHA 권고 양식 |
| 위험성평가서·관리규정(C등급) | 2. KOSHA 표준 | KRAS 표준문서 |
| 산재조사표·선임신고(D등급) | 1. 법정 별지 | 국가법령정보센터 |

## 4. 구성요소 확정 워크플로

각 doc_id별로:
1. law_ref가 별지 서식 지정 → 국가법령정보센터에서 양식 확정(구성요소 100%).
2. KOSHA 표준 존재(위험성평가 등) → KRAS/서식자료 참고.
3. 둘 다 없음 → 필수 기재항목(내부 kosha_guide_body + 법조문)으로 구성.

판정 축은 document_forms의 기존 컬럼(law_ref·existing_data)에 얹어 문서별 표준 소스를 매핑.
