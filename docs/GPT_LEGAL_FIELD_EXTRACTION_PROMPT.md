## ▼▼▼ 복사 시작 ▼▼▼

당신은 한국 산업안전보건법 전문가입니다. 아래 29건의 산업안전 법정 문서에 대해, 각 문서의 **법적 필수 기재항목**을 해당 법령 원문(법률·시행령·시행규칙·별표·별지·고시·KOSHA GUIDE)에서 정확하게 추출해주세요.

## 작업 규칙

1. **반드시 법령 원문을 근거로** 기재항목을 추출해주세요. 추정하지 마세요.
2. 각 항목마다 **법적 근거 조항**을 명시해주세요 (예: "시행규칙 제26조 제3항", "별표4 제2호").
3. **법정 양식(별지 서식)이 있는 경우** 해당 별지 번호를 명시해주세요.
4. **법정 양식이 없는 경우** "법정양식 없음 — 기록 유지 의무만 규정"이라고 명시해주세요.
5. 법령에 기재항목이 구체적으로 나열되지 않고 "기록을 유지해야 한다"만 있는 경우, **KOSHA GUIDE나 고용노동부 지침에서 권고하는 항목**을 별도로 구분하여 추출해주세요.
6. **보존 기간**이 법령에 규정되어 있으면 반드시 포함해주세요.
7. **점검 주기**(일일/주간/월간/분기/반기/연간)가 법령에 규정되어 있으면 포함해주세요.
8. **작성자 자격 요건**이 있으면 포함해주세요 (예: "안전관리자 또는 안전관리전문기관").

## 출력 형식

**각 문서마다 아래 형식으로 출력해주세요:**

```
### [DOC-ID] 문서명

**법적 근거:** 법률명 제X조 (시행령 제X조, 시행규칙 제X조)
**법정 양식:** 있음 (별지 제X호 서식) / 없음
**보존 기간:** X년 (근거: 시행규칙 제X조)
**점검 주기:** 일일/주간/월간 등 (근거: 시행규칙 제X조)

| ...| ... | ... |

| No | 항목명 | 출처 |
|----|--------|------|

**비고:**
- (해당 문서에 대한 특이사항, 주의사항)
```

## 추가 요청

모든 29건 처리가 끝나면, 마지막에 아래 요약표를 출력해주세요:

```
## 전체 요약

| DOC-ID | 문서명 | 법정양식 | 법정항목수 | 권고항목수 | 보존기간 | 비고 |
|--------|--------|---------|-----------|-----------|---------|------|
| DOC-OSH-006 | 안전보건교육일지 | 없음 | 9 | 2 | 3년 | |
| ... | ... | ... | ... | ... | ... | ... |
```

그리고 요약표 이후에, **전체 결과를 아래 JSON 형식으로도 출력**해주세요. 이 JSON은 DB에 직접 입력됩니다:

```json
[
  {
    "doc_id": "DOC-OSH-006",
    "doc_name": "안전보건교육일지",
    "has_legal_form": false,
    "legal_form_ref": null,
    "retention_years": 3,
    "retention_law_ref": "시행규칙 제26조",
    "writer_requirement": "안전관리자 또는 관리감독자",
    "writer_law_ref": "시행규칙 제26조 제3항",
    "required_fields": [
      {
        "no": 1,
        "field_name": "교육일시",
        "field_key": "education_datetime",
        "law_ref": "시행규칙 별표4",
        "is_mandatory": true,
        "source": "법정"
      },
      {
        "no": 2,
        "field_name": "교육내용",
        "field_key": "education_content",
        "law_ref": "시행규칙 별표5",
        "is_mandatory": true,
        "source": "법정"
      }
    ]
  }
]
```

- `field_key`: 영문 snake_case로 항목을 식별하는 키 (DB 컬럼 매핑용)
- `is_mandatory`: true=법정필수, false=권고
- `source`: "법정" 또는 "KOSHA" 또는 "고용노동부지침"

## 주의사항

- **법령이 2024년 이후 개정된 경우, 최신 버전을 기준으로** 작성해주세요.
- **동일 법적 근거를 가진 유사 문서**(예: DOC-OSH-007과 DOC-OSH-038)는 기재항목이 동일할 수 있습니다. 이 경우에도 각각 별도로 출력하되, 비고에 "DOC-OSH-007과 동일 법적 근거"라고 표시해주세요.
- **법적 근거가 불분명하거나 찾을 수 없는 항목**은 "법적 근거 미확인 — 추가 확인 필요"라고 표시해주세요. 절대 추정으로 채우지 마세요.
- 29건 분량이 많으므로 그룹별로 나누어 출력해도 됩니다. "계속"이라고 입력하면 다음 그룹을 진행합니다.
