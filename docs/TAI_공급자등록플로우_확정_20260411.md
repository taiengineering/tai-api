# 공급자(용역회원) 등록 플로우 확정

> 작성일: 2026-04-11  
> 상태: 확정

---

## 핵심 원칙

**가입은 쉽게, 검증은 마이페이지에서**

```
가입 시 본인인증 요구 → 진입장벽 높음, 이탈 증가, 불필요 과금
마이페이지 검증 방식 → 이탈 최소화, 실사용자만 인증, 비용 최적화
```

---

## 등록 플로우

```
[1단계] 간편 가입 (진입 허들 낮춤)
  이름 / 이메일 / 비밀번호 / 전화번호
  → 가입 완료 (PENDING 상태)

[2단계] 마이페이지 → 검증 시작 (본인인증 여기서)
  ① 본인확인 (KG이니시스 통합인증 — 본인확인 기능)
     이름·생년월일 CI값 획득
  ② 사업자 정보 입력 (업체의 경우)
     사업자번호 → 국세청 API 자동 조회
  ③ 자격·면허 서류 업로드
     → SUBMITTED 상태

[3단계] TAI 검토 (1~3일)
  → VERIFIED → 매칭 활성화
```

## 가입 화면 안내 문구
```
"지금 바로 가입하고,
마이페이지에서 자격 인증을 완료하면
매칭이 시작됩니다."
```

## 마이페이지 미완료 배너
```
⚠️ 본인 인증을 완료해야 매칭에 노출됩니다.
[지금 인증하기]
```

## DB 상태값

| 단계 | verify_status | 본인인증 | 매칭 |
|---|---|---|---|
| 가입 완료 | PENDING | ❌ | ❌ |
| 본인인증+서류 제출 | SUBMITTED | ✅ | ❌ |
| TAI 검토 중 | REVIEWING | ✅ | ❌ |
| 검증 완료 | VERIFIED | ✅ | ✅ |

본인인증(이니시스)은 PENDING → SUBMITTED 전환 시 1회만 발생.
