## 산업 vs 건설 차이

| 항목 | 산업 | 건설 |
|---|---|---|
| 점검 기준 | 설비별 고정 | 공정별 가변 |
| 출입 기록 | 없음 | 필수 |
| 고위험 확인 | 없음 | 있음 |
| 사진 첨부 | 이상 시 선택 | 이상 시 필수 |
