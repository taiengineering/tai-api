# 05 — Human Review Flow Design

Check의 구조 관측을 **사람의 검토**로 연결하는 설계. 핵심: LEG의 자가평가(completeness, 선언한 근거 체인)와 Check의 독립적 구조 관측을 비교해, **불일치를 사람에게 보여주고 사람이 결정**한다. LEG도 Check도 스스로 결정하지 않는다.

## 1. 비교 로직 (host-side, 예정 위치: `verification/`)

각 의무에 대해 LEG 의무 데이터(completeness·의무유형, `obligation_id` 조인)와 Check 관측(`claim_status`·`chain_status`·`evidence_statuses`)을 결합한다. 검토 플래그 조건:

| 조건(Check 관측) | 의미 | 우선순위 |
|------------------|------|----------|
| `chain_status = EVIDENCE_CHAIN_BROKEN` | 선언한 근거 중 일부가 실재하지 않음 | 높음 |
| `evidence_status ∈ {REF_MISSING, NOT_ATTACHED}` | 근거가 선언됐으나 미보유 | 높음 |
| `claim_status = CLAIM_REF_MISSING` | 근거 체인이 알 수 없는 의무를 가리킴 | 중간 |
| `chain_status = NOT_DECLARED` | LEG가 근거 연결을 선언하지 않음 | 중간 |
| 빈 체인으로 `COMPLETE` | 근거 없이 완결 선언 | 중간 |
| 모두 `PRESENT/ATTACHED/COMPLETE` | 구조상 이상 없음 | 정보 |

**최우선 신호 = 자가평가 ↔ 구조 불일치:** LEG `completeness`가 높은데 Check가 `BROKEN` / 근거 미보유를 관측한 의무. "서류상 완결로 보이나 실제 근거 연결이 확인되지 않음" → 사람 검토 1순위.

## 2. UI 언어 — 침착한 운영 한국어 (필수 원칙)

고객/검토자 화면에 **기계 언어 노출 금지**(`BROKEN`, `REF_MISSING`, `runtime`, `chain` 등). 표현 도메인(presentation layer)을 통해 사람 언어로 변환한다. 패닉 표현("치명적 장애", "즉시 조치") 금지.

| 구조 관측(내부) | 사람 표현(예시) |
|------------------|------------------|
| chain BROKEN / 근거 미보유 | "근거 자료가 아직 확인되지 않았습니다" |
| claim REF_MISSING | "의무 항목과 근거의 연결을 확인해야 합니다" |
| chain NOT_DECLARED | "이 의무에 연결된 근거가 아직 없습니다" |
| 자가평가↔구조 불일치 | "완료로 보이지만 근거 확인이 필요합니다" |
| 모두 확인됨 | "근거가 모두 확인되었습니다" |

AI는 **설명을 보조**할 뿐(왜 검토가 필요한지 풀어쓰기), **모든 조치 결정은 사람**이 한다(Auto Governance 금지).

## 3. 검토자 동작 (모두 사람, 기록됨)

- **근거 확인 완료** 처리 (사람이 실제 자료 확인)
- **근거 요청** (담당자에게 자료 제출 요청)
- **예외 인정** (사유 기록)

어떤 동작도 Check/LEG가 자동 수행하지 않는다. 검토 결과는 TAI에 기록되며, 다음 진단/근거 변화 시 재관측(04)된다.

## 4. 표시 경로

- Check/LEG는 **구조화된 상태**만 emit한다. 사람용 운영 피드로의 재구성은 PRJ(프로젝션 엔진) 또는 host 표현 계층이 담당한다(LEG projection.boundary와 일관: 엔진은 텍스트를 만들지 않고, 표현 계층이 재구성).
- 검토 큐는 의무별로 (법령명·조문·의무유형[LEG 도메인]) + (근거 확인 상태[Check 구조]) + (사람 표현 문구)를 함께 보여준다. 의무 도메인 값은 `obligation_id` 조인으로 가져온다(03).

## 5. 제품 철학 정합 (45CM "운영 안심")

고객의 질문은 "내 의무에 문제 없나? 원인이 뭐지? 무엇을 해야 하지?" 이다.

- Check의 독립 구조 관측 = "근거 연결에 객관적으로 문제가 있는가?"에 답한다(LEG 자가평가와 분리된 신뢰 신호).
- 원인·조치 표현은 사람 언어로 제시하되, **결정과 책임은 사람**에게 둔다.
- 따라서 본 흐름은 "관제/자동판정"이 아니라 **사람의 운영 안심을 돕는 보조 신호**다.

## 6. 경계 체크리스트

| 항목 | 보장 |
|------|------|
| Check/LEG 자동 결정 | 없음 (사람이 결정) |
| 고객 화면에 기계 언어 노출 | 없음 (표현 계층 경유) |
| Check 상태값/계약 변경 | 없음 (기존 상태값을 표현으로 매핑만) |
| 비교·표시가 Check를 수정 | 없음 (host-side 소비) |
