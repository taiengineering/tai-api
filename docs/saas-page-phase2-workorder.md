## 1. 요금제 가격 불일치 [수정 필수]

**기준**: `docs/PRICING_FINAL.md` (tai-api dev)

### 건물(BUILDING) — 3티어로 수정

현재 페이지: STARTER 59K + PRO 249K + ENTERPRISE → **2티어 + 협의**
확정 가격표: 기본관리 59K + 정밀관리 145K + 대형건물 249K → **3티어**

```
STARTER → 기본관리 59,000원 (5,000㎡ 미만)
STANDARD → 정밀관리 145,000원 (5,000㎡ 이상)  ← 신규 추가
PRO → 대형건물 249,000원 (복합·특수건물)
ENTERPRISE → 별도 협의 (유지)
```

STANDARD 카드 추가 내용:
- 스타터 플랜 전체 포함
- 소방시설 자체점검 연동
- 승강기 검사 주기 관리
- 위반 위험 사전 알림

PRO는 STANDARD의 내용 + 석면·에너지 점검 + 법정 서식 자동 생성

### 산업(INDUSTRY) — 확인

현재: STARTER 79K + PRO 149K + BUSINESS 249K + ENTERPRISE
확정: STARTER 79K + BUSINESS 149K + PRO 249K + CUSTOM 협의

**주의**: 이름 순서가 다름. 현재 PRO=149K이지만 확정은 BUSINESS=149K, PRO=249K.
이름을 확정 가격표 기준으로 맞추거나, 금액만 맞으면 이름은 대표님 확인 후 결정.

### 건설(CONSTRUCTION) — 확인

현재: STARTER 145K + PRO 385K + ENTERPRISE
확정: STANDARD 145K + PREMIUM 385K + CUSTOM 협의

이름 매핑 확인 필요.

## 2. 섹션 구조 점검 [수정]

### 현재 문제: 안전관리자 기능 4개 + 총책임자 기능 4개 = 8개

작업지시서에서는 "핵심 기능 5개로 통합" 지시.

### 통합 방안:

```
기능① 작업지시·요청·승인 (현재 총책임자④) → 유지
기능② TBM 전자서명 (현재 안전관리자③) → 유지
기능③ 설비 점검 47초 (현재 안전관리자②) → 유지
기능④ 법령 자동 추적 (현재 안전관리자④) → 유지
기능⑤ 기상 작업중지 감시 (현재 총책임자③) → 유지
```

### 삭제 대상:

| 현재 섹션 | 처리 |
|---|---|
| "안전관리자를 위해" 헤더 | → "핵심 기능"으로 헤더 변경 |
| 안전관리자① (혼자 안 해도/자동 배분) | → **삭제** (섹션3 AS-IS/TO-BE와 중복) |
| "총책임자·경영진을 위해" 전체 섹션 | → **삭제** |
| 총책임자① (감사 대응) | → **삭제** (섹션3에서 충분히 전달) |
| 총책임자② (사고 통보) | → **삭제** |

이렇게 하면 8개 → 5개로 축소. 페이지 길이가 줄어서 전환률 상승.

## 3. 중대재해처벌법 섹션 위치 [이동]

현재: 기능 섹션 뒤에 별도 섹션
이동: **요금제 바로 위**로 이동

이유: 기능을 보고 나서 → "안 하면 어떻게 되나?" → 과태료/처벌 → "그럼 얼마야?" → 요금제. 이 흐름이 자연스러움.

## 4. 도입 과정 섹션 [보강]

현재: "이렇게 시작합니다" + 4단계
보강: "오늘 가입하면 내일 점검이 시작됩니다" + 각 스텝에 소요시간 명시

```
STEP 1  무료 법령진단 (3분)
STEP 2  SaaS 구독 시작 (5분)
STEP 3  작업자 초대 (10분)
STEP 4  첫 점검 완료 (당일)
```

하단에 세팅 대행 안내 추가:
"직접 세팅이 어려우시면 TAI가 대행합니다. (기본 20만원 + 설비당 2~3만원)"
