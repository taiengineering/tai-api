## 3. 핵심 발견

### TAI가 할 수 있는 것: 약 115건 (64%)

179건 중 X(범위 밖)를 제외하면 약 115건을 TAI가 자동화 가능.
이 중 30건은 SaaS 기본 포함(무료), 85건은 이용권(유료).

### TAI가 할 수 없는 것: 약 64건 (36%)

외부 전문기관이 해야 하는 것:
- 작업환경측정 (측정기관)
- 건강진단 (검진기관)
- 품질관리·시험 (시험기관)
- 정밀안전진단 (진단기관)
- 화학물질 등록·평가 (전문 컨설팅)
- 설비 검사 (검사기관)

→ 이것들은 TAI Fix(수선 연결)로 전문기관을 연결해주는 서비스로 전환 가능.

### 중복 문서 발견: 약 15~20건

OSH와 CON, SERA 간 동일 내용의 문서가 다른 ID로 수집됨.
예: OSH-015와 CON-011 (안전보건협의체 회의록)
→ 내부적으로는 하나의 템플릿으로 처리, 섹터별 라벨만 다르게.

## 4. 개발 우선순위 (수익 × 난이도 기준)

### Phase 1: 지금 바로 (난이도 S, 약 30건)

등급A 문서 전부. SaaS 기본 포함.
- 점검 체크리스트, 점검 기록부, TBM 일지, 안전일지
- 교육 기록부, 보호구 착용 점검기록
- 전기·승강기·가스·위험물 점검기록부
- 보일러 운전일지, 냉동기 점검기록부

→ inspections 데이터를 PDF 템플릿에 바인딩하면 끝.
→ 개발 기간: 1~2주 (템플릿 제작)

### Phase 2: 입력폼 추가 (난이도 A, 약 40건)

등급B 문서. 이용권 10매.
- 작업허가서 (고소/밀폐/화기/일반) → 4종을 하나의 폼으로
- 안전보건협의체 회의록
- 보호구 지급대장
- MSDS 교육기록
- 아차사고 보고서
- 비상훈련 기록
- 소방훈련 기록
- 하도급관리대장

→ 입력폼 설계 + 템플릿 제작
→ 개발 기간: 2~4주

### Phase 3: 핵심 로직 (난이도 B, 약 20건)

등급C 문서. 이용권 30매. 고단가 수익.
- 위험성평가서 ← 가장 큰 수익 잠재력
- 안전보건관리규정
- 안전보건관리체계 구축계획서 (중대재해법)
- 사고보고서
- 비상조치계획서
- 소방계획서

→ 법령엔진 + AI 초안 생성 로직 필요
→ 개발 기간: 1~2개월

### Phase 4: 관공서 연동 (난이도 C, 약 25건)

등급D 문서. 이용권 50매. 최고 가치.
- 산업재해 발생보고 자동제출
- 안전관리자 선임/변경/해임 신고
- 소방안전관리자 선임신고
- 전기안전관리자 선임신고
- 화학사고 신고

→ 관공서 API 공개 여부 확인 필요
→ 특허 0067716번 핵심 수익화
→ 개발 기간: 2~3개월

## 5. X등급(범위 밖) → TAI Fix 연결 기회

64건의 X등급 문서는 TAI가 직접 만들 수 없지만,
해당 서비스를 제공하는 전문기관을 연결해주는 것은 가능.

예시:
- 작업환경측정 → 측정기관 매칭 (TAI Fix)
- 건강진단 → 검진기관 매칭 (TAI Fix)
- 정밀안전진단 → 진단기관 매칭 (TAI Fix)
- 설비 검사 → 검사기관 매칭 (TAI Fix)

이것이 TAI Fix의 수익 모델과 연결됨.
"이 문서가 필요합니다 → TAI가 직접 못 만드는 것 → 전문기관 연결"
