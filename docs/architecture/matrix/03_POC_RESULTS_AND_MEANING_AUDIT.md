# MATRIX 증거·POC·의미 검증 — 수치와 의미의 구별

기준: 2026-10-13. 본 문서는 실행 증거의 **상한**을 명시한다. 아래 행 수는 승인된 관계 건수나 운영 기능 품질 지표가 아니다.

## 1. 시험 결과 계층

- SOURCE_ONLY: 실제 Git 소스/Blob과 특정 함수의 정적 계약 관찰. 제품 배포 동작 보증 불가.
- SYNTHETIC_FUNCTION: 합성 입력으로 기존 순수 함수 재실행. 실제 고객 입력/DB/LEG/HTTP와 별개.
- HUMAN_POC_PROPOSAL: 사람이 원천 발췌문을 보고 만든 관계. 자동 MATRIX가 산출한 출력이 아니다.
- SOURCE_EXACT_SUPPORTED: 원천 자체의 코드↔명칭 또는 식별자 병기를 확인. 다른 두 콘텐츠 사이의 검증관계와 별개.
- CROSS_SOURCE_VERIFIED: 서로 다른 실제 콘텐츠의 정확한 권위 ID, 원문 근거, 판본, 권리를 확인한 관계. WO-009 기준 0.
- LIVE_SERVICE_VERIFIED: 현재 공개 API에서 검색 응답의 identity를 통해 상세 조회·관계 카드를 확인한 것. WO-009 기준 0.

## 3. WO-009 표본과 원천

총 32개 참조 = 기존 공개 콘텐츠 7 + TAI 내부 작업/설비 레지스트리 항목 11 + TAI KSIC 매핑 참조 2 + KCSC·PubChem 등 외부 메타데이터 12.

이는 다음을 의미하지 않는다:
- 신규 공개 콘텐츠 25개 수집/DB 적재 완료.
- 현재 운영 TAI의 32개 상세 URL 정상 응답.
- 서로 다른 32개 콘텐츠 간 자동 관계 생성.
- KSIC/KCSC/CHEM/LEG 공식 매핑 확정.

표본 7개는 캐시/인덱스에 남은 사고 5개(S01~S05)와 공개 지식 2개(S06~S07)로, 현재 origin 응답을 관찰한 7건이 아니다.

## 6. 사람에게 중요한 실제 사례와 정정

### S01 — 지게차 포크 탑승/충돌
사고에서 지게차가 언급되며 사람이 포크에 탑승했다는 사실은 사고 문맥으로 읽을 수 있다. '포크에 올라타는 작업'을 정상적 표준 작업으로 신설하거나 TAI FORKLIFT=사업장 지게차 운용과 동일한 사실로 처리하면 안 된다. 사고에 대한 법적 의무 추론은 LEG 승인 밖이다.

### S02 — 주조기/취출로봇 끼임
사고 설명에 주조기와 로봇이 함께 나오더라도 서로 다른 설비 개념이다. 금형 조정과 도형제 도포도 서로 다른 수행 활동이다. 현재 시트에서 두 설비 후보의 대상 identity가 비어 동일한 조합으로 충돌하는 계약 결함이 있다. 저장소 edge_key 유일성과 실제 원천 ID 정합성을 먼저 설계해야 한다.

### S03 — 트럭 적재함 추락
적재함에서 내려오는 행위를 곧바로 가설비계 작업 또는 KCSC 시방서 작업이라고 결론 낼 수 없다. 사고유형으로 추락이 표시되는 것은 원천에서 확인 가능한 범위다.

### S04 — 로더가 밀던 폐지 더미와의 충돌
로더 자체에 부딪힌 사건이 아니라 **로더가 이동시킨 폐지 더미와 사람의 접촉**이다. 기계/행위/직접 접촉 대상/상해를 분리하지 않으면 위험원인 왜곡이 발생한다. 로더를 지게차로 동일화하지 않는다.

### S05 — 파쇄기 내 이물질 제거 및 끼임
파쇄기, 이물질 제거 활동, 끼임 사고는 문맥상 연결할 수 있다. 이것만으로 정기 정비, 작업 중지 의무, 특정 법령의무의 적용을 확정할 수 없다.

### KSIC / KCSC
굴착 활동과 KCSC 터파기 표제는 관련할 수 있지만 표준 코드와 현장 공정/작업은 같은 개체 ID가 아니다. KSIC 업종은 해당 업종 내 모든 설비의 소유·사용 증거가 아니다.

### 화학 (PubChem / MSDS)
CID와 SID는 구분하며 CAS 번호 하나로 MSDS 제조사 제품, 혼합물, 개정 판본, 재고 lot을 동일화하지 않는다. 공통 공개 물질 참고정보는 제품·사업장 호출과 분리한다.

### 공개 지식 ↔ LEG
지식 글에 법령명이 언급되었다는 것과 정확한 LEG law_id/article_id/clause_id 및 시행 버전이 연결된 것은 다르다. 지금은 특정 의무/처벌/법적 적용을 출력할 수 없다.
