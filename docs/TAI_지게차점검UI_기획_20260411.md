# 지게차 작업 전 점검 UI 시안

> 작성일: 2026-04-11  
> 상태: 시안 완성 (HTML 파일: tai_forklift_check_ui_html.html)
> 적용 위치: safe.taieng.co.kr 점검 실행 화면

---

## 시안 설계 원칙

```
1. 작업자가 5초 내 응답할 수 있는 단문형 체크 구조
2. 이상 선택 시 자동 경고 및 정비 연계
3. 누적 데이터 기반 위험도 상향 조정
4. 관리자 화면으로 즉시 전송 가능한 구조
```

---

## UI 구성

### 상단 정보 영역
```
현장: 대성정밀 1공장
설비: 지게차 / 3톤 전동식
작업자: 김작업
점검 주기: 매일 작업 전
현재 위험도: 중간
```

### 점검 항목 (5건)

| 번호 | 위험유형 | 항목 | 버튼 |
|---|---|---|---|
| 1 | 전도 | 타이어 상태 이상 없음 | 정상/이상/보류 |
| 2 | 충돌 | 경적 정상 작동 | 정상/이상/보류 |
| 3 | 충돌 | 브레이크 정상 작동 | 정상/이상/보류 |
| 4 | 추락 | 안전벨트 착용 상태 | 정상/이상/보류 |
| 5 | 협착 | 포크 손상 또는 균열 없음 | 정상/이상/보류 |

### 우측 사이드바
```
[실시간 결과 요약]
  완료 항목: 5 / 이상 항목: 1 / 위험 경고: 1

[자동 경고]
  경적 이상 탐지 → 정비요청 / 관리자알림 버튼

[누적 데이터 활용]
  최근 30일 경적 이상 4회
  타이어 정비 요청 2회 누적
  동일 작업자 누락 0건

[TAI 설계 포인트]
  5초 내 응답 구조
  이상 선택 시 자동 경고
  누적 기반 위험도 조정
  관리자 즉시 전송
```

## 연계 DB 테이블

```
inspection_sets         ← 설비별 점검 세트
inspection_set_items    ← 점검 항목 (67건 생성 완료)
form_submissions        ← 점검 결과 저장
corrective_actions      ← 정비 요청 연계
notifications           ← 관리자 알림
```
