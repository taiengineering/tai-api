# REPORT — WO-ANALYSIS-006 Obs-006 Analysis (법/시행규칙 분리 등장)

> Input: Obs-006 재확인(VALID, 2431494d), Observation Inventory(6be576e4).

## 1. Observation
Obs-006 — 같은 사안(같은 obligation_summary)이 모법과 시행규칙으로 나뉘어 각각 등장(VALID, 131건, 제조·건축·건설).

## 2. Evidence (조문 원문·행위 추적)

### E1 — 안전보건관리규정의 작성 (법 vs 시행규칙 원문)
- 산업안전보건법 §25(법): "사업주는 … 다음 각 호의 사항이 포함된 안전보건관리규정을 **작성하여야 한다**" — 작성 의무의 근거 + 포함 사항(관리조직·교육·작업장 안전 등).
- 산업안전보건법 시행규칙 §25: "① 법 제25조제3항에 따라 작성해야 할 **사업의 종류 및 상시근로자 수**는 별표2와 같다. ② 사유 발생일부터 **30일 이내**에 별표3의 내용을 포함하여 작성해야 한다" — 적용 대상 + 기한 + 서식.
- THEN 차이: 시행규칙만 `THEN_DEADLINE 30일 이내` 보유(법엔 없음). 법=근거/원칙, 시행규칙=대상·기한·양식.

### E2 — 기계설비유지관리자 선임 (법 vs 시행규칙 행위)
- 기계설비법(법) "선임 등": THEN_ACTION = 선임하여야 한다(APPOINT) + 신고하여야 한다(REPORT) + 확인하여야(INSPECT) — 선임·신고·확인 근거를 한 조문에.
- 기계설비법 시행규칙: 조문이 행위별로 분화 — "선임신고 등"(제출해야 한다=신고 절차/서식) + "선임"(선임해야 한다=선임 절차).
- 법=의무 근거(복합), 시행규칙=행위별 절차 분화.

## 3. Root Cause
- **Obs-006은 진짜 중복이 아니다.** 법과 시행규칙은 **서로 다른 층위**를 규정한다: 모법=의무의 근거·원칙·포함사항, 시행규칙=적용 대상·기한·서식·행위별 절차.
- 두 대표 사례 모두 동일: 시행규칙이 법에 없는 요소(30일 기한, 별표 서식, 대상 범위, 절차 분화)를 규정 → 둘은 다른 의무.
- **Root Cause 판정: 정상 동작(모법-하위법령 위임 구조).** 같은 사안명이 법·시행규칙에 병존하는 것은 법령 체계상 정상이며 진짜 중복이 아니다. Obs-004·005와 같은 '존재 ≠ 오류' 패턴.

## 4. Impact
- 조회/조립 로직: 정상(무영향) — 각 층위 조문이 별도 draft로 정당하게 존재.
- 표시: 같은 사안명이 법·시행규칙으로 두 번 보여 사람 눈에 중복처럼 보일 수 있으나, 내용은 다른 층위. 이는 표시/UX 인지 문제이지 데이터 중복 아님.
- 참고: Obs-002 병합과의 관계 — Obs-002는 (law_name 동일 + article 동일)의 중복만 병합했다. 법 vs 시행규칙은 law_name이 다르므로 애초에 Obs-002 병합 대상이 아니었고, 그래야 맞다(다른 의무이므로).

## 5. Conclusion
- Obs-006 = **정상 동작 확인 (진짜 중복 아님).** 법=근거, 시행규칙=절차/기한/서식 — 서로 다른 의무.
- **CHG 불필요(현재 Evidence 기준).** 같은 사안명 병존이 사용자에게 중복처럼 보인다면 표시/UX(층위 구분 표기) 논의이지 데이터 제거가 아니다 — 별도.
- 당위 판단('중복이니 제거') 하지 않음. 법/시행규칙 내용 차이를 사실로 확인.
