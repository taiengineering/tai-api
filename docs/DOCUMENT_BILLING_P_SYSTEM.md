## 1. 설계 원칙

### 왜 현금이 아닌 P인가

현금 44,000원 차감 → "4만4천원이 나갔네" → 다음에 망설임
P 440P 차감 → "440P 썼네" → 별 생각 없음

같은 금액인데 느끼는 무게가 다르다.
카드가 현금보다 쓰기 쉬운 것과 같은 원리.
P는 카드보다도 더 가벼운 심리적 화폐 역할을 한다.

### 왜 문서생성과 발송을 조합하는가

문서생성과 발송은 분리된 행위가 아니다.
안전관리자 입장에서는 "이 서류를 처리한다" = 생성 + 발송이 하나의 업무.
따라서 조합별로 가격이 다르게 책정되어야 한다.

### "의뢰"라는 행위

TAI는 도구가 아니라 "내 일을 대신 해주는 존재".
사용자가 하는 행위는 "의뢰".
버튼 텍스트, 화면 제목, 이력 — 모두 "의뢰"라는 단어를 사용한다.

## 2. P 충전 패키지

기준: 1P = 100원 가치 (구현 후 조정 가능)

| 이름 | P | 가격 | P당 단가 | 할인 |
|---|---|---|---|---|
| 라이트 | 500P | 49,000원 | 98원 | 2% |
| 스탠다드 | 1,200P | 99,000원 | 82원 | 18% |
| 프로 | 2,500P | 179,000원 | 72원 | 28% |
| 비즈니스 | 6,000P | 490,000원 | 82원 | 18% |

### SaaS 구독자 월간 보너스 P

| SaaS 플랜 | 월 보너스 |
|---|---|
| STARTER (79K) | 50P |
| BUSINESS (149K) | 150P |
| PRO (249K) | 300P |
| 건설 (145K~385K) | 150~300P |

보너스 룰: 이월 안 됨. 충전 P는 유효기간 1년.
보너스 목적: "이번 달 무료 P로 써보세요" → 습관화 유도 → 충전 전환.

### PG 결제 상품 등록

이니시스 결제 상품명 (PG 심사용):
- "TAI 문서 의뢰 서비스 이용료 49,000원"
- "TAI 문서 의뢰 서비스 이용료 99,000원"
- "TAI 문서 의뢰 서비스 이용료 179,000원"
- "TAI 문서 의뢰 서비스 이용료 490,000원"

→ 일반 상품 결제로 심사 통과
→ 내부적으로 P 충전 처리하는 것은 TAI 운영 로직
→ PG 승인 후에는 내부 과금 방식 자유

금지 단어 (PG 심사): "포인트", "코인", "충전금"
→ 대외적으로는 "서비스 이용료", 내부에서만 P로 관리

## 3. 과금 경계선 — 4단계 흐름

### STEP 1: 데이터 입력 — 항상 무료

점검 체크, TBM, 위험성 참여, 교육 이수 등.
SaaS 구독의 기본 가치. 이걸 막으면 데이터가 안 쌓이고, 데이터가 없으면 문서도 못 만든다.

과금: 0P (SaaS 구독료에 포함)

### STEP 2: 문서 미리보기 — 무료

"이런 문서가 나옵니다" 보여줘야 구매 전환이 일어난다.

과금: 0P

### STEP 3: 문서 생성 + 발송 — P 차감 (조합별)

"의뢰하기" 버튼 클릭 시 P 차감.
문서 등급과 발송 채널의 조합에 따라 가격이 다르다.

### STEP 4: 접수 확인·이력 — 무료

발송 완료 후 접수번호 저장, 이력 관리. SaaS 기본 기능.

과금: 0P

### 문서 등급

| 등급 | 설명 | 예시 |
|---|---|---|
| A | SaaS 기본 포함 (무료) | TBM일지, 점검기록, 안전일지 |

| C | 복잡 문서 자동생성 | 위험성평가서, 관리규정, 보고서 |

### 발송 채널

| 채널 | 원가 | 서비스 가치 |
|---|---|---|
| 다운로드 | 0원 | 기본 |

| 팩스 (솔라피) | 100원/장 | 노동 대체 (팩스 안 보내도 됨) |
| 등기우편 (포스트플러스) | ~3,000원 | 1시간 노동 대체 (우체국 안 가도 됨) |

### 조합별 가격표 (1P = 100원 기준)

|  | 생성만 (다운로드) | + 이메일 | + 팩스 | + 등기우편 |
|---|---|---|---|---|
| 등급A (점검·TBM) | 무료 | 무료 | — | — |
| 등급B (허가서 등) | 120P | 120P | 130P | 200P |
| 등급C (평가서 등) | 360P | 360P | 370P | 440P |

### 원화 환산 (프로 패키지 단가 72원 기준)

|  | 생성만 | + 이메일 | + 팩스 | + 등기우편 |
|---|---|---|---|---|
| 등급B | ~8,600원 | ~8,600원 | ~9,400원 | ~14,400원 |
| 등급C | ~25,900원 | ~25,900원 | ~26,600원 | ~31,700원 |

### 가격 포지셔닝

| 비교 대상 | 가격대 |
|---|---|

## 5. 발송 비용의 근거 — 가치 기반 가격

### 등기우편: 왜 +80P (≈8,000원)인가

안전관리자가 등기 1건 보내려면:

| 작업 | 시간 | 비용 |
|---|---|---|
| 문서 출력 | 5분 | 토너/용지 200원 |
| 봉투 준비·인쇄 | 5분 | 봉투 100원 |
| 우체국 이동 | 15~30분 | 교통비 2,000~5,000원 |
| 접수 대기·처리 | 10~20분 | — |
| 복귀 | 15~30분 | — |
| 등기번호 기록 | 5분 | — |
| **합계** | **최소 1시간** | **~30,000~43,000원** |

(안전관리자 시급 약 25,000~35,000원 + 교통비 + 우편요금)

TAI가 하는 것: 버튼 클릭 5초.
80P(≈8,000원)는 1시간 노동 + 이동 대체 가치.
원가(3,000원)가 아니라 대체 가치(30,000원+)의 1/4 수준.

### 팩스: 왜 +10P (≈1,000원)인가

팩스 원가는 100원이지만, 팩스기 찾기 + 번호 확인 + 전송 확인 + 기록 = 15분 노동.
10P는 이 노동 대체 가치의 최소 단위.

### 이메일: 왜 무료인가

원가 0원. 클릭 한 번. 추가 가치를 매길 이유 없음.
문서를 만들었으면 이메일 발송은 기본 서비스.

## 7. 안전장치

- 의뢰 전 반드시 미리보기 + 사용자 확인 (확인 없이 처리 절대 안 함)
- 발송 실패 시 P 자동 환불 (문서생성 P는 차감, 발송 P만 환불)
- 등기우편 발송 시 2차 확인 ("등기우편으로 발송합니다. 80P가 추가 차감됩니다")
- 발송 이력 영구 보관 (법적 증빙)
- 잔여 P 부족 시 충전 유도 화면 표시

## 10. 기존 등급D 폐지

기존 DOCUMENT_SERVICE_PLAN.md의 등급D(관공서 자동제출, 50매)는 폐지.

이유:
- 관공서 API 자동제출은 현실적으로 불가 (인증서, CAPTCHA)
- 실제 제출 채널은 팩스·이메일·등기우편
- 문서생성(등급C) + 발송(채널별 P)으로 분리하는 것이 정확

변경:
- 등급D 50매 → 등급C 360P + 발송 채널별 P
- 관공서 포털 직접 입력 → TAI에서 안내만 ("이 서류는 민원마당에서 직접 제출이 필요합니다")
