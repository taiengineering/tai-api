## 배경

사용자가 SaaS 플랜을 선택할 때 "뭘 골라야 할지 모르는" 문제 해결.  
TAI는 상담 서비스가 아니므로 "전문가 상담" 버튼은 불가.  
대신 **법령진단 결과 데이터 → 엔진이 자동으로 적합 플랜 추천** 구조.

### 사용자 경로 2가지

```
경로 A (대다수): 무료진단 → 결과 페이지 → 플랜 추천 → 결제
경로 B (소수):   pricing 직접 방문 → "뭘 골라야 하지?" → 진단 유도 → 경로 A 합류
```

### 데이터 소스

BE-08 API 호출: `GET /diagnosis/{diagnosis_id}/recommend-plan`

### 동작

1. 진단 결과 페이지 로드 시 BE-08 API 자동 호출
2. 추천 플랜 카드 렌더링 (recommended + reasons[])
3. comparison 블록 (과태료 vs 구독료 비교) 표시
4. "이 플랜으로 시작하기" → pricing.html#{plan_code} 앵커 이동 (또는 결제 페이지)
5. "다른 플랜도 보기" → pricing.html 이동

### 디자인 가이드

- 카드: 흰색 배경, border-top 4px #0f172a, 라운드 18px, 그림자
- ★ 추천 뱃지: 네이비 배경 + 흰색 텍스트, 카드 상단 좌측
- reasons: 체크 아이콘(✓) + 텍스트, 간결하게
- 비교 블록: 라이트그레이 배경, 가격 볼드
- CTA 버튼: btn-navy 스타일 (사업주 페이지와 통일)

## 기술 참고

### API 호출 패턴

```javascript
// 진단 결과 페이지에서
const diagnosisId = new URLSearchParams(location.search).get('id');
if (diagnosisId) {
  fetch(`${API_BASE}/diagnosis/${diagnosisId}/recommend-plan`)
    .then(r => r.json())
    .then(data => renderPlanRecommendation(data))
    .catch(() => {
      // 추천 실패 시 → "다른 플랜 보기" 링크만 표시
    });
}
```

### 플랜 추천 없는 경우 (fallback)

- 진단을 받지 않은 사용자가 결과 페이지에 직접 접근
- API 오류
- → 추천 블록 숨기고, "무료 진단을 먼저 받아보세요" 안내
