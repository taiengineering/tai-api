## 1. 핵심 원칙

### 하나의 폼, 동일한 입력
- 무료든 유료든 **같은 폼**으로 같은 데이터를 입력받는다.
- 차이는 "입력 필드 수" (INDUSTRY) 또는 "가격" (BUILDING/CONSTRUCTION)에서만 발생.
- 결과를 인위적으로 제한하지 않는다. 엔진은 받은 데이터로 최선의 결과를 낸다.

### 가격 자동 판정 (BUILDING / CONSTRUCTION)
- 사용자가 가격을 선택하지 않는다.
- 입력 데이터(면적/공사금액)로 **자동 판정**하여 안내한다.
- 1단계 구매 후 상위 기준 감지 시 **추가금 결제**를 안내한다.

### TAI UI 원칙
> "지금 보지 않아도 되는 것은 보여주지 않는다."

### 건설 현장 구매 판단 구조
> "결과물을 즉시 사용이 가능하면 사게 됩니다.
> 즉시 사용이 아니면 가격이 낮아도 안 삽니다." — 심태왕 대표

## 2. 섹터별 tier 구조

### BUILDING (건물)

```
FREE (8필드) → PAID (28필드 추가) = 총 36필드
입력 필드: 소형/대형 동일
가격: 면적 자동 판정
```

| 등급 | 가격 코드 | 금액 | 기준 |
|---|---|---|---|
| 무료 | BUILDING_FREE | 0원 | — |
| 소형 | BUILDING_V2 | 99,000원 | 연면적 5,000㎡ 미만 |
| 대형 | BUILDING_LARGE_V2 | 249,000원 | 연면적 5,000㎡ 이상 |

**자동 판정 로직:**
```
주소 입력 → 건축물대장 API → total_floor_area 자동 조회
if total_floor_area >= 5000: 가격 = 249,000원
else: 가격 = 99,000원
```

### CONSTRUCTION (건설)

```
FREE (4필드) → PAID (22필드 추가) = 총 26필드
입력 필드: 기본/종합 동일
가격: 공사금액 자동 판정
```

| 등급 | 가격 코드 | 금액 | 기준 |
|---|---|---|---|
| 무료 | CONSTRUCTION_FREE | 0원 | — |
| 기본 | CONSTRUCTION | 145,000원 | 공사금액 50억 미만 |
| 종합 | CONSTRUCTION_PREMIUM | **299,000원** | 공사금액 50억 이상 |

**자동 판정 로직:**
```
project_amount 입력
if project_amount >= 5,000,000,000: 가격 = 299,000원
else: 가격 = 145,000원
```

**50억 분기점 근거:**
- 중대재해처벌법 직접 적용
- 안전관리자 선임 의무 발생
- 안전보건총괄책임자 선임 기준

### INDUSTRY (산업)

```
FREE (4필드) → PAID1 (+13필드) → PAID2 (+9필드) → PAID3 (+12필드)
입력 필드: 등급별 다름 (누적)
가격: 사용자 선택
```

| 등급 | 가격 코드 | 금액 | 추가 입력 영역 |
|---|---|---|---|
| 무료 | INDUSTRY_FREE | 0원 | 주소·업종·인원·면적 |
| 기본 | INDUSTRY_V2 | 79,000원 | +위험물·화학물질·보일러 등 |
| 정밀 | INDUSTRY_STANDARD | 149,000원 | +공정 (용접·도장·주조 등) |
| 종합 | INDUSTRY_PREMIUM | 249,000원 | +설비 (크레인·프레스·지게차 등) |

## 3. FREE 필드 구성

| 섹터 | FREE 필드 |
|---|---|
| BUILDING | 주소, 연면적, 지상층수, 지하층수, 용도, 건축연도, 주구조, 근로자수 |
| CONSTRUCTION | 현장주소, 공사금액, 투입인원, 공사기간 |
| INDUSTRY | 사업장주소, 업종, 근로자수, 연면적 |

**공통: 주소 검색은 모든 섹터 FREE에 포함** → 건축물대장 자동 조회 트리거

## 4. 업그레이드 프로세스

### BUILDING + CONSTRUCTION 공통 플로우

```
┌─ 1단계: 소형/기본 구매 ──────────────────────────┐
│  사용자가 유료 진단 결제 (99K / 145K)              │
│  동일한 입력 폼으로 데이터 입력                     │
│  엔진 실행 → 결과 제공                             │
└──────────────────────────────────────────────────┘
                    ↓
┌─ 2단계: 상위 기준 감지 ──────────────────────────┐
│  BUILDING:     면적 ≥ 5,000㎡ 감지                │
│  CONSTRUCTION: 공사금액 ≥ 50억 감지               │
│                                                  │
│  "이 사업장은 대형건물(5,000㎡ 이상)입니다."        │
│  "더 정확한 진단을 위해 대형 진단이 필요합니다"     │
│  추가 결제: 150K (BUILDING) / 154K (CONSTRUCTION) │
│  [추가 결제하기]  [현재 결과로 유지]                │
└──────────────────────────────────────────────────┘
                    ↓
┌─ 3단계: 업그레이드 완료 ─────────────────────────┐
│  추가 결제 완료 → 동일 데이터로 엔진 재실행        │
│  대형 기준 법령 추가 적용 → 결과 업데이트           │
└──────────────────────────────────────────────────┘
```

### 업그레이드 가격

| 섹터 | 1단계 | 2단계 | 추가금 |
|---|---|---|---|
| BUILDING | 소형 99K | 대형 249K | **150,000원** |
| CONSTRUCTION | 기본 145K | 종합 299K | **154,000원** |

### 업그레이드 감지 시점

| 시점 | 동작 |
|---|---|
| **입력 중** (주소/금액 입력 시) | 즉시 안내: "대형건물입니다. 대형 진단이 필요합니다" |
| **결과 확인 후** | 결과 페이지에서 업그레이드 안내 표시 |
| **과거 구매 건** | 마이페이지에서 업그레이드 버튼 제공 |

### INDUSTRY는 해당 없음

INDUSTRY는 입력 필드 자체가 다르므로 업그레이드가 아닌 **등급 선택** 방식.
처음부터 사용자가 등급을 고른다.
