1. **폐업 횟수 확정** — 세무서에서 법인+개인 전체 건수 확인 필요
   - 홈택스에서 법인은 안 나옴 (법인 사업자번호 기반이라)
   - 파산 종결 법인은 홈택스 온라인 조회 안 될 수 있음
   - → 관할 세무서 전화해서 확인 필요

2. **면책결정문 재발급** — ecfs.scourt.go.kr에서 신청
   - 전자소송 사건이면 온라인 발급 가능
   - 아니면 방문/우편 수령 (3~5일)
   - 마감일(5/7) 감안하면 이번 주 안에 신청 필수

3. **법인 폐업사실증명원 발급** — 파산 법인이라 온라인 조회 안 됨
   - 사업자번호는 알고 있으나 홈택스에서 서치 안 됨
   - 관할 세무서 전화/방문 필요
   - 안 되면 법인등기부등본(폐쇄)으로 대체 (주관기관 확인 필요)

4. **결제 페이지 구성** — 개발 창에서 처리 필요
   - 이니시스 카드심사 진입 위한 필수 선행과제

5. **서울지식재산센터 전화** — 02-2222-3860
