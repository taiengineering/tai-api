## 실행 내용

### 1. 조문 코드값 현황 확인
```
전체 10,974 조문:
  ✅ 법제처 공식 조문키 (9,796건, 89.3%) - 이미 저장됨
  🟡 NFTC/NFPC 생성키 (1,178건, 10.7%) - 현재 상태 유지
```

조문 코드값이 이미 대부분 저장되어 있어 추가 수집 불필요.

법제처 공식 조문키 예시:
- `0001000` = 제1장 총칙
- `0001001` = 제1조(목적)
- `0004021` = 제4조의2(지방자치단체의 책무)
- `0038001` = 제38조(안전조치)

### 2. 매핑 테이블 생성
```sql
CREATE TABLE rule_article_mapping (
  rule_id TEXT,
  law_id UUID REFERENCES law_master(id),
  article_id UUID REFERENCES law_article(id),
  article_internal_key TEXT,  -- 안정 키
  mapping_source TEXT,
  confidence_score NUMERIC,
  ...
)
```

### 3. 자동 매핑 실행 (정규식 기반)
```
패턴 추출:
  "제N조"    → article_no
  "제N조의M" → article_no + article_sub_no

매칭 기준:
  (law_name, article_no, article_sub_no)
  → law_master + law_article 조인
```
