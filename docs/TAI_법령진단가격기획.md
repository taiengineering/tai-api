# TAI 법령진단 및 SaaS 가격/구조 전략 정리

> 작성일: 2026-04-10
> 목적: 서비스별 가격 구조 및 전환 전략 확정

---

## 1. 전체 전략 방향

TAI는 단일 상품 구조가 아니라 다음 흐름으로 설계됨:

```
FREE → 진단 → 유료 진단 → SaaS → 실행/운영
```

**핵심 원칙:**
- 진단 = 고객 유입 및 문제 인식
- SaaS = 실제 수익 모델
- 프리미엄 = SaaS 전환 유도 장치

---

## 2. 서비스별 구조

### 2.1 건설 (Construction)

| 항목 | 내용 |
|---|---|
| 구조 | FREE → 단일 유료 상품 |
| 가격 | 유료: 199,000원 |
| 특징 | 선택 구조 없음 / 즉시 결제·즉시 대응 / 점검 항목 생성 포함 (실행형 진단) |
| 포지션 | "현장 대응용 도구" / "감독 대응 및 제출용 리포트 생성" |

---

### 2.2 시설 (Facility)

| 단계 | 가격 | 역할 |
|---|---|---|
| FREE | 0원 | 유입 |
| 베이직 | 49,000원 | 법령 확인 / 선임·점검·신고 리스트 / PDF 리포트 |
| 상위 | 99,000원 | 전체 결과 공개 / 실행 필요 항목 확인 / 결심 단계 |
| 최고단 | 149,000원 | 실무자 활용 단계 / 연결(선임·수선) 진입 |

---

### 2.3 산업 (Industrial)

| 단계 | 가격 | 역할 |
|---|---|---|
| FREE | 0원 | 유입 |
| 베이직 | 79,000원 | 법령 이해 |
| 상위 | 149,000원 | 전체 확인 및 실무 판단 |
| 프리미엄 | 249,000원 | SaaS 진입 전 단계 / 전환 유도 역할 |
| SaaS | 월 79,000원 | 점검 항목 생성 / 일정 자동 생성 / 작업자 배정 / 운영 및 데이터 축적 |

---

## 3. SaaS 구조

| 항목 | 내용 |
|---|---|
| 가격 | 월 79,000원 |
| 역할 | 유일한 "실행" 기능 제공 / 반복 수익 구조 핵심 |

**핵심 원칙:**
- 점검·실행 기능은 SaaS에서만 제공
- 진단 서비스에서는 제공하지 않음

---

## 4. 가격 구조 전략

```
시설:  49 → 99 → 149
산업:  79 → 149 → 249 → SaaS(79/월)
건설:  199 (단일)
```

**핵심 전략:**
- 약 2배 단위 상승 구조
- 고민 없이 업셀 가능
- SaaS로 자연스럽게 유도

---

## 5. 서비스별 포지셔닝

| 서비스 | 포지션 | 특징 |
|---|---|---|
| 건설 | "지금 바로 대응" | 빠른 결제 / 즉시 사용 |
| 시설 | "관리용 진단" | 중간 난이도 |
| 산업 | "운영 시스템 진입" | 가장 깊은 구조 |

---

## 6. 핵심 설계 원칙

1. 가격으로 설득하지 않는다
2. 구조로 결제하게 만든다
3. SaaS만이 실행 기능을 가진다
4. 프리미엄은 전환용 상품이다
5. 건설은 단일 상품으로 간다

---
