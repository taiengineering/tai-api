## 🔴 당장 맘에 안 드는 것 (치명적 Gap)

### ① 주기가 생성됐는데 "할 일"이 없다
work_schedules 156건이 전부 source_type = MANUAL. 법령엔진이 factory_diagnosis_results에 진단 결과를 쌓았지만, 그것이 work_schedules로 연결되는 파이프가 없다.  
안전관리자 입장에서는 "법적으로 뭘 해야 하는지"는 진단 결과에 있는데, 그게 오늘 캘린더에 안 뜬다.  
**→ 진단→일정 자동생성 연결이 끊겨 있음**

### ② work_assignments 1,161건이 READY인데 담당자가 없다
전체 1,161건 중 담당자가 배정된 건 90건(8%)뿐. 나머지 1,071건은 배정 없이 READY 상태로 쌓여 있다.  
안전관리자가 이 화면을 보면 "이걸 내가 다 해야 하나?"라는 공포감이 먼저 온다.  
TAI Safe의 철학인 "배분"이 구조만 있고 실제 배분은 비어 있는 상태.

### ③ 점검표가 껍데기다
inspection_sets 296건인데 inspection_set_items는 0건. 점검 일정이 잡혀 있어도 "뭘 점검하라는 건지" 항목이 없다.  
안전관리자가 점검을 나가면 빈 화면을 보게 된다.  
safety_templates도 2개에 항목 7개 수준으로 사실상 미구축.

### ④ 알림이 전혀 발송되지 않는다
notifications 0건, notification_templates 0건.  
D-7, D-3, 당일 알림이 설계는 되어 있지만 (notification_settings 42건 존재) 실제 발송 기록이 없다.  
안전관리자가 시스템을 쓰는 이유가 "잊지 않기 위해서"인데, 잊었을 때 아무도 알려주지 않는다.

## 🟠 문제인 것 (구조적 결함)

### ⑤ 법령엔진 결과가 안전관리자에게 "번역"되지 않는다
factory_diagnosis_results에는 rule_count 248건(제조), 187건(건축) 수준의 적용 결과가 있다. 그런데 안전관리자가 이걸 볼 수 있는 화면이 없다.  
"우리 현장에 산업안전보건법 몇 조 몇 항이 걸리고, 그 중 이번 달 마감이 몇 개다"를 한 줄로 보여주는 대시보드가 없다.  
법령 진단 결과는 내부 엔진 결과일 뿐, 관리자 화면에서 소비되지 않고 있다.

### ⑥ 위험성평가가 없다
risk_assessments 0건. 현행 산안법에서 위험성평가는 연 1회 이상 의무.  
이게 TAI Safe에 아예 붙어 있지 않으면, 안전관리자 입장에서 "이 시스템이 법적 의무를 커버하는가?"라는 의구심이 생긴다.

### ⑦ TBM이 0건
tbm_meetings 0건. 건설현장에서 TBM은 매일 해야 하는 법적 의무에 가깝다.  
구조는 있는데 사용이 전혀 없다는 건 UX 진입장벽이 있거나 모바일 화면이 없다는 뜻.

### ⑧ 교육이 배정되지 않는다
education_assignment 0건. 신규입사자 안전교육, 특별교육, 정기교육 모두 법적 의무인데 배정 기록이 없다.

## 🟡 있으면 좋을 것 (안전관리자가 실제로 원하는 것)

### ⑨ "오늘 나한테 걸리는 것" 하나짜리 뷰
법령 수백 개, 일정 156개, 점검 296개가 있어도 안전관리자는 "오늘 뭐 해야 해?"만 본다.  
오늘 마감 / 3일 내 마감 / 이번 달 마감 세 줄이면 충분. 지금은 그 화면이 없다.

### ⑩ "이상 발생 → 조치 → 완료" 흐름의 단절
defects, corrective_actions 테이블은 있지만 각각 연결이 없고 데이터도 없다.  
안전관리자가 현장에서 이상을 발견했을 때 → 사진 첨부 → 조치 지시 → 완료 확인까지 한 흐름으로 처리하는 화면이 없다.

### ⑪ 보고서 자동 생성
document_form_master 63건이 있는데 form_submissions 0건.  
서식은 있는데 아무도 쓰지 않는다. "산업안전보건법 제57조 보고서를 버튼 하나로"가 핵심 가치인데, 현재는 서식 목록만 존재.

### ⑫ 모바일 작업자 앱 부재
지게차 점검 UI를 만들었지만, 실제로 작업자가 쓸 모바일 화면이 없다.  
tbm_meetings 0건인 이유가 여기 있다. 안전관리자가 배분하고 싶어도, 작업자가 받을 화면이 없으니 결국 혼자 다 한다.

## 정리: 지금 TAI Safe의 위치

```
법령 진단 (완성 70%)
    ↓ ← 여기서 끊김
일정 자동생성 (껍데기만)
    ↓ ← 연결 안됨
배분/위임 (구조만 존재)
    ↓ ← 실사용 0건
실행/점검 (점검 항목 없음)
    ↓ ← 미구축
알림/에스컬레이션 (발송 0건)
    ↓ ← 미작동
보고서 자동화 (서식만 존재)
```

## 가장 빠른 가치 폭발 지점

**"법령 진단 결과 → work_schedules 자동 생성 → 담당자 배정 → D-3 알림 발송"** 이 파이프 연결.  
이것만 살아도 안전관리자가 "이 시스템이 나 대신 뭔가를 하고 있다"는 체감이 생긴다.

## 세션 구조 현황
- 각각의 역할을 준 창들이 프로젝트에 포함됨
- 법령엔진만 다루는 별도 창 신규 생성
- 메일함 10건 수신 확인 (문의/계약/점검/교육 등 다양한 수요)
