## Deliverable gate for each unique form
1. Record identity: unique canonical candidate, original research IDs, topic relationships/variants and non-duplicate rationale.
2. Audience and purpose: author, approver, consumer, trigger, prerequisites, output, archival and exceptions.
3. Evidence/source: precise original URL + attachment ID, observed original fields (source citation/page), independent proposed fields, permission to redistribute original, current law and LEG relation. Empty or unverified values are blockers.

5. File specification: distinct HWPX/DOCX/XLSX/PDF plans; Excel sheets/cell groups/formulas/print area, Word/HWPX sections/tables/page breaks, PDF print/readability, accessible and font-safe design.
6. Process and lifecycle: draft/review/approved/current/replaced/retired, actor permissions, audit events, source version freshness and supersession behavior.
7. Discoverability and CMS: canonical slug, title, intro, sector/task/role/event filters, keywords, disclaimers, SEO metadata, preview/download CTA and source attributions.
8. Data contract: SoT entities, constraints, FK links, versioning, dedup mapping, immutable evidence and migration strategy. No extra production table creation before approval.

10. Implementation WO: dependency-ordered steps, exact repos/services, DB migration plan, APIs/pages/jobs, rollback, deployment smoke, independent verification and Owner gates.

- LEG_RIGHTS_CLEARED: applicable obligations verified by LEG and rights documented or valid independent-original route approved
- BUILD_SPEC_READY: document+CMS+download+QA+WO completely specified
