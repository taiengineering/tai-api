## Findings
1. Manufacturing preventive maintenance covers preventive calendar, breakdown response, lockout/return-to-service and operational handoff. **Only role's work duties directly evidenced, not original paper templates.**
2. Facility FM entries remain unverified workflow hypotheses in this study. **Do not claim external practitioners actually supplied these file names.** Dedicated FM case study needed.
3. University lab safety provides the strongest *individual document* evidence this round: exact daily inspection, outdoor-storage inspection, organization-level checks and change-registration workflows.
4. Chemical warehouse role source establishes inbound/outbound/storage and warehouse safety, whereas lot, shelf-life and inventory discrepancy columns remain TAI design hypotheses. This distinguishes WMS traceability from a generic SDS file repository.
5. Correct artifact designs will depend on whether document is reusable blank form, repetitive editable register, incident one-off report or official form. No common template or files yet.
