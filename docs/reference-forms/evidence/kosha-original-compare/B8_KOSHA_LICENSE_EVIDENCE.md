# B8 C029/C031/C033 — KOSHA 라이선스·재배포 권한 증거

## 1. 조사 범위

C029, C031, C033 에 대응하는 KOSHA 24종 서식의 라이선스·재배포 권한 증거 수집.

---

## 2. 확인된 증거

### 2.1 KOSHA 게시 페이지 안내 문구 (연구 문서 기반)

출처: OBJ-REF-01-KOSHA-24-FORMS-SOURCE-03.md

> "게시된 참고서식은 사업장 상황에 맞게 수정 가능"

판정:
- 내부 업무 사용 맥락의 문구
- 상업적 SaaS 배포·유료 다운로드에 대한 명시적 허가 아님
- 일반적 상업적 재배포 허가 아님

### 2.2 KOGL(공공누리) 유형 미확인

| 항목 | 상태 |
|------|------|
| 해당 게시물 KOGL 유형 확인 | 미확인 |
| KOGL 유형 1 (자유이용) 적용 여부 | UNVERIFIED |
| KOGL 유형 2 (비영리) 적용 여부 | UNVERIFIED |
| KOGL 유형 3 (변경금지) 적용 여부 | UNVERIFIED |
| KOGL 유형 4 (비영리+변경금지) 적용 여부 | UNVERIFIED |

KOGL 유형 확인을 위해서는 해당 페이지 접근이 필요하나 JWT 인증 장벽으로 미확인.

### 2.3 붙임2 HWP 라이선스 (C029, C033 해당)

| 항목 | 상태 |
|------|------|
| 붙임2 HWP 파일 확보 | NOT_OBTAINED |
| HWP 파일 내 저작권 표기 확인 | IMPOSSIBLE |
| 원본 파일 KOGL 표기 유무 | UNVERIFIED |
| 상업적 재배포 명시 허가 | NOT_FOUND |

### 2.4 붙임5 ZIP 라이선스 (C031 해당)

| 항목 | 상태 |
|------|------|
| 붙임5 ZIP 파일 확보 | NOT_OBTAINED |
| ZIP 내 파일 저작권 표기 확인 | IMPOSSIBLE |
| 엑셀·한글 파일 KOGL 표기 유무 | UNVERIFIED |
| 상업적 재배포 명시 허가 | NOT_FOUND |

## 4. 연구 문서 법령 인용 (2차 증거)

출처: OBJ-REF-01-KOSHA-24-FORMS-SOURCE-03.md §"Scope, authority, fidelity"

> "LEG continues as legal applicability SoT."

법적 적용성 최종 판정 권한은 LEG에 있으며, 이 문서는 출처·라이선스 증거만 기록.
