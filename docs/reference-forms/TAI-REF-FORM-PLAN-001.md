# TAI 참고서식 콘텐츠 서비스 기획서 v1.0

## 1. 목적 및 범위
안전관리 전체 업무에서 사용되는 관리대장·점검표·계획서·보고서·평가표·교육/서명·법정 별지 등 실무문서를 조사·정규화하여, 사용자에게 검색 가능한 상세 설명과 편집/인쇄 파일을 제공한다. 기존 TAI 자동서식 문서군을 포함한 안전관리 전체 실무서식을 제공한다. 기존 DB와 대조하거나 중복 제거하는 작업은 수행하지 않는다. 기존 TAI 자동서식의 문서명/업무유형은 범위 파악의 참고로만 사용하며 내용·필드배치·디자인을 복제하지 않는다. 조사 후보 218건은 전체 모집단이 아닌 초기 참고 목록이다. 18개 분류 역시 변경 가능한 초기 가설이다. 목표 이용자: 사업주/안전관리자/현장관리자/실무자.

## 2. 원칙
- PRJ=개발 거버넌스, LEG=법령 SoT. 자료실 CMS는 기존 진단/자동 문서 엔진과 별개 서비스이며 기존 코드/SoT를 변경하지 않는다.
- GPT=조사계획·분석·설계·작업지시·독립검증; Claude Code=필요 시 사실조사·실행·증거수집; Owner=승인권.
- 법정 별지: 현행 공식 원본임을 표시하고 변형하지 않는다.
- 공공 자료: 출처/공공누리 유형/별도 라이선스/상업적 사용·변형·재배포 여부를 문서별 확인하여 허용 시 원본 제공.
- 민간/일반 참고·관리 서식: 필수 정보를 사실에 근거하여 TAI가 내용과 배치를 독자적으로 설계한다. 법정 필수항목과 실무 권장항목을 구분.
- 저작권/법령 불확실성과 검수 전 파일은 게시 금지.
- 공통 디자인은 인벤토리 및 항목 분석 후에만 개발한다.

## 3. 검색·콘텐츠
문서 ID, 표준명, 검색 별칭, 카테고리/업무/산업 태그, 사용시점, 작성주체를 관리한다. 각 서식은 canonical 상세페이지 하나에 고유 SEO title/meta/H1, 핵심 요약, 언제/누가/무엇을/어떻게 작성하는지, 기재항목(필수/권장), FAQ, 출처/현행성, 관련 서식, 실제 검수된 다운로드 목록을 포함한다. 파일 형식별 SEO 중복페이지를 생성하지 않는다. 제목과 설명은 검색어·실무 목적·법적 정확성 검증 뒤 승인한다. 얇은 내용의 자동 게시를 금지한다.

## 4. 파일 제공
HWPX, HWP, DOCX, XLSX, PDF 별도 포맷. 계획서/보고서 DOCX 중심, 관리대장/계산 XLSX 중심, 모든 파일의 PDF 열람본은 필요 시 제공, 공공기관 원본은 실제 허용 형식으로 제공. 반드시 4가지 전부 생산하지 않는다. PPTX/CSV는 별도 검토. HWPX와 HWP 호환/변환을 자동 합격으로 인정하지 않음. 파일 버전, 원본/변환 provenance, 체크섬, 크기, MIME, 저장 경로, 제작/열람/인쇄/계산 QA, 게시 승인 추적.

## 5. 별도 CMS 논리 구조(물리스키마 확정 전)
1. reference_forms — canonical ID, 대표명/업무분류/게시상태
2. reference_form_content — SEO·작성법·FAQ·정규 URL
3. reference_form_files — 1:N 포맷/버전/검수/해시
4. reference_form_sources — 원본 기관·근거·이용권/현행성 검증
5. reference_form_relations — 문서 관계/업무 흐름
6. reference_form_legacy_links — 기존 DB 원본 식별자 매핑
7. reference_form_aliases — 유사 검색명과 검색의도
8. reference_form_events — 리뷰/승인/발행 감사기록
물리 DB 적용 전 PK/FK/unique/index/RLS/스토리지 ACL/마이그레이션/회수 정책과 기존 document-engine API 충돌 여부 확인.

## 6. 인벤토리와 품질게이트
업무 전체 매트릭스 구축 → 공식/현장 근거 조사 → 서식 제공 대상 목록 및 업무별 분류 확정(기존 DB와 비교·중복판정하지 않음) → 문서별 필수/권장/선택 필드 정의 → 파일 우선순위 → SEO 네이밍 → 물리 DB/공통 디자인 Owner 승인 → 대표 샘플 제작/검증 → 배치 제작 → 단계적 발행.
QA: 출처 실제 확인, 법적 주장 및 현행성, 저작권 허용, 필드 실용성, 문서명 검색의도, URL 유일성, 실제 파일 열기/저장/계산/출력, 파일 체크섬, 접근제어, Owner publish approval.

## 7. 현재 기준선 및 금지
2026-10-08 선행 조사에서 document_forms=260, document_form_master=64, form_templates=11 기록(합계 335 레코드; 고유문서수 아님); 신규 후보 218은 미검증이며 중복 미제거. 세 가지 기존 DB 테이블을 별도 보존. 생산 DB write/DDL, 기존 API 변경, 배포, 공개, 무허가 자료 복제를 이번 문서 승인으로 허용하지 않는다. 파일 링크/출처 URL은 추가 실측·검증 필요.

## 8. 승인 게이트
A0 조사 스코프/중복기준, A1 서식 항목·권리 모델, A2 DDL·RLS·스토리지, A3 공통 디자인 및 파일 생산 방식, A4 시범파일, A5 게시/색인. 단계별 증거와 롤백을 제출한다.

## 9. Owner scope correction (2026-10-08)
- 본 사업은 기존 TAI 시스템의 문서 DB 정비가 아닌 **독립 참고서식 제공**이다.
- 기존 TAI에서 자동생성되는 문서의 유형까지 **빠짐없이 독립 제작 범위에 포함**한다. 단, 자동서식 원본의 편집·내용복사·레이아웃 재사용 금지. 업무 요구, 공식 법령, 공공자료를 조사해 별도 기재항목/디자인을 직접 설계한다.
- 기존 TAI DB 335건 대비 중복·매핑·병합 분석은 **중단/비목표**. 이전 중복 보고서는 역사적 조사 흔적으로만 남기며 제작 기준으로 사용하지 않는다.
- 참고서식 CMS는 자동문서 엔진과 분리하고, 각 문서의 검색명·목적·기재항목·제공파일을 독립적으로 관리한다.
