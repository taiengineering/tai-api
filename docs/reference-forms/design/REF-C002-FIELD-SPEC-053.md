│  사업장: ___ 작성일: ___ 번호: ___   │      │      │        ││
│                                     │ (서명)│ (서명)│ (서명) ││
│                                     └──────────────────────────┘│

### 4.2 결재란 배치 (v0.2 확정)

**결정**: 문서 제목 아래 오른쪽 배치 (전체 너비 행의 우측 90mm에 우측 정렬).

- 문서 제목 행: 전체 170mm (제목 텍스트 왼쪽, 결재란 우측 정렬)
- 결재란 블록: 총 너비 90mm, 균등 3분할 (각 30mm)
- 최소 행 높이: 15mm (서명 공간)
- 결재자 구분: 작성(F01) / 검토(F02) / 승인(F03)

DOCX 구현: 2열 테이블 (제목 영역 + 결재란 영역) 또는 텍스트박스 배치.
PDF 구현: 절대 좌표로 결재란 블록 우측 정렬.

### 4.3 기본 정보 행 (N01–N04)

선택 입력 행. 3열 테이블로 구성 (각 열 약 56mm):

```
사업장: ___________________  작성일: ____년 ____월 ____일  문서번호: ___________
```

또는 2행으로 분리 (N01/N02 첫 행, N03/N04 둘째 행). DOCX 편집성 기준으로 최종 결정.

### 4.4 전사 목표 섹션 (F04)

- 단일 텍스트 입력란: 최소 높이 20mm (2–3행 서술 가능)
- 레이블: "전사 목표" (NanumGothic Bold 10pt)
- 위치: 기본 정보 행 아래, 계획 테이블 위
- 배치: 전체 너비(170mm) 단일 셀
- 배경: 연회색(`#F5F5F5`) 또는 하단 밑줄로 기재 공간 표시

### 4.5 계획 테이블 (핵심 섹션) — v0.2 열 너비 재배분

**v0.1 → v0.2 변경**: F09 "예산(만원)" 헤더(6글자 ≈ 21mm)가 15mm 열에 미fit.
셀 좌우 여백 포함 실제 입력 공간 분석 후 열 너비 재배분.

**셀 실제 입력 공간 계산** (셀 좌우 여백 3mm×2 = 6mm 차감):

| 열 | 필드 | v0.1 너비 | v0.2 너비 | 실제 입력 공간 | 한글 10pt 글자 수 | 검증 |
|---|---|---|---|---|---|---|
| 1 | 목표·세부 추진계획 (F05) | 60mm | **58mm** | 52mm | ~13자 | ADEQUATE |
| 2 | 추진일정 (F06) | 30mm | **28mm** | 22mm | ~6자 (자유 입력) | ADEQUATE |
| 3 | 성과지표 (F07) | 30mm | **24mm** | 18mm | ~5자 | ADEQUATE |
| 4 | 담당부서 (F08) | 20mm | **20mm** | 14mm | ~4자 | ADEQUATE |
| 5 | 예산(만원) (F09) | 15mm | **22mm** | 16mm | ~4자 (숫자) | ADEQUATE |
| 6 | 달성률 (F10) | 15mm | **18mm** | 12mm | ~3자 (%, 숫자) | ADEQUATE |

**총 너비**: 58+28+24+20+22+18 = **170mm** ✓

**F09 헤더 처리**: "예산(만원)" 6글자 × 3.5mm ≈ 21mm → 22mm 열에서 한 줄 fit 가능.
Bold 10pt에서 실측 필요 — 미fit 시 헤더를 "예산\n(만원)" 2행으로 처리.

**데이터 입력 예시 (실사용 검증용)**:

| 목표·세부 추진계획 | 추진일정 | 성과지표 | 담당부서 | 예산(만원) | 달성률 |
|---|---|---|---|---|---|
| 협착·끼임 재해 예방교육 실시 | 연 2회 (3월, 9월) | 교육 이수율 100% | 안전관리팀 | 500 | — |
| 위험성평가 연 1회 실시 | 2월 | 평가 완료 100% | 각 부서장 | 200 | — |

→ F05(58mm)에서 "협착·끼임 재해 예방교육 실시" 14글자 ≈ 49mm: fit ✓
→ F06(28mm)에서 "연 2회 (3월, 9월)" 10글자 ≈ 35mm: **2행 처리 필요** (행 높이 15mm 확보 시 가능)
→ F09(22mm)에서 "500": 3글자 ≈ 10.5mm: fit ✓

**시제품 제작 전 추가 검증 필요**: F06 일정 표기가 2행 처리를 요구하는지 확인.

**기본 데이터 행 수**: 5행. 필요 시 "행 추가 가능" 안내 문구 하단 포함.
**헤더 행 반복**: PDF `repeatRows=1`, DOCX `TblHeader` 설정.

### 4.6 추진일정 (F06) — v0.2 확정

**결정**: 자유 입력형 텍스트 기재란 (옵션 A).

이유: 28mm 열에서 월별 12칸 배치 시 각 셀 약 2mm — 인쇄 불가. A4 가로 전환 없이 A4 세로 유지.
서술형 일정 ("연 2회", "매월", "3분기") 또는 날짜 범위 기재.
