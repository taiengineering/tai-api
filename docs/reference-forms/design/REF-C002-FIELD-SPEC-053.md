## 4. 레이아웃 설계

### 4.1 페이지 구성 (A4 세로, 170mm 본문 너비)

```
┌─────────────────────────────────────────────────────────────────┐
│  [N04: 적용 연도] 안전보건 목표 및 추진계획서  (문서 제목 16-18pt) │
├─────────────────────────────────────────────────────────────────┤
│  사업장: [N01]    작성일: [N02]    문서번호: [N03]  ← 선택 필드  │
├──────────────────────────────────┬──────────────────────────────┤
│           [F04: 전사 목표]       │        결재란                 │
│           기재란 (2–3행)         │  F01작성 │ F02검토 │ F03승인  │
│                                  │   서명   │  서명   │  서명   │
├──────────────────────────────────┴──────────────────────────────┤
│                  계획 테이블 (반복 행)                            │
│  F05목표·세부추진계획 │ F06추진일정 │ F07성과지표                 │
│  F08담당부서 │ F09예산(만원) │ F10달성률 │ N05비고                │
│  (데이터 행 반복, 최소 5행 기본 제공)                             │
├─────────────────────────────────────────────────────────────────┤
│                          페이지 번호 N / 전체                    │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 결재란 배치

공통 규격(COMMON-DESIGN-SPEC-053.md § 4.3) 준수:
- 위치: 문서 제목 우측 또는 문서 제목 아래 전체 너비
- 열 너비: 균등 3분할 (결재란 총 너비 90mm)
- 최소 행 높이: 15mm (서명 공간)
- 결재자 구분: 작성(F01) / 검토(F02) / 승인(F03)

설계 선택 A (우측 결재란): 문서 제목이 좌측 ~80mm, 결재란이 우측 90mm.
설계 선택 B (하단 결재란): 제목 전체 너비 170mm, 결재란 별도 행 90mm (오른쪽 정렬).
→ **TAI_NEW_PROPOSAL**: 선택 A(우측) 권장 — PLAN 유형 실무 표준. GPT 확정 필요.

### 4.3 전사 목표 섹션 (F04)

- 단일 텍스트 입력란: 최소 높이 20mm (2–3행 서술 가능)
- 레이블: "전사 목표" (NanumGothic Bold 10pt)
- 위치: 결재란 아래, 계획 테이블 위
- 배치: 전체 너비(170mm) 단일 셀

### 4.4 계획 테이블 (핵심 섹션)

**기본 열 구성 (6열)**:

| 열 | 필드 | 너비 (권장) | 최소 행 높이 |
|---|---|---|---|
| 1 | 목표·세부 추진계획 (F05) | 60mm | 15mm |
| 2 | 추진일정 (F06) | 30mm | 15mm |
| 3 | 성과지표 (F07) | 30mm | 8mm |
| 4 | 담당부서 (F08) | 20mm | 8mm |
| 5 | 예산(만원) (F09) | 15mm | 8mm |
| 6 | 달성률 (F10) | 15mm | 8mm |

총 열 너비 합계: 170mm (A4 세로 본문 너비와 일치).

**비고 열 (N05, TAI_NEW_PROPOSAL)**:
N05 추가 시 열 너비 재조정 필요 → GPT 결정 사항.

**기본 데이터 행 수**: 5행 (최소), 필요 시 추가 가능 표시.
**헤더 행**: 다음 페이지에서 반복 (ReportLab `repeatRows=1`).

### 4.5 추진일정 세분화 옵션 (UNRESOLVED)

F06 "추진일정" 표현 방식 3가지 제안:
- 옵션 A: 자유 텍스트 기재란 (단순)
- 옵션 B: 월별 체크박스 12칸 (1월~12월 소형 셀)
- 옵션 C: 분기별 4칸 (1Q/2Q/3Q/4Q)

→ UNRESOLVED: 옵션 B가 실무 가독성 높으나 열 너비 압박. GPT 결정 필요.
옵션 B 선택 시 추진일정 열을 A4 가로로 전환 고려 (가로 본문 너비 267mm).
