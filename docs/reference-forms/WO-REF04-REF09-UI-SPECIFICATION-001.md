# 참고서식 상세페이지 UI 계약 (v1 — 다운로드 UI 교정 반영)

WO-REF04-REF09-UI-AMENDMENT-001 Owner 변경사항 적용.

기존 GPT WO에서 '로그인 후 무료 다운로드' 안내 섹션 **전부 삭제**.

---

## 1. 페이지 범위

OBJ-REF-09 (Publish and observe) 상세페이지 UI.

- 의존성: REF-05 (CMS schema) + REF-08 (Content factory QA) — 현재 BLOCKED
- 이 문서는 의존성 해소 후 구현 기준이 된다.

---

## 2. 유지사항 (기존 WO 범위 유지)

| 항목 | 상태 |
|------|------|
| 상세정보 공개 | 로그인 없이 열람 가능 |
| 파일 미리보기 공개 | 로그인 없이 미리보기 가능 |
| 다운로드 로그인 필수 | 비회원 다운로드 불가 |

| 기존 Shared Search 연계 | 통합 검색 색인 연계 유지 |
| 유료 결제 불필요 | 다운로드에 유료 구독 불요 |
| Owner 공개 승인 전 배포·색인 금지 | 무승인 자동 배포·색인 금지 |

## 3. 다운로드 섹션 UI (변경)

### 3.1 섹션 제목

`다운로드`

로그인 안내 카드, 무료 다운로드 홍보문구, 회원가입 유도문구를 **상시 표시하지 않는다.**

### 3.2 파일 목록

실제 등록된 파일마다 다음을 나열한다:

| 요소 | 설명 |
|------|------|
| 파일명 | 실제 파일명 + 확장자 표시 |
| 형식 아이콘 | XLSX / DOCX / PDF / HWPX / HWP 등 형식별 로고/아이콘 |
| 다운로드 아이콘 | 다운로드 동작 트리거 버튼 |

미등록 형식은 표시하지 않는다.

---

## 4. 비회원 클릭 동작

1. 파일 클릭 시 로그인 상태 확인
2. 비회원이면 다운로드 대신 모달 표시

**모달 스펙:**

| 필드 | 값 |
|------|----|
| 제목 | 다운로드 안내 |
| 메시지 | 다운로드는 로그인이 필요합니다. |
| 버튼 1 | 로그인 |
| 버튼 2 | 회원가입 |

3. 로그인 선택 → 기존 TAI 로그인 페이지로 이동
4. 회원가입 선택 → 기존 TAI 회원가입 페이지로 이동
5. 로그인·가입 완료 후 원래 서식 상세페이지로 복귀 (redirect 유지)

---

## 5. 로그인 회원 클릭 동작

1. 별도 모달 없이 즉시 다운로드 요청
2. 서버에서 인증토큰 검증
3. 파일 공개 승인 상태 확인
4. 권한 확인 (RLS 기반)
5. 검증 성공 → 파일 다운로드 (Storage signed URL, 클라이언트 노출 금지)
6. 인증 만료 → 로그인 모달 출력 (4번 항목과 동일 모달)
7. 파일 미승인 또는 미존재 → 적절한 오류 메시지 표시
