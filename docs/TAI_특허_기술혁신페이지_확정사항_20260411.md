# 기술 혁신 페이지 확정 사항

> 작성일: 2026-04-11
> 파일: nexas/patents.html

---

## 네이밍 확정

```
푸터 메뉴명:      기술 혁신
페이지 타이틀:    TAI의 기술 혁신
영문 표기:        Patent Pending
```

**기각된 네이밍:**
- 특허출원 현황 → 행정적, 클릭 유인 없음
- 특허 기술 → 등록 후 사용 가능
- 핵심 기술 → 평범

---

## 카드 디자인: 특허증 스타일

### 표시 항목
| 항목 | 표시 여부 | 사유 |
|---|---|---|
| PATENT PENDING 스탬프 | ✅ | 법적 상태 명시 |
| 출원번호 | ✅ | 공식 번호 공시 |
| 발명 명칭 | ✅ | 세리프 폰트 강조 |
| 핵심 기술 설명 | ✅ | 2~3줄 |
| 연계 서비스 배지 | ✅ | 하단 |
| 출원인 | ❌ | **개인 이름 노출 방지** |
| 출원일 | ❌ | **출원 시점 노출 방지** |

### CSS 핵심
```css
.patent-card {
  background: #FEFDF8;       /* 크림/아이보리 */
  border: 2px solid #B8960C; /* 골드 테두리 */
}
.patent-card::before {
  inset: 6px;
  border: 1px solid #B8960C; /* 더블 라인 */
}
.patent-stamp {
  background: #dc2626;        /* 빨간 대각선 스탬프 */
  transform: rotate(35deg);
}
.patent-title {
  font-family: 'Noto Serif KR', serif; /* 명조 폰트 */
}
```

## 법적 표기 원칙

```
✅ 가능: "특허 출원 중 (Patent Pending)"
✅ 가능: "출원번호: 제10-2026-0056330"
✅ 가능: 출원번호 공개

❌ 불가: "특허 기술" (등록 후 사용)
❌ 불가: "특허 받은" (등록 후 사용)
❌ 불가: 특허청 로고·직인 사용
```

## 법적 고지 문구 (확정)

```
본 서비스에 적용된 핵심 기술은 특허 출원 중이며
(출원번호: 제10-2026-0056330 외 4건),
출원일로부터 제3자의 동일·유사 기술 실시에 대해
법적 대응이 가능합니다.
무단 복제·모방·역설계 시 특허법에 따른
민·형사상 조치를 취할 수 있습니다.
```
