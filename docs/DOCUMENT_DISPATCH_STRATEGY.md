# TAI 서류 자동발송 채널 전략

> 작성일: 2026-05-01  
> 상태: 확정

---

## 1. 배경 및 핵심 인사이트

### 안전관리자의 실제 서류 제출 현실

안전관리자는 매달, 분기마다, 연간마다 아래 과정을 반복한다.

```
서류 작성 → 프린트 → 봉투 → 우체국 방문 → 등기 접수 → 등기번호 보관 → 대장 기록
```

**핵심 문제:** 이런 서비스(포스트플러스)가 존재한다는 것을 아는 안전관리자가 거의 없다.  
 TAI가 이를 연결해주는 것이 핵심 가치다.

### 채널별 실제 사용 빈도

| 채널 | 실제 사용 빈도 | 비고 |
|---|---|---|
| 온라인 포털 직접 입력 | 1순위 | 민원마당, 정부24 등 — TAI 자동화 불가 |
| 팩스 | 2순위 | 지방 노동청·소방서 공식 채널 |
| 이메일 | 3순위 | 담당 감독관 직접, 비공식이지만 실무 통용 |
| 방문 제출 | 4순위 | 원본 필요 서류 |
| 등기우편 | 5순위 | 법적 서류, 가장 번거로운 작업 |

## 2. TAI가 자동화할 수 있는 것 / 없는 것

### 가능
- 제출 기한 임박 알림 (SMS/카톡)
- PDF 자동 생성 (Gotenberg)
- **팩스 자동 발송** (기관 팩스번호 등록 시)
- **이메일 자동 발송** (기관 이메일 등록 시)
- **등기우편 자동 발송** (포스트플러스 API)

### 불가능
- 정부 포털 자동 로그인·제출 (인증서, CAPTCHA 차단)
- 방문 제출 대행

### 등기우편 API 가능 서비스 (조사 완료)

한국에서 PDF → 인쇄 → 등기 자동발송 API를 제공하는 서비스는 **포스트플러스가 유일**하다.

| 서비스 | 우편 API | 비고 |
|---|---|---|
| **포스트플러스** | ✅ | 우정사업본부 공식 파트너, REST API |
| 우체국 e-그린우편 | ❌ | 개인 수동 접수만, 기업 연동은 대규모 공공기관 전용 |
| 뿌리오 | ❌ | 우편·인쇄 메뉴 있으나 API 없음 |

**결정: 포스트플러스 (유일한 선택지)**

## 5. 우편 자동발송 핵심 전략

### 왜 우편이 키포인트인가

안전관리자에게 가장 번거로운 작업이 우체국 방문이다.  
포스트플러스 같은 서비스가 존재한다는 것을 모르는 사람이 대부분이다.  
TAI가 이를 열어주는 것 자체가 차별점이다.

### PDF 사본 문제 검토 결과

**우려:** 인쇄된 PDF는 법적으로 사본 → 원본 요구 시 반려 리스크

**검토 결과 (`document_submission_analysis.csv` 기준 150개 서류):**

| 구분 | 건수 | 비율 |
|---|---|---|
| 우편 발송 가능 (mail_available=true) | 약 125건 | **83%** |
| 온라인 전용·외부기관 발행 (불가) | 약 25건 | 17% |

**결론:** 83%는 이미 팩스로도 통하는 서류 = 사본 OK.  
원본이 필요한 서류는 이미 `mail_available=false`로 분류됨.  
17%는 TAI에서 "직접 제출이 필요합니다" 안내로 처리.

### 서비스 방향

```
"우체국 안 가도 됩니다"

TAI에서 버튼 하나 → PDF 자동 생성 → 포스트플러스 등기 자동 발송 → 발송 기록 자동 보관
```
