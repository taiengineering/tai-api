# for-safety-manager 리디자인 v2 작업지시서

> 파일: `nexas/for-safety-manager.html` (taieng 레포, Cursor 필수)
> 핵심: 안전관리자의 속마음이 먼저. TAI는 대답. 섹션마다 레이아웃이 다르게.
> 페이지가 길어져도 OK. 스크롤할수록 "이것도 해주네?" 느낌.
> 교육사업 제외. 준비 중 서비스는 "준비 중" 배지 + 사전등록.
> 대표 등장 없음. 신뢰 섹션 불필요.

---

## 설계 원칙

1. **속마음→해결 쌍이 기본 단위.** 하지만 모양이 매번 다름.
2. **섹션 레이아웃 6가지를 돌려 씀** → 반복감 제거.
3. **속마음은 현장 언어 그대로.** 반말, 한숨, 짜증 섞인 톤. 따옴표 안에.
4. **TAI 대답은 간결하게.** 기능명 안 씀. "이렇게 됩니다"만.
5. **각 섹션에 비주얼 1개 필수.** 목업, SVG, 아이콘, 숫자 강조 등.

---

## 레이아웃 유형 (6가지)

```
A. 풀폭 임팩트   — 다크 배경, 큰 텍스트만, 비주얼 없음 (히어로/전환점용)
B. 좌텍스트-우목업 — 왼쪽 속마음+해결, 오른쪽 모바일 프레임
C. 우텍스트-좌목업 — B의 좌우반전
D. 숫자 강조     — 큰 숫자 3개 + 한 줄 설명 (카운트업)
E. 카드 그리드   — 2~3컬럼 카드 (아이콘+짧은 텍스트)
F. 타임라인      — 세로 또는 가로 스텝 (프로세스용)
```
