## 신청 완료 3종

### 1. 기상청_단기예보 조회서비스 (ID: 15084084)
```
산업안전 현장의 풍속·기온·강수량·낙뢰 데이터를
법적 작업중지 기준과 자동 비교하여 현장 관리자에게 알림을 제공합니다.
```

### 2. 기상청_특보 조회서비스

```
산안법 기준 작업중지 여부를 자동 판단하여 현장에 알림을 제공합니다.
```

## API 키 관리

- 환경변수명: `KMA_SERVICE_KEY`
- BUILDING_API_KEY와 **별도** 관리 (기상청은 별도 키 발급)
- Railway → tai-api → Variables → `KMA_SERVICE_KEY` 등록 완료
- 3종 모두 **자동승인** 완료
