# for-safety-manager 페이지 리디자인 작업지시서

> 파일: `nexas/for-safety-manager.html` (taieng 레포, main)
> 목표: 안전관리자가 한 페이지에서 TAI 전체 서비스를 이해하고 도입까지 진행
> 톤: 공감 + 전체 서비스 맵. "당신 편에 선 사람이 만든 서비스"
> 교육사업은 제외. 작업 중인 서비스는 "준비 중" 표시.

---

## 페이지 역할

- SaaS 페이지: "TAI Safe는 이런 제품입니다" (제품 중심)
- **이 페이지: "안전관리자인 당신을 위해 이 모든 걸 준비했습니다" (사람 중심)**
- 안전관리자가 이 한 페이지에서 TAI의 모든 서비스를 보고 "이거면 되겠다" 판단

---

## 서비스 상태 정리

| 서비스 | 상태 | 페이지 표시 |
|---|---|---|
| 법령진단 (무료) | ✅ 운영 중 | CTA 버튼 활성 |
| SaaS 구독 | ✅ 거의 완료 | CTA 활성 → /service/saas |
| 인앱결제 (자동신고·문서서식·라벨) | 🔧 작업 중 | "준비 중" 뱃지 + 사전등록 |
| 수선연결 (TAI Fix) | 🔧 작업 중 | "준비 중" 뱃지 + 사전등록 |
| 컨설팅 | 🔧 작업 중 | "준비 중" 뱃지 + 사전등록 |
| 선임연결 | 🔧 작업 중 | "준비 중" 뱃지 + 사전등록 |
| 교육사업 | ❌ 제외 | 이 페이지에 표시하지 않음 |

## 섹션 구조 (총 5개)

### 섹션1. [공감] "혼자 다 하고 계시죠?"

짧게. 감정 연결만. 3스크롤 이내.

```
헤드라인:
"안전관리, 혼자 다 하고 계시죠?"

서브:
법령 파악, 점검, 기록, 보고, 교육, 신고...
겸직이라 본업도 해야 하는데.
아무도 도와주지 않고, 사고 나면 책임은 나한테.

하단 한 줄:
"당신이 못해서가 아닙니다. 구조가 그렇게 되어있는 겁니다."
```

**비주얼:**
- 피곤한 안전관리자 일러스트 또는 현장 사진
- 또는: 쌓인 서류 + 엑셀 화면 + 전화기 조합 이미지
- 다크 오버레이 + 흰 텍스트

---

### 섹션2. [전환] "TAI가 이 전부를 해결합니다"

안전관리자의 **고민 순서**대로 서비스를 배치.

```
헤드라인:
"당신의 고민 하나하나, TAI가 해결합니다."

서브:
안전관리자의 업무 흐름 그대로.
법령 파악부터 점검, 신고, 수선까지 한 곳에서.
```

**서비스 카드 6장 (세로 스크롤, 고민→해결 쌍):**

```
── 카드① 법령진단 [무료] ──
고민: "우리 사업장에 뭐가 적용되는지 모르겠어요"
해결: 업종·규모·설비 입력 → 3분 만에 적용 법령·의무 목록 자동 도출
상태: ✅ 지금 바로 가능
[무료 법령진단 시작 →]
비주얼: 법령진단 결과 화면 캡처 (모바일 프레임)

── 카드② SaaS 구독 ──
고민: "점검 일정, 기록, TBM, 서류... 혼자 다 관리하고 있어요"
해결: 법령 기반 일정 자동 생성 · 작업자 분산 배정 · D-3 알림
      TBM 전자서명 · 현장 QR 점검 · 기록 자동 보관
상태: ✅ 지금 바로 가능
[SaaS 자세히 보기 →] → /service/saas
비주얼: 대시보드 + 점검 화면 캡처 (좌우 배치)

── 카드③ 인앱결제 (자동신고·문서서식·라벨) ──
고민: "신고서류 작성이 너무 번거로워요"
해결: 점검 데이터 기반 법정 신고서식 자동 작성 · 출력 후 날인만
      설비 라벨 생성 · 문서 서식 자동화
상태: 🔧 준비 중
[사전등록 →] → /pre-register
비주얼: 신고서 목업 이미지

── 카드④ 수선연결 (TAI Fix) ──
고민: "설비 고장났는데 믿을 만한 업체를 모르겠어요"
해결: 증상 입력 → 검증된 정비업체 자동 매칭 → 견적 비교 → 시공
상태: 🔧 준비 중
[사전등록 →] → /pre-register
비주얼: TAI Fix 채팅 화면 목업 (모바일 프레임)

── 카드⑤ 선임연결 ──
고민: "전임 안전관리자가 필요한데 어디서 구하죠?"
해결: 자격 요건 자동 매칭 → 검증된 전문가·대행기관 연결
상태: 🔧 준비 중
[사전등록 →] → /pre-register
비주얼: 전문가 프로필 카드 목업

── 카드⑥ 컨설팅 ──
고민: "중대재해처벌법 대응, 전문가 도움이 필요해요"
해결: 안전관리 체계 구축 · 위험성평가 · 법령 대응 전문 컨설팅
상태: 🔧 준비 중
[사전등록 →] → /pre-register
비주얼: 컨설팅 아이콘 + 체크리스트 일러스트
```

**카드 디자인 규칙:**
- 각 카드: 상단에 고민(회색 배경 말풍선), 하단에 해결(흰 배경)
- ✅ 서비스: 파란/진한 CTA 버튼
- 🔧 준비 중 서비스: 회색 톤 + "준비 중" 뱃지(주황) + 사전등록 버튼(보조 스타일)
- 준비 중 카드는 약간 opacity 낮추되 내용은 다 보이게 (기대감 유발)
- 각 카드에 비주얼 1개 필수 (캡처 또는 목업 또는 아이콘 일러스트)

### 섹션3. [흐름] "이렇게 연결됩니다"

서비스들이 분리된 게 아니라 하나의 흐름이라는 것을 보여줌.

```
헤드라인:
"따로따로가 아닙니다. 하나의 흐름입니다."

수평 프로세스 다이어그램:
법령진단 → SaaS(점검·TBM·일정) → 이상 발견 → 수선연결 → 완료 기록
  (무료)      (구독)                              (TAI Fix)
                   ↕
            자동신고·서류 (인앱)
                   ↕
            전문가 필요 시 → 선임연결 / 컨설팅
```

**비주얼:**
- 인라인 SVG 다이어그램 (가로 흐름)
- 활성 서비스: 진한 색 노드
- 준비 중 서비스: 점선 노드 + "준비 중" 작은 뱃지
- 모바일에서는 세로 흐름으로 변환 (반응형)

### 섹션4. [신뢰] "이런 사람이 만들었습니다"

```
헤드라인:
"안전관리자 자격증을 가진 대표가
 직접 쓰려고 만든 프로그램입니다."

내용 (간결하게):
"현장에서 겸직 안전관리를 하면서
 법이 너무 많고 혼자 다 할 수 없다는 걸 느꼈습니다.
 그래서 직접 만들었습니다."

— 심태왕, TAI 엔지니어링 대표
  산업안전기사 · 건설안전기사 (취득 예정 시 업데이트)
  특허 8건 출원
```

**비주얼:**
- 대표 사진 (site-assets/about/ceo-profile.jpg 활용)
- 또는: 사진 없이 심플한 인용문 디자인
- 특허 8건 아이콘 배치 (작게)

## SaaS 페이지와의 관계

| | for-safety-manager | SaaS 페이지 |
|---|---|---|
| 역할 | 전체 서비스 맵 ("문") | SaaS 상세 + 요금제 + 결제 ("집") |
| 톤 | 공감, 사람 중심 | 논리, 기능 중심 |
