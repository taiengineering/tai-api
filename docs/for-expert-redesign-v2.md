# for-expert 리디자인 v2 작업지시서 (수정)

> 파일: `nexas/for-expert.html` (taieng 레포, Cursor 필수)
> 핵심: **전문가가 속으로 하고 싶은 말이 주(主). TAI는 그 말에 답하는 역할.**
> 대상: 대행기관, 전임 안전관리자, 정비·수선 업체, 안전 컨설턴트 — 통합 1페이지
> 서비스 상태: 전체 "준비 중" → **서비스 안내 + 파트너 사전등록**
> 대표 등장 없음. 교육사업 제외.

---

## 이전 버전과의 차이

이전: TAI의 강점에 현실을 끼워맞춤 → "영업이 힘들죠? TAI가 해결"
수정: **전문가의 진짜 속마음이 주인공** → 그 속마음에 TAI가 자연스럽게 답

속마음은 TAI를 팔기 위한 장치가 아니라,
이 페이지를 보는 전문가가 "이거 내 얘기인데?"라고 느끼는 것이 목적.

---

## 설계 원칙

1. **속마음 = 전문가가 술 한 잔 하면서 할 말.** 영업 얘기뿐 아니라 자존심, 돈, 미래 불안 포함.
2. **각 전문가 유형별로 다른 속마음.** 대행기관 대표 / 프리랜서 안전관리자 / 정비업체 사장 / 컨설턴트 — 각자 고민이 다름.
3. **해결은 설명이 아니라 한 마디.** "그런 곳에서 연락이 옵니다."
4. **전체 "준비 중"이니까 약속하지 않는다.** "~할 예정입니다", "~을 준비하고 있습니다"
5. **금지 용어: "소개비", "소개수수료", "인력소개", "소개료"** → "매칭 서비스료", "플랫폼 이용료"

## 레이아웃 유형 (6가지, 기존과 동일)

```
A. 풀폭 임팩트   — 다크 배경, 큰 텍스트
B. 좌텍스트-우목업 — 연회색/흰색 배경
C. 좌목업-우텍스트 — 흰색/연회색 배경
D. 숫자 강조     — 카운트업
E. 카드 그리드   — 2~4컬럼
F. 타임라인/프로세스 — 다크 + 인라인 SVG
```

### 섹션2. 속마음① — 대행기관 대표 [B 좌텍-우목업]

```
배경: 흰색

좌측:
속마음:
"단가 경쟁이 너무 치열해요.
 깎아달라는 곳만 있어요.
 기존 고객도 더 싼 데 찾으면 가버리고.
 영업사원 뽑을 여력도 없어서
 내가 직접 뛰어야 하는데
 점검 나가면서 영업까지 하면
 몸이 두 개라도 모자라요."

해결:
법적으로 안전관리를 맡겨야 하는 사업장이
직접 찾아오는 구조를 만들고 있습니다.
단가가 아니라 자격과 실적으로 선택받게 됩니다.

우측:
모바일 프레임 — 의뢰 수신 목업
("새 의뢰
 제조업 200인 · 강남구
 안전관리 대행 위탁
 계약 희망: 월 정기
 [상세 보기]")
```

### 섹션3. 속마음② — 전임 안전관리자 [C 좌목업-우텍]

```
배경: 연회색

좌측:
모바일 프레임 — 매칭 알림 목업
("자격 매칭 알림
 산업안전기사 · 서울 강서구
 제조업 150인 · 전임 선임 필요
 자격 일치 ✓ · 거리 4.2km
 [의뢰 확인] [패스]")

우측:
속마음:
"자격증 따는 데 2년 걸렸어요.
 교재비, 학원비, 시험비.
 그런데 막상 따고 나니까
 일은 아는 형한테 소개받아야 와요.
 이번 계약 끝나면 다음 달 뭐 하지.
 월급쟁이로 돌아갈까 생각도 했어요."

해결:
자격 요건에 맞는 사업장이
시스템 안에서 직접 연결됩니다.
소개를 기다리지 않아도 됩니다.
```

### 섹션4. 속마음③ — 정비업체 사장 [B 좌텍-우목업]

```
배경: 흰색

좌측:
속마음:
"큰 업체한테 다 밀려요.
 우리도 실력은 있는데
 인맥이 없으면 일이 안 와요.
 네이버에 올려봐야
 광고비에 묻혀서 전화 한 통 안 와요.
 공장에서 급하게 부르면 가는데
 안 부르면 할 게 없어요."

해결:
설비에 문제가 생긴 사업장에서
증상을 입력하면
자격과 거리 기준으로 매칭됩니다.
규모가 아니라 적합성으로 연결됩니다.

우측:
모바일 프레임 — TAI Fix 의뢰 목업
("수선 의뢰
 지게차 유압 누유 · 화성시
 긴급 · 24시간 이내
 자격: 지게차 정비 ✓
 거리: 8.1km
 [수락] [거절]")
```

### 섹션5. 속마음④ — 컨설턴트 [C 좌목업-우텍]

```
배경: 연회색

좌측:
모바일 프레임 — 컨설팅 의뢰 목업
("컨설팅 의뢰
 건설업 · 공사금액 48억
 안전관리체계 구축 + 위험성평가
 관련: 중대재해처벌법
 [의뢰 확인]")

우측:
속마음:
"보고서 한 건 써주면 끝이에요.
 반복 매출이 없어요.
 한 건 끝나면 또 처음부터 영업.
```
