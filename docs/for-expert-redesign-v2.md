# for-expert 리디자인 v2 작업지시서

> 파일: `nexas/for-expert.html` (taieng 레포, Cursor 필수)
> 핵심: **전문가(공급자)의 속마음이 먼저. TAI는 "일감이 알아서 옵니다"로 대답.**
> 대상: 대행기관, 전임 안전관리자, 정비·수선 업체, 안전 컨설턴트 — 통합 1페이지
> 서비스 상태: 전체 "준비 중" → **서비스 안내 + 파트너 사전등록** 페이지
> 대표 등장 없음. 교육사업 제외.

---

## 핵심 관점 차이

| | 안전관리자 | 사업주 | **전문가** |
|---|---|---|---|
| 입장 | 도움 필요 | 처벌 무서움 | **일감 필요** |
| TAI 관계 | 사용자 | 사용자 | **공급자/파트너** |
| 속마음 톤 | 반말, 한숨 | 불안, 솔직 | **좌절, 현실적** |
| 핵심 메시지 | "이것도 해주네" | "안 걸리겠네" | **"영업 안 해도 일이 온다"** |
| 페이지 목적 | SaaS 도입 | SaaS 도입 | **파트너 사전등록** |

---

## 설계 원칙

1. **전문가의 속마음 = "영업 피로"가 핵심.** 실력은 있는데 일이 안 온다.
2. **톤: 좌절과 현실.** 반말보다는 독백체. "~인데", "~거든요"
3. **해결은 "TAI 안에서 의뢰가 온다"** — 기능 설명이 아니라 구조 설명.
4. **4가지 전문가 유형을 하나의 흐름 안에서 자연스럽게 노출.**
5. **전체 "준비 중" → 사전등록 CTA가 핵심 전환점.**
6. **금지 용어: "소개비", "소개수수료", "소개료"** → "플랫폼 이용료", "매칭 서비스료" 사용
