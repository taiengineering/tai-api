# for-business-owner 리디자인 v2 작업지시서

> 파일: `nexas/for-business-owner.html` (taieng 레포, Cursor 필수)
> 핵심: 사업주의 속마음(불안·비용·무지)이 먼저. TAI는 "이러면 안 걸립니다"로 대답.
> 안전관리자 페이지와 같은 구조이되, 톤과 관점이 다름.
> 대표 등장 없음. 교육사업 제외.

---

## 설계 원칙

1. **사업주의 속마음은 "불안"이 핵심.** 짜증이 아니라 두려움.
2. **속마음 톤: 경영자의 솔직한 독백.** "걸리면 어떡하지", "돈이 얼마야", "안 할 수도 없고"
3. **해결은 리스크 제거 관점.** 기능이 아니라 "이러면 처벌을 피할 수 있다".
4. **"대표는 확인만 하면 된다"가 반복 메시지.**
5. **6가지 레이아웃 돌려쓰기** — 안전관리자 페이지와 동일 방식.

---

## 레이아웃 유형 (6가지, 안전관리자와 동일)

```
A. 풀폭 임팩트   — 다크 배경, 큰 텍스트 (히어로/전환점/CTA)
B. 좌텍스트-우목업 — 연회색 배경
C. 좌목업-우텍스트 — 흰색 배경
D. 숫자 강조     — 큰 숫자 카운트업
E. 카드 그리드   — 2~3컬럼 카드
F. 타임라인/프로세스 — 다크 배경 + 인라인 SVG
```

## 디자인 규칙 (안전관리자 페이지와 동일)

- 래퍼: `#fo2` (for-owner 2)
- 속마음: `<q>` 태그 + 큰 따옴표, 사업주 톤 (불안, 솔직, 경영자 언어)

- 모바일 프레임: `.fo2-device` (border-radius:40px, 노치)
- 카운트업: IntersectionObserver, 천단위 콤마
- SVG: 인라인, for-safety-manager와 색상 체계 통일
- 모바일 반응형 필수 (390px)
- nav(#tai-header), footer(#tai-footer) 유지
- 대표 사진/인용문 없음
- 교육사업 없음
- 준비 중 서비스 없음 (사업주 페이지에는 불필요)
- WOW.js init 유지
