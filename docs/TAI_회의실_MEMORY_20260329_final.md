## 공사현장 관리 모듈 설계 방향

```
[입력]
공사현장 개요
  ├─ 현장명 / 공사종류(건축/토목) / 공사금액
  ├─ 원청 근로자 수 + 하도급 근로자 수
  └─ 수전용량 / 공사기간

[공정 등록]
KCS 공종 목록에서 선택 (건축 75개 / 토목 50개)
  └─ 선택 공종별 작업 자동 로드 (KCSC 작업 목차)

[작업자 등록]
  ├─ 원청 직원 / 하도급 업체별 작업자
  └─ 담당 공정·작업 연결

[법령 판정]
  ├─ 합산 인원 기준 (원청+하도급)
  ├─ 공사종류별 기준 (건축 150억 / 토목 120억)
  └─ 위험작업 여부 → 안전작업허가서 자동 생성

[보고서 자동 생성]
  ├─ 작업일보 (전체 공정·작업·인원)
  ├─ 안전관리 일지
  └─ 안전작업허가서 (위험작업 해당 시)
```
