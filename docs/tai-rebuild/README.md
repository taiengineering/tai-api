## 경계·진행 원칙
- **체크·법령엔진 = 외부 범용엔진(블랙박스).** 입력→여러 레이어→JSON 결과. 엔진 내부·엔진 소유 테이블은 **엔진팀 별도 워크스트림**. TAI는 **계약 버전으로만** 접속.
- **핵심 결론(04):** 작업 무게중심은 "청소"가 아니라 **"엔진 결과 단일 계약 정립"**(현재 저장4·읽기4·투영3~4로 파편화).
- **Object 방식**: 결과물축 관리, 게이트(테스트) 통과 후 다음 착수.
- 죽음 판정은 **코드참조0 + 소유확인 + 런타임미사용** 3중 확인 후에만.
- 실측 기준: 소스(taiengineering/tai-www·tai-admin·tai-api, 45cminc/*), 운영 DB(Supabase `vwlahtguyggrhvslabax`). 백엔드는 service_role로 RLS 우회 → grant/정책 이슈는 anon 프론트 직결에만 해당.
