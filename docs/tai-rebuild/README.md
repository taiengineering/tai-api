## 경계 원칙 (중요)
- **체크·법령엔진 = 외부 범용엔진(블랙박스).** 입력 → 여러 레이어 처리 → **JSON 결과**. 엔진 내부·엔진 소유 테이블 정리는 **엔진팀 별도 워크스트림**.
- **TAI 리빌딩 대상 = 엔진 앞(입력 투입)·이음새(계약)·뒤(JSON 소비) + 순수 SaaS 도메인.** 엔진과는 **계약 버전으로만** 연결.

## 진행 원칙 (요약)
- **Object 방식**: 결과물축(Object)으로 관리. 각 Object는 범위·목표·완료 테스트(게이트)를 가지며 게이트 통과 후에만 의존 Object 착수.
- **도메인당 SSOT 1개**, **시크릿은 env(소스 금지)**, **마이그레이션은 원자적(DB+API+FE 조율)**.
- 죽음 판정은 **(a) 코드 참조 0 + (b) 소유 도메인 확인 + (c) 런타임 미사용** 3중 확인 후에만("0행"만으로 판정 금지).
