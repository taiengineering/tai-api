# O6 safe 재스코프 — vue3 기준 (2026-07-24)

## 정정 배경
앞선 O6-a/b/c는 `tadmin/full-version`을 라이브 safe로 오인해 분석했음. **실제 라이브 데스크톱 safe = `vue3/`** (safe.taieng.co.kr, CF Pages `taieng-tadmin`, root_dir=vue3, `pnpm build`, main). 이 문서가 O6 safe 계획의 정본이며 tadmin 기반 O6-a/b/c는 참고용으로 격하.

## 앱 3종 역할(확정)
- **vue3 (main)** = 라이브 데스크톱 safe. 고객사 SaaS 운영담당자 대상(로그인에서 admin 001/002·순수워커 004/006/014/022 차단). Vue3+Vuetify(Vuexy 9.5 기원). **이번 safe 리빌드 정본.**
- **tadmin/full-version** = 구 safe(Bootstrap). vue3 이식 원본 + **모바일 워커 PWA의 원본 소스**(현재 vue3/public/app로 graft됨). 은퇴 대상이나 PWA SSOT로 잔존.
- **admin-vue3 (feat/admin-rebuild)** = 관리자 앱(admin.taieng.co.kr, role 001/002). vue3 복사본, 코어(useTaiApi/useAuth) 공유·pages/nav 분리. 별도 트랙.

## vue3 현황(감사 요약)
- 페이지: `src/pages` 파일기반 47 실페이지 + login + error. **Vuexy 데모 0, 준비중 0, 빈 셸 없음.** 완성도 ≈80~85%.
- nav: `src/navigation/horizontal/index.ts` 정적 9그룹(vertical은 re-export). **role/sector/level 게이팅 없음(플랫)**. 구 `menu-tadmin.js`는 stale 폐기.
- 인증: `useAuth.ts` `POST /auth/login`→localStorage. role 분기(admin/app 차단). `saveContractInfo`가 `contract_sector/level` 저장하나 **nav 미소비(갭)**.
- 코어: `useTaiApi.ts` 싱글턴(Bearer, 401→/login). **Supabase 직결 없음(전량 tai-api)**. 엔진(document-engine/legal-engine/diagnose/kcsc)은 소비만.
- 워커 이중화: `public/app/*`(구 PWA, graft) vs SPA 라우트 `worker-check`/`worker-check-construction`(공개 QR 폼).

## 경계·원칙(불변)
계약(C1/O5) 최후 · 엔진=외부 블랙박스 별도축 · admin은 별도 트랙 · 키=Railway · main 직접 커밋·배포 · 데드코드 삭제는 **참조 전수검증 후**(O8 방식).

## Object 재정의 (O6-V*)

### O6-V0 — 베이스라인 정정 [완료]
- 범위: 라이브 safe=vue3 확정, tadmin 기반 O6-a/b/c 격하, 스냅샷·빌드 건전성 기준선.
- 게이트: 본 문서 커밋 + 최근 배포 success(1fbfa8e 빌드·배포 성공 확인). → **통과.**

### O6-V1 — 워커앱 전략 결정 [선행 게이트·제품결정]
- 범위: `public/app` 풀 PWA(구) vs vue3 `worker-check*`(신규)의 정본·소유권 결정. (a)PWA 유지·vue3는 데스크톱만 (b)워커도 vue3로 흡수 (c)PWA를 별도 앱 분리.
- 목표: 워커 UX 단일 소유권 확정.
- 게이트: 결정 문서화. **V2·V5를 블록.**

### O6-V2 — worker-check 백엔드 계약 확정
- 범위: vue3 `worker-check`/`-construction`이 쓰는 `/equipment-checks/template`·`/equipment-checks`(주석상 "추정") 실제 tai-api 존재·계약 검증, 없으면 백엔드측 신설 요청.
- 게이트: 엔드포인트 실측 확인 + 저장 성공(또는 백엔드 이슈 등록). (V1에서 worker-check 유지 시)

### O6-V3 — Vuexy 데드코드·에셋 정리
- 범위: `package.json` name(vuexy→tai-safe), `views/pages/authentication/AuthProvider.vue`, `public/images/svg/*`(gift/discord 등), `src/assets/images/*` 미참조분, `@core` 미사용 크롬(BuyNow/TheCustomizer 등)·CASL·msw — **전부 참조 전수검증 후 제거**.
- **제약(중요):** `vue3/public/assets/`는 구 tadmin 에셋이 대량 있으나 **그 일부(예 `img/tai-icon-*.png`)를 graft된 워커 PWA가 참조**함. `public/assets` 정리 시 PWA 의존분은 **보존**해야 함(삭제 전 PWA `../assets/*` 참조 목록 확정).
- 게이트: `pnpm build` green + 데스크톱 스모크(로그인·9그룹 nav·대표 5화면 200) + `/app/` PWA 스모크 무회귀 + 라우트/레이아웃 컴포넌트 오삭제 없음.

### O6-V4 — nav 권한 정합 [제품결정+구현]
- 범위: `saveContractInfo`의 `contract_sector/level`을 nav 게이팅에 배선할지, 플랫 유지할지 결정. 배선 시 그룹/항목별 sector×level 노출 규칙 구현.
- 게이트: 메뉴가 계약정책과 일치(또는 "플랫 유지" 결정 문서화) + 회귀 없음.

### O6-V5 — 레거시 tadmin 은퇴 경로
- 범위: 워커 PWA SSOT를 tadmin→vue3(`public/app`)로 정본 이관 확정 후, `tadmin/full-version`을 배포·참조에서 분리하고 아카이브. (어느 배포도 tadmin을 서빙하지 않음 확인)
- 게이트: PWA가 vue3에서 서빙됨 확인 + tadmin 무참조 확인 → 아카이브. (V1·V3 이후)

### O6-V6 — 미세 마감
- 범위: 실페이지 TODO 3건(contact/education-setting/tai-survey), `index`(홈)·`alert-list`(구) 라우트 정리, document-forms raw-fetch 예외 문서화.
- 게이트: TODO 해소/티켓화 + build green.
