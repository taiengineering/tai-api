# OBJ-C4 (SaaS SSOT) — 가격 판정 (데이터 대조)

**작성일:** 2026-07-23 · **방법:** `price_master`·`price_policy`·`product_pricing` 실데이터 대조.
**결론:** 세 저장소는 **가격이 실제로 다른 별개 모델** → 기계적 수렴 불가. 통합은 **비즈니스 "정본 가격표" 결정**이 선행.

---

## 1. 데이터 대조 (같은 서비스, 다른 가격)

**모델 A — `price_master`** (sector = BUILDING/INDUSTRY/CONSTRUCTION, tier = 일반/대형/CUSTOM)
- SAAS: 건물 149k/349k, 산업 149k/299k/499k, 건설 249k/499k
- DIAGNOSIS: 동형 149k~499k

**모델 B — `price_policy`** (category = agent/diagnosis/saas, sector = INDUSTRIAL/CONSTRUCTION/SPECIAL_FACILITY, tier = BASIC/PRO/PREMIUM/SINGLE/CUSTOM…)
- saas 산업: BASIC **99k** / PRO 199k / PREMIUM 349k
- diagnosis 산업: FREE 0 / BASIC **79k** / STANDARD 149k / PREMIUM 249k
- agent(선임대행): 산업 BASIC 150k/STANDARD 280k/FULL 협의 …

**모델 C — `product_pricing`** (generic, sector 없음)
- BASIC **79k** / PREMIUM **149k**(추천) / ENTERPRISE 0

**충돌 예시**
| 서비스 | 모델 A | 모델 B | 모델 C |
|---|---|---|---|
| SaaS 산업 기본 | 149,000 | **99,000** | — |
| 진단 산업 기본 | 149,000 | **79,000** | — |
| 공개 일반 요금 | (sector별) | — | 79,000 / 149,000 |

- sector 코드도 불일치: A=`INDUSTRY/BUILDING`, B=`INDUSTRIAL/SPECIAL_FACILITY`. tier 코드도 상이.
- `price_policy.agent`(선임대행)는 `price_safety_management`(안전관리 대행)와도 가격 체계가 갈림 → 선임대행 가격도 이중.

---

## 2. 판정

- `product_pricing`·`price_policy`는 **price_master의 다른 표현이 아니라, 실제 가격이 다른 독립 모델**이다. → **뷰/매핑으로 수렴 불가**(수렴 시 고객 노출 가격이 바뀜).
- 따라서 가격 SSOT "완전 통합"은 **기술 작업이 아니라 비즈니스 결정**(정본 가격표 확정)이 선행돼야 한다.

## 3. 소비 현황 (누가 어느 모델을 보나)
- **모델 A price_master** — admin price-setting(제 호환 뷰), `public_pricing` v3(신규 공개), `price_master_admin`. → **기술 SSOT로 이미 단일화된 경로.**
- **모델 C product_pricing** — `tai-www` **공개 가격 페이지(레거시)** + `pricing_validation_api`의 정합 검사 대상.
- **모델 B price_policy** — 자체 `/price-policy` API(요약/수정). 소비 프론트는 추가 확인 필요.

## 4. C4 가격 "마무리" (지금 가능한 것 / 결정 대기)
- **지금(안전) 가능:** `pricing_validation_api.py`의 오해 소지 docstring("Single Pricing Source: price_saas_plan…")을 "SSOT=price_master (price_saas_plan/report=호환 뷰)"로 정정 — **auth/정리 PR에 배치**(크리티컬 아님, 소규모).
- **결정 대기(비즈니스):** 정본 가격표 확정 → 확정 후 (a) 나머지 모델을 price_master로 매핑/뷰 수렴, (b) tai-www 공개 페이지를 `public_pricing`(price_master)로 이관, (c) `price_policy`/`product_pricing` 격리.
- ⚠️ **가격 불일치 자체가 운영 리스크**(고객이 페이지마다 다른 가격 열람 가능) — 우선 확인 권장.

## 5. 다음
가격은 위 결정 대기로 두고, C4 나머지(**커미션 SSOT → 교육 이원화 → 알림 레거시**)를 데이터 대조로 이어서 판정·정리한다.
