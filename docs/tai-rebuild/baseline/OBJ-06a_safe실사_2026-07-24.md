## 엔진 호출 (플래그만 — 45cm 블랙박스, tai-api 경유)
- factory-list → `POST /legal-engine/apply/{id}`
- index → `GET /legal-engine/diagnose/{fid}/history`
- construction-site-list / construction-inspection-anchor → `POST /construction/sites/{id}/diagnose`
- diagnosis-purchase → `POST /diagnosis/request-quote`
- engine-document → `GET /engine/forms(...)`
- document-forms → `POST/PATCH /document-engine/documents(...)/generate`
- 참고: `?source=LEGAL_ENGINE`는 쿼리 파라미터(엔진 산출물 소비이지 직접호출 아님).

- 공통 코어: `assets/js/tai/api.js`(apiCall/TAI_API), `auth-guard.js`, `tai-rebuild/config.js`(baseUrl/loginPath/tokenKey). Phase4 `sbFetch`/`apiErrorMessage` 공유본 치환(#79~80)과 일치.

## 열린 범위 결정(사용자 확인 필요)
1. **모바일 PWA(`app/` 16화면, Supabase Edge OTP)** — 데스크톱과 별개 클라이언트. safe 리빌드 스코프 포함 여부.
2. **런타임 콘솔(`html/runtime/` 9화면)** — 메뉴 미배선. 활성/폐기 여부.
3. **`html/admin/`(engine-monitoring, watch-engine)** — admin 성격이 tadmin 내 존재. safe/admin 어느 쪽 소관인지.
4. 원본 `X.html` vs `X.rebuild.html` 병존 — 메뉴가 실제 링크하는 파일명 확정은 O6-b(이관) 착수 시 파일별로 확인.
