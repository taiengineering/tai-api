## 잔여 (사용자/권한 필요)
1. **DNS CNAME (사용자 액션 — 필수):** 제 API 토큰이 zone:read만 있어 DNS 생성 불가(403). taieng.co.kr 존에 다음 레코드 추가 필요:
   - Type `CNAME`, Name `safe1`, Target `taieng-safe1.pages.dev`, Proxy **ON(주황)**.
   - 추가 후 Pages 도메인 검증(HTTP)이 자동 완료되어 `https://safe1.taieng.co.kr/app/index.html`이 워커 PWA를 서빙.
2. **capacitor.config.ts `server.url` 변경(DNS 완료 후 내가 수행):** `https://safe.taieng.co.kr/app/index.html` → `https://safe1.taieng.co.kr/app/index.html` (+ allowNavigation에 safe1 추가). safe1이 실제 서빙된 뒤 변경해야 안전.
3. **앱 재빌드·재심사(사용자 액션):** `git pull → npx cap sync android → Android Studio release AAB → Play Store 재심사`. server.url이 앱 바이너리에 박히므로 신규 빌드부터 safe1 적용. **기존 설치본은 계속 safe.taieng.co.kr/app/(graft) 사용** → graft는 앱 채택률 오를 때까지 유지.

## 구조 정리(분리 후 목표)
- **safe1.taieng.co.kr** = 워커 PWA 전용(독립 정적 배포).
- **safe.taieng.co.kr** = vue3 데스크톱 safe. `/app/` graft는 한시 유지 후, 신규 앱 채택 완료 시 제거(O6-V5 근처).
- 레거시 tadmin 데스크톱도 safe1에서 서빙되나(정적 전체), 워커 도메인 성격상 무해. 필요시 `_redirects`로 루트→/app/ 정리 가능.
