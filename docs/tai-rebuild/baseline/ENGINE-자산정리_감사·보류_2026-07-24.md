# 법령엔진 잔여자산 정리 — 감사 결과 + 보류 결정 (2026-07-24)

## 결정
법령엔진이 `45cminc/leg`로 이관·교정(E2E) **진행 중**이라, 관련 자산 정리는 **leg 컷오버 완료 후로 보류**. 지금은 감사·분류만 기록하고 **어떤 것도 제거·격리하지 않음**(코드·DB 모두).

## 판단 기준(중요)
- **DB 행수/사용량으로 판단 금지.** 오픈 전이라 소비자가 붙어야 채워지고 쓰이는 컬럼·데이터가 있음 → 낮은 행수 = "미사용" 아님.
- 정리 기준은 오직 **코드 참조**(미등록=앱 미마운트 + 미import). 그래도 이번엔 엔진 작업영역이라 전면 보류.

## 현재 배선(감사 확정)
- **라이브 authoritative 진단 = TAI 자체 in-DB 엔진**(`anonymous_diagnosis` → `anonymous_factory_service`).
- **leg(HTTP) = shadow**(`clients/leg_runtime_client.py`, 비차단·결과 미반영), `diagnose_clauses_common` RPC·`semantic_diagnosis` 직접경로 = **임시 검증 라우터 전용**(비라이브).
- leg 컷오버 미완(SEMANTIC_VALIDATION 진행, BASELINE FROZEN). → 구 엔진 유지 필수.
