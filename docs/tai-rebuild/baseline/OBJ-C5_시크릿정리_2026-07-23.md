| 위치 | 성격 | env화 가능? | 처분 | 오너/시점 |
|---|---|---|---|---|

| `tadmin/full-version/app/_utils.js` (safe) | 정적 JS | ❌ | **재빌드 대체** — safe 재빌드 시 `@tai/client`로 | O6 |

## 2. C5 나머지 항목 상태

- **@tai/client 공유 패키지(복붙 전역 근절):** admin-vue3는 이미 composable(`useTaiApi`=API base/token env, `useSupabaseRest`=env화 완료)로 단일화되어 **자체 중복 없음**. 진짜 통합 가치는 **레거시 3사이트가 재빌드(O6)되며 이 composable 계약을 공유**할 때 실현 → **O6와 묶어 진행**(지금 별도 패키지 배포처 결정은 O6 스코프).
- **dev_otp 노출:** 위치 정정 = `routers/auth.py`의 **`POST /auth/send-otp`**(SMS 미배선, dev_otp가 사실상 유일 전달). 라이브 safe는 **Supabase Edge Function**으로 OTP 처리 → 이 엔드포인트는 실사용 아닐 가능성. **크리티컬 auth 코드**라 전체교체·직접배포 대신 **별도 auth PR**(env-gate + 실사용 확인)로 처리. → **오너: 별도 PR**.
- **anon 열람표면 축소(정책/GRANT):** 백엔드는 service_role로 RLS 우회하므로 무관, **anon 프론트 직결 조회에만** 해당. 열람표면 338 축소는 **키 회전과 함께** 별도 DB 작업으로.
