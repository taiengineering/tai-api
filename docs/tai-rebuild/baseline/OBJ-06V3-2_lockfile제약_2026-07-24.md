# O6-V3 2차 — 데드코드 정리 제약 (2026-07-24)

## 핵심 제약: 의존성 변경은 lockfile 재생성 필요 (API-온리 불가)
- 시도: `vue3/package.json`에서 name 정정 + 미배선 msw(script/postinstall/devDep/config) 제거 (커밋 `a472c3a`).
- 결과: **CF Pages 빌드 실패** — `ERR_PNPM_OUTDATED_LOCKFILE` (`pnpm-lock.yaml`이 package.json과 불일치). 이 빌드는 `PNPM_FLAGS=--no-frozen-lockfile`가 적용되지 않고 frozen 설치로 실행됨.
- 조치: 즉시 **원복**(커밋 `7395d34`) → 빌드·배포 success로 main 복구. **라이브 무영향**(실패 빌드는 미배포).
- 결론: **package.json 의존성 추가/제거는 `pnpm install`로 `pnpm-lock.yaml`을 함께 갱신해야** 함 → API-온리(깃 커밋)로는 불가. **로컬 개발 단계로 이관.**
  - 대상: `msw` 제거, `@tiptap/*` 미사용 deps 제거(리빌드에서 에디터 2종 삭제로 소비처 0), name `vuexy-vuejs-admin-template`→`tai-safe`.
  - 절차(로컬): package.json 편집 → `pnpm install`(lockfile 갱신) → 커밋(package.json + pnpm-lock.yaml) → 푸시.
