# OBJ-C4 — 교육·알림 판정 (데이터 대조)

**작성일:** 2026-07-23 · **방법:** 교육·알림 계열 테이블 실카운트.
**결론:** 가격과 달리 **"다른 값의 충돌 저장소"가 아님** → 지금 안전한 DB 격리 액션 없음. 정리는 **코드 dedup(O6·O8)**.

---

## 1. 교육 — 실카운트
| 테이블 | 행수 | 판정 |
|---|---|---|
| **education_master** | **20** | **라이브**(admin 교육이수 현황 소스) |
| education_history | 0 | 휴면(완료이력 — 미사용) |
| education_assignment | 0 | 휴면(배정 — 미사용) |
| education_setting / company_education_setting | 0 / 0 | 휴면 |

- "이원화"(`education_history` vs `education_assignment`, 중복 `PUT /education/company-settings`)는 **양쪽 0행 = 휴면 코드중복**. 데이터 충돌 없음.
- ⚠️ 빈 테이블은 **의도된 향후 쓰기 대상**일 수 있음(완료/배정 기능) → **archive 금지**(오격리 위험).
- **조치:** 정본 완료-추적 경로(education_master 기준) 확정 후 **중복 테이블/엔드포인트 코드 dedup**(O6·O8). DB 액션 없음.

## 2. 알림 — 실카운트
| 테이블 | 행수 | 판정 |
|---|---|---|
| **runtime_notification_event** | **30,500** | **라이브 핵심**(런타임 알림엔진 이벤트) |
| runtime_notification_metrics | 9,443 | 라이브(메트릭) |
| **notification_settings** | **42** | **라이브**(사용자 알림 선호 — 레거시 `notifications.py`가 담당) |
| notifications / templates / queue / events / logs (레거시) | 0 / 0 / 0 / 0 / 0 | 휴면(알림 레코드 계열) |
| runtime_notification_queue | 0 | 일시성(처리 후 비움) |

- **레거시 통째 은퇴 불가**: `notifications.py`는 죽은 알림-레코드(0행) + **살아있는 사용자 설정(notification_settings 42행)** 을 동시에 담당. 런타임엔진은 **발송**(30.5k 이벤트)을 담당 → **보완 관계**(순수 legacy-vs-new 아님).
- ⚠️ 레거시 0행 테이블도 의도된 쓰기 대상 가능 → **archive 금지**.
- **조치:** `notifications.py`를 **(a) 사용자 설정 API(유지) / (b) 죽은 알림-레코드 경로(런타임엔진으로 대체)** 로 분리하는 **코드 리팩터**(O6·O8). DB 액션 없음.

## 3. C4 종합 (교육·알림 반영)
| 도메인 | 데이터 판정 | 조치 |
|---|---|---|
| 가격 | 충돌 저장소 3개(다른 값) | **완료** — A(price_master) 단일화, B·C archive 격리, 라우터 은퇴, validation 정리 |
| 커미션 | 계층형(기본율+override) | **패스**(고객 지시 — 서비스화 장기) |
| 교육 | 단일 라이브(education_master 20)+휴면 | **DB 액션 없음** — 코드 dedup(O6·O8) |
| 알림 | 런타임엔진 라이브(30.5k)+설정 라이브(42)+휴면 | **DB 액션 없음** — notifications.py 분리 리팩터(O6·O8) |

> **원칙 재확인:** "0행"만으로 죽음 판정 금지 — 교육·알림 빈 테이블은 의도된 쓰기 대상일 수 있어 격리 제외. 실제 정리는 **정본 코드경로 확인 후 코드 dedup**으로, 재빌드(O6)·데드코드(O8)와 함께 수행.

## 4. C4 실행 판정
- **실행 완료:** 가격 SSOT 단일화(A) + B·C 격리 + validation 정리(무중단 검증).
- **패스:** 커미션(고객 지시).
- **DB 액션 불요·코드 이관:** 교육·알림 → O6/O8 코드 dedup 큐로.
- → **OBJ-C4(SaaS SSOT)는 데이터 계층에서 실행 가능분 완료.** 잔여는 코드 dedup(O6/O8)·커미션(보류).
