### 최소 체크 원칙 설계

**기존 안 (폐기):** 개인별 보호구 6항목 체크 + 건강 4항목 체크 = 10개 체크박스
→ 매일 반복 → 형식적 클릭 → 안전 데이터로서 가치 없음

**확정 안:** 서명 = "보호구 착용 완료 + 건강 이상 없음" 확인 포함
- **평상시:** 서명만 하면 됨 → issue_flag = false (기본값)
- **이상 시:** 관리감독자가 해당 작업자에게 이상 표시 → issue_note에 사유 기입
- **문서 출력:** "참석자 전원 보호구 착용 확인, 건강상태 이상 없음" / 이상자 있으면 별도 표시

**앱 흐름 변경:**
```
[기존] QR 스캔 → 서명 → 끝 (3초)
[변경] QR 스캔 → 서명 → 끝 (3초, 변화 없음)
       관리감독자 화면에서 이상자가 있을 때만 해당 작업자 터치 → 이상 사유 입력
```
작업자 입장에서는 **기존과 동일합니다.** 관리감독자만 이상 시 추가 조작.
